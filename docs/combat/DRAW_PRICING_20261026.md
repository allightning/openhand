# 抽牌 / 刷新定价框架 · 2026-10-26 主窗

起因：数值核超带名单最大类 = 抽牌类偏肥（`advance`/`brace`/`defend2`/`haste`/`inbreath`/`statusPalm` 等，抽 1 = 1 劲定满所致）。用户拍方向：**抽牌 = 强奖励 + 刷新机制，不能免费，要有条件**；机制做深、做连贯，参考优秀作品。

## 参考系调研（2026-10-26 查证）

### 杀戮尖塔：抽从不裸给

| 牌 | 费 | 内容 | 条件 |
|---|---|---|---|
| Backflip | 1 | 挡 5 + 抽 2 | 抽占牌面约六成价值，挡只有半份 |
| Acrobatics | 1 | 抽 3 | **弃 1** |
| Dagger Throw | 1 | 打 9 + 抽 1 | **弃 1** |
| Pommel Strike | 1 | 打 9 + 抽 1 | 无（抽 1 是添头，主体是伤） |
| Battle Trance | 0 | 抽 3 | **本回合不能再抽**（自锁） |
| Offering | 0 | 回 2 劲 + 抽 3 | **失 6 血**（稀有） |
| Calculated Gamble | 1 | 弃全部手牌摸等量 | 制衡式：量不增，质换 |
| Dropkick | 1 | 打 6 | **敌有虚弱才抽 1** |

规律：抽牌永远占牌面价值的大头（挡/伤给半份），或者带硬条件（弃 / 自锁 / 血 / 状态前置）。**没有「效果全价 + 白送抽」的牌**——我们的 `brace`（全价挡 + 抽）正是 StS 不写的结构。

### 自走棋 / 小丑牌：刷新是搜索，搜索要付费且递增

- **TFT**：商店每回合免费自动刷一次（工资），主动滚 = 2 金搜 5 槽；利息阈值（存 50 金吃息）约束乱滚。刷新 = 主动搜索成本，不是升级。
- **Balatro**：滚 $5 起、同店每滚 +$1、下店重置——**递增定价**防无限搜；构筑层（券）可以降价，「把刷新变便宜」本身成了构筑奖励。

### 三国杀：工资 + 条件触发 + 制衡

摸牌阶段摸 2（固定工资）；无中生有 = 1 牌换 2（净 +1，无附加条件但占掉一次出牌）；孙权制衡 = 弃 X 摸 X（量不增、质换）；黄月英 = 用锦囊才摸（行为条件）。

## 归纳：抽 / 刷新的三种形态

1. **工资免费**：回合开始摸 D（我们已有）、TFT 免费刷、三国杀摸 2。底线量，人人有。
2. **牌面附带**：抽写在牌里。铁律 = **抽必须占价值大头或带硬条件**，不许「全价效果 + 白送抽」。
3. **经济搜索**：主动刷新要付费，递增防滥（我们的置换 = 费 −1 弃一换一，已是刷新；递增暂不加，置换自带弃牌成本）。

## 我们的「条件抽」框架（提案，待拍）

牌面抽一律从**条件菜单**里挑，不许裸抽：

| 条件 | 式 | 适合 |
|---|---|---|
| 弃 1 抽 2 | 制衡（Acrobatics） | 通用、凡牌 |
| 命中 / 达成系内条件才抽 | Dropkick（拳贴身 / 枪远档 / 钩拉近后 / 剑耗破绽后） | 系牌，机制连贯 |
| 本手未攻击则抽 | 吐纳式（配蓄力沉淀） | 棍、守势构筑 |
| 抽 N 但本手不能再抽 | Battle Trance 自锁 | 大抽牌 |
| 失 X 血 / 耗挡 | Offering | 绝招档 |
| 每手限 1 次 | 帽 | 兜底约束 |

定价：抽仍 1 劲 / 张，**条件折扣 20-35%**（进 NUMGEN 条件折扣表）。条件越苛刻、越贴系主语，折扣越深。

## 超带名单处置（按框架分流）

1. **纯抽类**（advance / brace / defend2 / haste / inbreath / statusPalm 等）：不削数字，**加条件**（逐张选菜单项，优先系内条件）；这是数值核二班的内容，和座前独立敌 ID 同包。
2. **偏肥（控）**（hitStaff / hookDisarm / staffBind / skillLock）：控制 1.5 劲定价复核，随层帽推导（待拍 11）一起，不动。
3. **偏瘦（白板）**：位移佐料化方向已拍（0.4 劲 / 格），随数值核二班补位移效果，不加数字。
4. **构筑层 27**：牌意核的包，已跳过。

与自由度铁律一致：给条件、不给免费，玩家自己决定要不要为条件去配装。
