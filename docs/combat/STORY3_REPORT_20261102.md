## 三条最好的实例

### 1. 风声不报原型名

若写成「下一战是莽夫，偏进，花 5%」，玩家拿到的是表格。

改后：

> 州桥茶摊的碗还烫，掌柜用勺沿点着街对面那个人的肩。肩往下沉，他嘴里吐出半个字，字落在进上。

听完才是机制：**听全下一场的倾向，花 ? 彩金。** 坐错桌会多出 X 个人来。选择改的是下一程的敌，不是一段解说。

### 2. 医杀有牙

谱上的由头是「掌门医看不惯沥血喂刀」，效果是同队首手劲少一截。若写成「他们理念不合，你选边站」，牙在口号上。

改后桌上同时有药粉和带血的纸。三个选项都会伤人：拿开纸，沥血的人走；让刀看完血印，按肋的人走；两人都留下，各自首手的劲少 `?`。怨可以不解，队也可以不拆。

### 3. 第 3 程不报名目

若写成「获得桩师 / 相士 / 赌徒，或拒绝」，职业名先把人定死。

改后路口是三个人：膝上有土、脚边一根木；看你的肩，在掌心写字；手指在扣着的盅上停得比别人长。拒绝的补偿写在选项上：**下一摊营地多抽 ? 张。** 木、字、盅都留在路口，路还能过。

## 创新思路

1. **情报分三口，不分成三张说明书。** 风声是茶馆里没听完的半句。底细是折缝、匣盖，或腕上按出来的印。命门是灯下那张不折的纸，或赢档之后压在筹码下的纸条。内容范例另放，买到才念：肩会换、血线以下段变密、袖里会插进来。
2. **缘分用已经有的动作叠在一起。** 夜霜是短刀的缝碰上血纸，温补是粥勺和药拳按在同一处伤。不新编两人怎么认识。群像是三个人把同一个动作做到同一拍上。拆开一个人，下一程就少这一个、多 X 个来的人。
3. **旧怨允许两边都留。** 有牙不是必须赶走一个。第三选项把代价写在劲和剑势上，数值用 `?`，玩家自己称。
4. **职业是看见的工序。** 先楔木、先说肩、先在盅沿偏一指、先等手臂伸直。进阶是这道工序多出来的一声：木裂开、字说在刀前面、盅换了底、掌心留下浅印。名目不进正文。
5. **开局是翻开三张，不是选角菜单。** 七张扣着，翻三张，看见兵器的刻痕。空白纸条决定下一程闪句叫你什么；不写，就用兵器叫。第 3 程的三个人可以全不跟，补偿是多抽，不是惩罚句。
