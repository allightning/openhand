## 二、模式 A · 踢馆（纯爬塔）

### 2.1 删

- 破/让/追/眼、位移充能、拆势、墨痕、气势——**不进爬塔战斗核**
- 意图条保留：读伤害、选站位、判断打空

### 2.2 紧张感改从哪来

- 气力不够出完手牌（膨胀后更细的点数分配）
- 站位：近打得狠、远刮痧、空档打空
- 彩金赌注 / 构筑 / 各系状态

### 2.3 数值膨胀（爬塔专用，读招不跟）

| 项 | 旧（约） | 新（爬塔） | 原则 |
|----|----------|------------|------|
| 劲上限 | 5–7 | ×8（约 40–56） | 数量级抬池 |
| 每拍回劲 | 3 | ×4（约 12） | 低于池倍率，逼分配 |
| 费 1 牌 | 1 | 6 | **不是** ×8，多出的点用来组合 |
| 费 2 牌 | 2 | 14 | 同上 |
| 气血 | 已 ×1.25 | 再 ×1.45 左右 | 拉长回合，兵刃特色才有时间表现 |

读招战役气力仍是 3/5，不膨胀。

### 2.4 各系状态牌

每系至少 **2 张**可摸到的状态/节奏牌（现有 1 张太瘦）。本周加第二张，效果走该系身份证（刀裂创、剑破绽、枪回劲/距离、棍格挡、钩滞手+拉、拳回血+抽）。

## 四、换页 vs 合成（只分析，本周不实现）

奖励池允许同一 id 叠到 3 张。两条路：

### 路线甲 · 换页（已有）

- 满 3 或主动选「换页」：`defend → defend2` 这类升级页
- **优点：** 已接线、测试绿、牌池膨胀可控、玩家「换一张更强的」直觉清楚
- **缺点：** 重复摸到同一张像浪费；换页目标表要维护；满 3 才换则前期重复无趣

### 路线乙 · 同名合成

- 2 张同 id → 自动/手动合成 1 张 +1 级（伤/挡/费效率）
- **优点：** 重复变成进度，肉鸽「捡垃圾变强」很爽
- **缺点：** 要做等级字段、UI、数值曲线；和换页表可能打架；3 级上限怎么封；读招锁牌关不能跟

### 建议（以后做）

**爬塔用「可叠 2 + 第 3 张触发合成预览」**，换页保留给「换不同功能」（卸力→抽牌页），不要两套都当主循环。读招永不合成。
