## 一、像不像抄？——诚实自查

**结论：机制骨架是「成熟范式的大杂烩」，不是抄某一款，但目前 demo 确实「通用感」太重——因为它丢掉了我们唯一的独创资产（7 格空间）。**

| 原型里的机制 | 来源范式 | 代表游戏 | 抄没抄 |
|---|---|---|---|
| 每回合气力预算、打牌花气 | 费用制 DBG | 杀戮尖塔 | 范式借用，全行业通用 |
| 敌方意图全亮、逐段结算 | 电报制 | Into the Breach / 杀戮尖塔 | 范式借用 |
| 拆/架/闪/攻 四种应对 | 攻防三角 | 所有卡牌战斗 | 通用 |
| 连拆返气滚雪球 | 连击增益 | 各类动作/卡牌 | 通用 |
| 墨痕（留痕下轮生效） | 格子标记 | 战棋常见 | 半原创（规则是我们定的） |
| 招路图（断咽喉瘫整路） | 依赖图破坏 | 少见 | 原创度最高，但还没做 |
| 起手式读人 | 扑克式读招 | For The King 2 / 各类 Boss 设计 | 范式借用，未做 |

**为什么你看着眼熟：** 目前落地的 demo 恰好只做了「气力 + 意图全亮 + 四种牌」——这是**最通用的那一层**，所以像一百个游戏。真正有区分度的三层（墨痕、招路图、起手式）只做了墨痕，而且墨痕还没绑到格子上。

**真正的风险不是抄袭，是平庸：** 我们把「七步石台」这个独创招牌拆了，换了一套谁都能写的系统。

## 二、和 7 格的关系——目前：零

| 项 | 旧拆招（空间版） | 新原型（气力版） |
|---|---|---|
| 7 格石台 | 核心：红格、距离、兵刃长度、贴身/远程 | **完全没用**，队列格是抽象序号 |
| 位移牌 | 硬拆手段（出红格） | 不存在 |
| 招眼（Eye） | 破眼全崩 | 不存在 |
| 破法表 22 种意图 | 全量接入 | 只剩 扫/刺/撞/蓄 4 种 |
| 兵器系差异 | 刀/剑/枪/棍/拳/钩各有破法 | 无 |
| 石台立绘/演出 | 挂格内小立绘 | 无 |

**这是当前原型最大的窟窿：** 游戏叫「七步石台」，战斗却和格子无关。名字、美术、旧系统全部围绕 7 格，新核把它架空了。

## 四、草案：三条路（不开工，等你拍）

### 路线 甲 · 气力制 + 7 格融合（推荐）

**核心改动：队列段不再是抽象序号，每段落在具体格子上。**

- 敌方每段招 = 「第 N 格起手的扫/刺/撞」，红格威胁区回到队列段上
- **拆牌 = 对某段的对策**（气力制保留）；**位移牌回归 = 你站哪格决定你能拆哪段**（贴身段够不着就拆不了）
- **墨痕落在格子上**：第 3 格留痕，他下回合从第 3 格起招就被克——格子重新成为棋盘
- 招路图 = 段与段的格子路径（扫从 3 格起、走到 5 格接刺），拆咽喉 = 断路径
- 气力制管「取舍」，7 格管「空间」，两层叠起来才是别人抄不走的

**代价：** 规则复杂度上一个台阶；原型要重做一轮（队列段带格坐标）。
**收益：** 招牌资产回归；「气力取舍 × 空间站位」双层博弈市面无同款。

### 路线 乙 · 气力制独立成「读招」，踢馆保留空间制

- 承认两套并存：读招战役是纯卡牌解谜（气力制），踢馆是空间拆招（旧制）
- 读招当「硬核谜题副产品」卖，不做主线核心
- **代价：** 核心玩法分裂，「重塑破招」的目标等于放弃——踢馆还是那套你不认可的系统
- **收益：** 不用再改，风险最小

### 路线 丙 · 弃气力制，回空间制深挖

- 承认气力制是弯路，回到旧空间拆招，在 7 格上做 α 招路图 + 墨痕（原 BREAK_DEPTH_PLAN）
- **代价：** 你已明确不认可旧系统「对答案」的本质，回去等于没解决病根
- **收益：** 不浪费旧资产

## 五、我的判断（不留情面）

1. **不是抄袭，但目前是平庸。** 通用层做对了（取舍确实出现了），独创层没接上。
2. **7 格必须回来。** 没有格子的「七步石台」是自杀。路线甲是唯一既治病根（取舍）又保招牌（空间）的走法。
3. **乙是温水，丙是否定这两天的判断。** 都不推荐。
4. 路线甲的具体规则草案（段带格坐标、位移牌怎么费气、墨痕怎么落格）等你拍板甲之后再出细稿——**这轮不动工**。
