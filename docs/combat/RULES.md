## 二、拆招四档（玩家视角）

敌回合结算前，`planBreaks` 对队列每一段打标签：

| 档位 | 代码 | 伤害 | 算破招计数 | 得势 | 典型场景 |
|---|---|---|---|---|---|
| **硬拆·破** | `hard` | 全免 | ✓ `v2BreakCount++` | +1 势 | 位移离格且耗位移充能；或反架类硬破 |
| **硬拆·追** | `hard`（撤段） | 他**仍撤** | ✓ | +1 势 | 打出朝他位移且更近，耗 1 位移充能 |
| **软拆·让** | `graze` | **减半**后仍结算 | ✗ | ✗ | 离格但无位移充能；或连打格挡≥8；追了但没更近 |
| **打空** | （无 tier） | 0（段落空） | ✗ | ✗ | 开局就不在红格/够不着 |
| **放** | （无 tier，撤段） | 他照撤 | ✗ | ✗ | 没追撤段 |
| **照打** | （无 tier） | 全额 | ✗ | ✗ | 还在红圈里，或没满足任何破法 |

**你问的「退步躲了伤但没拆」**：多数是下面之一——

1. **打空**：你本来不在红格，退步后段自己落空 → 没伤害，也**不算拆**（§31.14 公平性：白送拆已堵）。
2. **让**：你离格了，但这回合**没有位移充能**（没打位移牌，或充能已被前面的段耗掉）→ 半伤，日志「让！」，**不算硬拆**。
3. **照打**：退步后**仍在红格**（红格跟敌兵刃/抢步投影走，不是「当前脚下」）→ 全额伤害。

**兵刃距离与面向（Lab V2）**：拳 1 / 刀剑钩 2 / 枪棍 3。红格与命中只算**身前**（朝锁定线一侧），身后打不到；够不着或站身后 = 打空，不算拆。刀主攻：**贴身 10（叠 2 裂创），距 2 打 4**。枪 **2/3/4 格 3/5/8**，禁贴身。

**空间硬拆（打击/抢步）**：走出红格后这段本来就会**打空**（伤害已是 0）。「免伤」不是额外躲伤，硬拆多出来的是 **拆势（下一刀真伤+兵器系效果）+ 势 + 破眼/战利品**。「以拆为杀」指的是这些回报，不是免伤本身。

**仍在红格里的招**（如连打「让」）：他打得到你，半效/全免才是在谈减伤。

## 三、破法表（按意图种类）

每种敌意图有默认弱点（`DEFAULT_WEAKNESS`），可被敌人定义覆盖。

| 敌意图 | 破法类型 | 硬拆条件 | 软拆/其他 |
|---|---|---|---|
| **打击** strike | 空间·位移 | 打位移牌 + 收势离红格 + 耗 1 位移充能 | 离格无充能 → 让 |
| **抢步** lunge | 空间·离格 | 同上（`endDistGt1`） | 同上 |
| **连打** barrage | 格挡 | — | 收势格挡≥8 → 让（半效） |
| **卸力** guard | 反架 | 打破绽/刺/点穴/开缝 + 耗 1 反架充能 | 无充能 → 不破 |
| **冲锋** charge | 桩 / 进步 | 场上有桩，朝他进步且收势离开落点，或原地让他冲过头 | 横移离开落点但没进步 → 让 |
| **落桩** stake | 破桩 | 砸挡路的桩（攻击消耗其挡次），或点地/裂桩 | 低阶挡 1 次、高阶挡 2 次；棍一棍可拆高阶；贴身可砸邻格桩 |
| **拉** pull | 贴身攻 | 贴身攻击命中 | |
| **下机** trap | 躲机关 | 收势脚下无机关 | |
| **蓄势** windup | 命中 | 本回合命中敌人 | |
| **换位** swap | 留挡 | 收势格挡>0 | |
| **刀创** bleedcut | 格挡吃满 | 格挡≥刀创伤害 → 硬拆 | 否则照打 |
| **埋招** counter | 不出攻 | 本回合不出攻击牌 | |
| **金创** mend | 印记 | 敌人印记≥2 | |
| **封脉** seal | 留劲 | 收势劲力≥3 | |
| **裂盾** shatter | 不留挡 | 收势格挡=0 | |
| **吐纳** breathe | 贴身攻 | 贴身攻击命中 | |
| **撤** retreat | 追 | 朝他位移（进步/纵步/close）且收势更近，耗 1 位移充能 | 动了但没更近 → 让；没追 → 放（他仍撤） |
| **韦陀杵** pestle | 反架 | 打破绽/刺/点穴/开缝 + 耗 1 反架充能 | 无充能 → 照打且眩 1 |
| **迷眼** dust | 贴身攻 | 贴身攻击命中 | |
| **锁链** shackle | 不贴身 | 收势不贴身 | 贴着收 → 滞步 1 |
| **闪避** dodge | 不出攻或位移 | 本回合不出攻击，**或**打出位移 | 结算后你下一张攻击牌卡面伤落空；拆势真伤仍中 |
| **霸体** endure | 反架 | 打破绽/刺/点穴/开缝 + 耗 1 反架充能 | 结算后你下一张攻击仍打伤，但不吃击退/拉/眩晕 |
| **特色招** sig | 各表 | 见 `SIGNATURE_BREAK` | 无破法的特色招不准进踢馆 |

**位移充能牌**：`sidestep, retreat, advance, advance2, close, backpalm, push, push2, sweep`  
**追牌**（朝他）：`advance, advance2, close`  
**反架充能牌**：`expose, pierce, rift, marking`  
**落桩充能牌**：`plant, split`（立桩仍是棍的工作；其他兵器系用攻击砸挡路的桩）

每打一张对应牌 +1 充能；硬拆耗 1，多段按队列顺序扣。

## 四、硬拆奖励（`applyBreak`）

硬拆一段时依次：

1. **+1 势**（`addQi`）
2. **拆势 +1**（上限 3）：下一张攻击牌吃掉 1 层，兑现真伤 `BREAK_COUNTER_BASE(2) + 兵器品阶`，并附加场上兵器系效果（刀裂创 / 拳击退 / 剑破绽 / 枪远打 / 棍眩晕 / 钩缴械）
3. **连环拆**：同回合第 2 段起硬拆，拆势真伤池 +2，额外 +1 势
4. **战利品**（立刻落账，`breakLootFor`）：

| 破法路径 | 战利品 |
|---|---|
| 空间（打击/抢步） | 格挡 +4「让中带架」 |
| 追（撤） | 抽 1 + 下张攻击贴身 +2「追上」 |
| 反架（卸力） | 曝光 +2「看穿套路」 |
| 格挡吃满（刀创） | 回血 +3「铁扛回气」 |
| 桩类 | 劲力 +2「借势回劲」 |

5. **应激**：`tryAppendStressIntent(b, "break")` → 下回合敌规划时追加应激段（见下）

软拆（让）只记 `v2GrazedSegments`，**无**势、无真伤、无战利品、无应激。

## 五、招眼（Eye）

- **定义**：队列中**第一个**「可硬拆的攻击段」，且弱点属于位移或反架（`planEyeIdx`）。
- **破眼**：硬拆到眼所在段 → **套路全崩**（后续段直接散掉不结算）+：
  - 失衡 2 回合（承伤 ×2，`OFFBALANCE_MULT`）
  - +2 势
  - 拆眼加力 6 并入拆势池（打出时才扣血）
- 软拆眼段 **不能** 破眼。

## 六、应激（Stress）

| 触发源 | 来源 |
|---|---|
| 破招应激 | 硬拆一段 |
| 势爆应激 | 收招势≥3 的爆发 |
| 助战应激 | 助战化招 |
| 签名技应激 | 敌人签名技 |

**机制**（§31.14 后）：

- 触发时**不**当场插入当前队列，而是挂到 `v2PendingStress`
- **下一回合**敌规划时 drain，带「应」签拼进队尾
- 上限 `enemyStressCap`（拆招 1–2 馆强制 0；其后按馆 3–6）
- 应激段仍吃单回合伤害总督

玩家侧：破招越多 → 下回合敌招越长（但有上限、有总督）——**拆招的代价**。

## 七、变招（Variant AI）

- 同一意图种类被硬拆 ≥2 次（Boss ≥3）→ 敌人可能切 `patternSets[1]` 或换未破过的招。
- 踢馆开关：`v2VariantAi`。

---

## 八、鏖战（Grudge）

- 回合数超过阈值（杂兵 12 / 精英 14 / Boss 16）→ 双方伤害每回合 +1 叠层。
- 踢馆末馆可强制开启。

---

## 九、预览 = 结算

- 玩家回合内：`previewBrokenSegments` → UI 段上标「拆」
- 敌回合：`simV2ResolveIntentQueue` 用同一 `planBreaks(..., "resolve")`
- 红格：`registerQueueThreatProvider` 逐段投影敌位（§31.15，防抢步显示≠结算）

## 十、与赌注/彩金的挂钩（现行）

注额帽：馆 1/2/3 = 30/50/70；馆 4 起 120、170…；馆 7 后每馆 +100。

开打前**托管注额**（从彩金扣除）。赢注返还 `注额×赔率`；赢馆飞注仍发底彩、不抽税；**馆输且有注**：底彩不发，剩余彩金抽 **10%** 出血（至少 1）。复活赛禁止下注、满状态重打。每场开战满气血/劲。

黑市：价只跟馆序/底彩，**不跟彩金池**。可花钱刷新（同摊递增加价）；通常每摊最多买 4 件，第 10 馆开战前不限购。多的牌可按货架半价卖掉。营地须点「继续」才进下一屏。配装：出战牌张数按即将开战的馆有上下限，不合规不能开打。

| 赌注 | 条件 |
|---|---|
| 完璧注 | 收局血量比例 ≥ 目标（×1.5） |
| 速胜注 | 回合数 ≤ 目标（×2） |
| 血战注 | 收局血量比例 ≤ 目标（×2） |
| 赤手注 | 未用道具/助战（有道具才开盘，×2） |
| 不贴身 | 收势与敌相隔 ≥2（×2.5；枪/棍队不开） |
| 堆挡注 | 收势格挡 ≥ 目标（×1.5） |
| 本系刀 | 本局攻击皆为本系且至少打过一张（×1.5） |
| 连破注 | 馆 3+；全场硬破次数 ≥ 目标（×2.5） |
| 破眼注 | 馆 5+；破眼次数 ≥ 目标（×3） |
| 换人注 | 本局换人 ≥1（×2.5） |

峰值锚二次：`60+22s+6s²`。底彩 `B=10+6×馆`。
