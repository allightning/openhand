### 爬塔劲力（方案 C · 2026-09-10）

**每人一条蓝，不共用。** 换人扣上场者自己的劲；下场的人余劲留在后场。

| 档 | 上限（输出 / 肉盾 / 控制） | 开局 | 结束回（设计；代码仍是收势回） |
|---|---|---|---|
| 一 | 10 / 9 / 11 | 6 | 4 |
| 二 | 12 / 11 / 13 | 8 | 5 |
| 三 | 14 / 13 / 15 | 10 | 6 |

辅助同上限输出档。心法、道具、减耗走构筑；起步馆好懂，后期靠构筑。读招仍是上限 6 / 开局 5 / 回 3。

**破绽（剑）**：叠在敌人身上。打他时耗 1 层，穿挡直伤 4（面伤先吃格挡，这 4 点再扣血），用来打高格挡。

### 六系核副（爬塔 · 已落）

| 系 | 核 | 副 |
|---|---|---|
| 拳 | 击退（命中推 1） | 连击（帽 6；花 2 重放） |
| 刀 | 贴身高伤 | 裂创（贴身叠；结束跳血） |
| 剑 | 剑势（加伤=层，命中 +1，帽 6） | 破绽（帽 4，穿挡 4） |
| 枪 | 距离档（远强近弱） | 断劲（同手两枪 3–4 格扣劲 3） |
| 棍 | 桩（帽 2；禁敌身后） | 裂桩（我爆 4+晕 1；敌撞裂→你挡 +4） |
| 钩 | 拉近成功缴械（跳过下一次有伤） | 噬血 30%（仅缴械目标） |

**乱步 / 送手 / 失位** 三条分开，敌我对称：乱步=同一息又进又退；送手=贴身却没出招；失位=换位时先机不够（你领先换位则他失位）。

**爬塔不留硬拆**：连势 / 气脉 / 铺势 / 势 / 拆势 / 硬拆 / 让 / 位移充能不进爬塔状态表，局内 chip 也不亮。

## 一乙、读招胜负（仅气力承诺战役 · `qiCommit.ts`）

**仅 break 战役 / 训练馆气力承诺。爬塔击倒仍看气血，本段不生效。**

对打不以气血归零为胜负。硬拆打掉对方架势；空档打掉你的架势。架势破尽则负。攻牌不断血：点蓄力只断蓄；本拍已有硬拆或墨痕时，直取才夺势。

| 条 | 谁 | 职责 |
|---|---|---|
| 气势 ▲ 0–8 | 只有你 | 硬拆/墨 +1；空档「打」清零。▲3 夺势 2、▲5 回气 4、▲8 绝式 |
| 架势 | 双方 | 胜负条。敌 ≤0 你胜；你 ≤0 你负。界面不画气血 |

结算（收势，队列从左到右）：

| 结果 | 架势 / 气势 |
|---|---|
| 硬拆 / 墨痕 | 敌架势 −2，同拍第 2 段起再 −1；你气势 +1；红格留墨 |
| 架（擦） | 你架势 −max(0, 段值−3)；气势不清零 |
| 闪 | 不掉架势。站红格、花 1 气躲开该段 |
| 打空 | **算躲，不算拆。** 人不在红格，来招落空：不掉架势、气势不清零。播报「躲」。与闪同类（没挨打），做法不同 |
| 空档 / 错拆 / 无拆直取顶段 | 你架势 −段值；气势清零 |
| 攻点蓄力 | 断蓄，不夺敌架势 |
| 绝式 | 该段作废；敌架势 −8 |

收势末了：本拍至少一次硬拆或墨，每记直取夺势 1（气势≥3 则 2）。没有硬拆/墨的直取 = 白挨打，零夺势。

数字：你架势 12；杂兵 8；座前 14。打谱关（R1–R4、R6–R8）仍看目标清单，不因敌架势破尽提前胜。对打关（R5、RB）目标为破尽敌架势。

**登门半隐（C）。** 登门暂不守铁律「意图全段亮出」（行路仍全亮）。对打关可扣后段；蓄力段仍亮。起手式默认对应第一段暗牌：刀下=扫、刀平=刺、收刀=撞。**偶尔诱：** 开局第一条队列不诱；后续拍对打关可把最左暗段起手换成别的（约 1/6）。盯梢费 1 气翻开最左暗段，翻开的是真招（诱被拆穿）。暗段可先落子，收势时不在红格则该段**打空=躲**、这张拆作废。段上不印「用拆·点」（仅 R1 可留）。错了要能立刻看出是读错起手、信了诱，还是站错格。扣着的段不是一刀死。登门条款暂时都不升铁律。

**招路分叉（B）。** 段可标起 / 承 / 转 / 合。硬拆或墨打掉「承」，后面的「合」作废（播报「滞」），不掉你架势、不算拆。第一人只做一条咽喉，不铺整张招路图。

## 二、拆招四档（玩家视角）

> 下列四档是**踢馆爬塔**现行空间拆招。读招对打用上一节架势，不靠砍血。

敌回合结算前，`planBreaks` 对队列每一段打标签：

| 档位 | 代码 | 伤害 | 算破招计数 | 得势 | 典型场景 |
|---|---|---|---|---|---|
| **硬拆·破** | `hard` | 全免 | ✓ `v2BreakCount++` | +1 势 | 位移离格且耗位移充能；或反架类硬破 |
| **硬拆·追** | `hard`（撤段） | 他**仍撤** | ✓ | +1 势 | 打出朝他位移且更近，耗 1 位移充能 |
| **软拆·让** | `graze` | **减半**后仍结算 | ✗ | ✗ | 离格但无位移充能；或连打格挡≥8；追了但没更近 |
| **打空** | （无 tier） | 0（段落空） | ✗ | ✗ | 开局就不在红格/够不着 |
| **放** | （无 tier，撤段） | 他照撤 | ✗ | ✗ | 没追撤段 |
| **照打** | （无 tier） | 全额 | ✗ | ✗ | 还在红圈里，或没满足任何破法 |

**你问的「退步躲了伤但没拆」**：多数是下面之一——

1. **打空**：你本来不在红格，退步后段自己落空 → 没伤害，也**不算拆**（§31.14 公平性：白送拆已堵）。
2. **让**：你离格了，但这回合**没有位移充能**（没打位移牌，或充能已被前面的段耗掉）→ 半伤，日志「让！」，**不算硬拆**。
3. **照打**：退步后**仍在红格**（红格跟敌兵刃/抢步投影走，不是「当前脚下」）→ 全额伤害。

**兵刃距离与面向（Lab V2）**：拳 1 / 刀剑钩 2 / 枪棍 3。红格与命中只算**身前**（朝锁定线一侧），身后打不到；够不着或站身后 = 打空，不算拆。刀主攻：**贴身 10（叠 2 裂创），距 2 打 4**。枪 **2/3/4 格 3/5/8**，禁贴身。

**空间硬拆（打击/抢步）**：走出红格后这段本来就会**打空**（伤害已是 0）。「免伤」不是额外躲伤，硬拆多出来的是 **拆势（下一刀真伤+兵器系效果）+ 势 + 破眼/战利品**。「以拆为杀」指的是这些回报，不是免伤本身。

**仍在红格里的招**（如连打「让」）：他打得到你，半效/全免才是在谈减伤。

## 三、破法表（按意图种类）

每种敌意图有默认弱点（`DEFAULT_WEAKNESS`），可被敌人定义覆盖。

| 敌意图 | 破法类型 | 硬拆条件 | 软拆/其他 |
|---|---|---|---|
| **打击** strike | 空间·位移 | 打位移牌 + 收势离红格 + 耗 1 位移充能 | 离格无充能 → 让 |
| **抢步** lunge | 空间·离格 | 同上（`endDistGt1`） | 同上 |
| **连打** barrage | 格挡 | — | 收势格挡≥8 → 让（半效） |
| **卸力** guard | 反架 | 打破绽/刺/点穴/开缝 + 耗 1 反架充能 | 无充能 → 不破 |
| **冲锋** charge | 桩 / 进步 | 场上有桩，朝他进步且收势离开落点，或原地让他冲过头 | 横移离开落点但没进步 → 让 |
| **落桩** stake | 破桩 | 砸挡路的桩（攻击消耗其挡次），或点地/裂桩 | 低阶挡 1 次、高阶挡 2 次；棍一棍可拆高阶；贴身可砸邻格桩 |
| **拉** pull | 贴身攻 | 贴身攻击命中 | |
| **下机** trap | 躲机关 | 收势脚下无机关 | |
| **蓄势** windup | 命中 | 本回合命中敌人 | |
| **换位** swap | 留挡 | 收势格挡>0 | |
| **刀创** bleedcut | 格挡吃满 | 格挡≥刀创伤害 → 硬拆 | 否则照打 |
| **埋招** counter | 不出攻 | 本回合不出攻击牌 | |
| **金创** mend | 印记 | 敌人印记≥2 | |
| **封脉** seal | 留劲 | 收势劲力≥3 | |
| **裂盾** shatter | 不留挡 | 收势格挡=0 | |
| **吐纳** breathe | 贴身攻 | 贴身攻击命中 | |

**位移充能牌**：`sidestep, retreat, advance, advance2, close, backpalm, push, push2, sweep`  
**追牌**（朝他）：`advance, advance2, close`  
**反架充能牌**：`expose, pierce, rift, marking`  
**落桩充能牌**：`plant, split`（立桩仍是棍的工作；其他兵器系用攻击砸挡路的桩）

每打一张对应牌 +1 充能；硬拆耗 1，多段按队列顺序扣。

## 四、硬拆奖励（`applyBreak`）

硬拆一段时依次：

1. **+1 势**（`addQi`）
2. **拆势 +1**（上限 3）：下一张攻击牌吃掉 1 层，兑现真伤 `BREAK_COUNTER_BASE(2) + 兵器品阶`，并附加场上兵器系效果（刀裂创 / 拳击退 / 剑破绽 / 枪远打 / 棍眩晕 / 钩缴械）
3. **连环拆**：同回合第 2 段起硬拆，拆势真伤池 +2，额外 +1 势
4. **战利品**（立刻落账，`breakLootFor`）：

| 破法路径 | 战利品 |
|---|---|
| 空间（打击/抢步） | 格挡 +4「让中带架」 |
| 追（撤） | 抽 1 + 下张攻击贴身 +2「追上」 |
| 反架（卸力） | 曝光 +2「看穿套路」 |
| 格挡吃满（刀创） | 回血 +3「铁扛回气」 |
| 桩类 | 劲力 +2「借势回劲」 |

5. **应激**：`tryAppendStressIntent(b, "break")` → 下回合敌规划时追加应激段（见下）

软拆（让）只记 `v2GrazedSegments`，**无**势、无真伤、无战利品、无应激。

## 五、招眼（Eye）

- **定义**：队列中**第一个**「可硬拆的攻击段」，且弱点属于位移或反架（`planEyeIdx`）。
- **破眼**：硬拆到眼所在段 → **套路全崩**（后续段直接散掉不结算）+：
  - 失衡 2 回合（承伤 ×2，`OFFBALANCE_MULT`）
  - +2 势
  - 拆眼加力 6 并入拆势池（打出时才扣血）
- 软拆眼段 **不能** 破眼。

## 六、应激（Stress）

| 触发源 | 来源 |
|---|---|
| 破招应激 | 硬拆一段 |
| 势爆应激 | 收招势≥3 的爆发 |
| 助战应激 | 助战化招 |
| 签名技应激 | 敌人签名技 |

**机制**（§31.14 后）：

- 触发时**不**当场插入当前队列，而是挂到 `v2PendingStress`
- **下一回合**敌规划时 drain，带「应」签拼进队尾
- 上限 `enemyStressCap`（拆招 1–2 馆强制 0；其后按馆 3–6）
- 应激段仍吃单回合伤害总督

玩家侧：破招越多 → 下回合敌招越长（但有上限、有总督）——**拆招的代价**。

## 七、变招（Variant AI）

- 同一意图种类被硬拆 ≥2 次（Boss ≥3）→ 敌人可能切 `patternSets[1]` 或换未破过的招。
- 踢馆开关：`v2VariantAi`。

## 八、鏖战（Grudge）

- 回合数超过阈值（杂兵 12 / 精英 14 / Boss 16）→ 双方伤害每回合 +1 叠层。
- 踢馆末馆可强制开启。

## 九、预览 = 结算

- 玩家回合内：`previewBrokenSegments` → UI 段上标「拆」
- 敌回合：`simV2ResolveIntentQueue` 用同一 `planBreaks(..., "resolve")`
- 红格：`registerQueueThreatProvider` 逐段投影敌位（§31.15，防抢步显示≠结算）

## 十、与赌注/彩金的挂钩（现行）

行路剧情赌馆：单注最高当前彩金 **80%**。登门仍走馆序帽：馆 1/2/3 = 30/50/70；馆 4 起 120、170…；馆 7 后每馆 +100。

开打前**行路默认不开赌馆**。选项写「进赌馆」之后才进盘口，不预排槽位。一局最多 3 次，由选项累计。登门仍每场可押。赢注返还 `注额×赔率`；赢馆飞注仍发底彩、不抽税；**馆输且有注**：底彩不发，剩余彩金抽 **10%** 出血（至少 1）。复活赛禁止下注、满状态重打。每场开战满气血/劲。行路开局不垫资，起步彩金 20。

当铺：金创、谱、小货，营地常驻。黑市：外功、淬刃，价只跟馆序/底彩，**不跟彩金池**。江湖营地默认只摆当铺；选项写「去黑市」才开跨阶货。`skipMarket` 只藏黑市。可花钱刷新（同摊递增加价）；通常每摊最多买 4 件，第 10 馆开战前不限购。多的牌可按货架半价卖掉。营地须点「继续」才进下一屏。配装：出战牌张数按即将开战的馆有上下限，不合规不能开打。

| 赌注 | 条件 |
|---|---|
| 完璧注 | 收局血量比例 ≥ 目标（×1.5） |
| 速胜注 | 回合数 ≤ 目标（×2） |
| 血战注 | 收局血量比例 ≤ 目标（×2） |
| 赤手注 | 未用道具/助战（有道具才开盘，×2） |
| 不贴身 | 收势与敌相隔 ≥2（×2.5；枪/棍队不开） |
| 堆挡注 | 收势格挡 ≥ 目标（×1.5） |
| 本系刀 | 本局攻击皆为本系且至少打过一张（×1.5） |
| 连破注 | 馆 3+；全场硬破次数 ≥ 目标（×2.5） |
| 破眼注 | 馆 5+；破眼次数 ≥ 目标（×3） |
| 换人注 | 本局换人 ≥1（×2.5） |

峰值锚二次：`60+22s+6s²`。底彩 `B=10+6×馆`。

## 十一、牌面去重（2026-09-09）

禁止换名复制，禁止「只改费/只改数字」的平行牌。进图鉴的每一张都要有自己的结算钩子（位移、裂创、破绽、落桩、变式、绝招条件等）。

已落地：

- **异系融合**每对系只留一张（`fusePalmSaber` 这种字典序），换人不再塞正反两张同名同数。旧档正反 id 映射到这一张。
- **本系架**不再换页成「格挡 9」；六系架各带不同钩子（推 / 反震 / 破绽 / 回劲 / 落桩 / 滞手），不是六张换皮卸力。
- 删掉中后期纯数字平行牌：中盘贯手/卸/推、镇殿锤、削册、稳铺、沉脉。旧 id 映射到仍有钩子的牌（追魂掌、卸力入骨、破门、压肘、削谱、铺势、聚气）。
- **直取**改为伤 4 + 破绽 1，不再与劈掌同数。
- 同名消歧：拳系状态二档不再叫「聚气」；剑钩融合不再叫「锁喉丝」（钩状态牌保留此名）。

换页仍保留：卸力入骨、开山掌等**在原牌钩子上加一层**的升级，不是第二套平行牌。
