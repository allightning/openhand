## 待拍

### D1 · 资源主模型

建议：第一位大师用固定军械库。关卡内解锁、战前预算不进这一场。

待拍：A 固定军械库 / B 关卡内解锁 / C 战前预算 / 自定义。

现码：没有这三种模式。`createQiFight` 的手牌来自本局 `hand`，或从 `draw` 摸 4 张。`STARTER_DECK` 是一份牌库（含重复的拆·压、拆·点、扫叶·攻），不是进门齐套。

### D2 · 军械库里有哪些动词

建议：进门就有拆·压、拆·点、拆·引、横拦·架、退步·闪、进步、撤步、攻、过、盯梢。绝式不另发牌，气势满 8 才能用。

待拍：这份名单用 / 删掉其中几张 / 把现码多出来的「进招·攻」「直取」写进名单 / 自定义。

现码：牌面 9 张都在 `QI_CARDS`。过、盯梢、绝式、直取是函数，不是牌。详见下节动词表。

### D3 · 燃料

建议：正名局沿用训练场现值。气力开局 3、每拍回 3、帽 5。拆费 2，硬拆还 1。盯梢费 1。不新造货币。数字等数值阶段，本稿不另定。

待拍：沿用现值 / 正名局另定一档 / 自定义。

现码：`refillQi` 为 `min(帽, 3 + (气势≥5 ? 1 : 0) + 存货)`，`qiCap` 为 5，开局 `qi` 缺省 3。拆在 `QI_CARDS` 费 2，硬拆成功 `qi + 1`。盯梢 `playPeek` 扣 1。

### D4 · 亮段序

建议：队列从左到右就是这一拍的先后。顺序不卖，登门不设黑市买段序。

待拍：亮顺序 / 跟行路一样默认藏顺序 / 自定义。

现码：`queue` 是有序数组。段按钮上有序号 `i + 1`。暗段按钮写「后段」，不写招名。这是画面已经排成一列，不是「亮段序」这条已经拍过。

### D5 · 亮红格、藏招种

建议：每一段标红格。藏的是刺、扫、撞。登门不挂行路六类（伤势、进势、退势、守势、蓄势、诡势）。蓄力段照旧全亮，没有起手。

待拍：红格亮且招种藏 / 红格也藏 / 六类一起挂上 / 自定义。

现码：亮段按钮写招名和「N 格」。暗段按钮不写招名，写起手。石台格子上，暗段的真招名仍会拼进格子文字（`MOVE_LABEL`，人站上或有墨时不拼）。藏招种在段按钮上成立，在石台格上还没藏干净。六类架势不在 `qiCommit.ts`。

### D6 · 风声

建议：若要风声，只告诉习惯表里哪一式份数高。不告诉某一拍的段序。

待拍：要这份风声 / 登门不要情报 / 自定义。

现码：没有习惯表，没有风声。

### D7 · 虚招

建议：登门的虚招就是现有的诱。起手换成另一式，真招不动。首拍不诱，之后 1/6。不另做一层「架势标签是假的」。

待拍：诱即虚招 / 登门再加类型造假 / 诱从正名局拿掉 / 自定义。

现码：`FEINT_CHANCE = 1/6`。`maybeFeintQueue` 在下一拍开始时跑，开局那条队列不经它。`feintTell` 换起手，结算仍按 `move`。`otherTell` 的换法是刀下→刀平→收刀→刀下，一次只换相邻一把，不是两把里任选。

### D8 · 反应窗

建议：不搬七系窗，不加第八种系窗。登门一种窗，名叫改口。每番 1 次，思考 3 秒，耗气力 1。不造成伤害，不削架势，不回气。

待拍：改口按此规格 / 登门不用窗 / 搬行路七系里的某几件 / 次数、秒数、费用改数 / 自定义。

现码：`qiCommit.ts` 没有反应窗，没有改口。

### D9 · 改口何时弹出

建议：你已把拆落在暗段上，这段出手时起手和真招不符，或这段填了分叉并走到另一支。窗里两枚：维持原拆，或把承诺改成躲。没诱、没分叉，窗不弹。

待拍：按此触发 / 诱可以弹、分叉先不弹 / 改口可以改成别的动词 / 自定义。

现码：无此窗。躲已有：人不在红格，结算结果是「躲」。

### D10 · 重打

待拍：留句且不亮招种 / 跟行路一样重打全亮 / 连复盘句也不留 / 自定义。

### D11 · 两核边界

建议：行路结算留在 sim。登门结算留在 qiCommit。sim 不读气力、架势条、起手、诱、改口。qiCommit 不读劲、抽牌、配装、职业、缘分、六类架势、七系窗。板沿用登门 7 格、两端墙。

现码：`QI_BOARD = 7`。胜负看 `playerStance` / `enemyStance`（你的上限常量 12）。这局手牌、队列、气力都在 `QiFight` 里。没有改口字段。

### D13 · 权重下限与怎么减

建议：每式最低 1。二番把上一番硬拆次数最多的那式 −1。次数相同，先减当前份数高的；份数也相同，先减刺。一番没有硬拆，权重原样进二番。权重不改伤害，不改气力。

现码：无。

### D14 · 红格跟着躲走

### D15 · 架势跨番

建议：三番是一场。架势跨番。任一番有人到 0，这场结束。三番打完他的架势仍大于 0，你输。

### D16 · 气力、气势、墨不跨番

建议：气力不跨。每番第一拍从 3 起，帽 5。「过」存下的气在番末清掉。气势番末归 0。墨番末清格。绝式仍可以在同一番里打出。

现码：气力在下一拍按 `refillQi` 回，存货 `banked` 当拍用完即清。气势、墨留在同一场的下一拍。没有番末清空。

### D17 · 第一场分叉

建议：招路分叉的能力留着，第一场队列不填。`fork` 空着。承段亮、合段扣放到第二位大师，或这位的再战。

待拍：第一场不填 / 第一场就放一条承合 / 自定义。

现码：没有 `fork` 字段。段上有 `node`：`open` / `carry` / `turn` / `close`。承被硬拆或墨之后 `throatCut`，合段结算为「滞」。座前关卡已经在用这条，那是训练场，不是正名第一场。

现码：无识破，无「某式不再诱」的开关。诱只看 `allowFeint` 和 `FEINT_CHANCE`。

现码：`lastRecap` 是上一拍的招名加结果（破、闪、躲、墨等），不是番末的一句人话。

### D20 · 手牌即阵型
