# 任务卡 · 叙事 2.0（环境词条文案 + 全库文风翻新 + 文风机器守卫 + 词条路由）

2026-10-23 主窗派发。遭遇窗，MEGA 版，五个阶段。独占 `storyBeats.ts`、`climbPlaces.ts`、`gauntletPaths.ts`、新建 `scripts/proseLint/`。不定任何数值。

## 做完的样子

三类环境词条的馆间叙事成体系；`storyBeats.ts` 全库逐条过文风铁律、不过者重写；禁词有机器扫描守卫；词条标签能随路由进下一场战斗；死亡评论与战斗闪句成套。

## 阶段

### P0 · 基线盘点
- 开工先 grep 盘点：`storyBeats.ts` 现有事页 / 选项 / 死亡评论 / 闪句各多少条，行数，写进 SYNC 本班。后面所有工作量以这个基线说话。

### P1 · 环境词条叙事包
- 灼烧 / 无墙 / 缺格（末端 / 中间）三类各 3 条馆间事页（共 9）：每条 = 白描 6–10 句（看得见人、物、正在发生的事）+ 2–3 选项，选项带机制结构、数值用 `X` / `?` 占位。
- 各 1 条死亡评论（可写长）、各 2 条战斗闪句（带数字或人名，数字 `X` 占位）。
- 3 条「选项改变下一程站位远近」叙事钩子（文案，不接距离数值）。

### P2 · 全库文风翻新（大头）
- `storyBeats.ts` 每一条事页 / 选项 / 评论逐条过铁律 §4 与 §3：
  - 禁词表：便 / 却 / 只 / 亦 / 忽 / 遂 / 乃 / 方 / 而 / 于是 / 终究 / 其实 / 所谓 / 归根
  - 禁「不是 A 而是 B」反转（一场最多 1 处且必须真可能误会）
  - 禁假对峙收束（你不开口他不摊开 / 得你先说）
  - 禁段段哲理收句、禁连续超短句排比、禁「像/仿佛/如同」式心理比喻
  - 禁后半句否定撑场（不问姓 / 没叫号 / 不报上姓连用）
- 自检：删掉「不是…是…」、末句哲理、后半句「不问/没叫/不报」后场面还在，才算过。
- 不过的逐条重写。重写保持原有机制数字与选项结构不变，只动文。
- 逐条登记《翻新台账》`docs/combat/PROSE_REWORK_20261023.md`：条 id → 原问题 → 处理（重写 / 微调 / 过关）。

### P3 · 词条路由
- `climbPlaces.ts` / `gauntletPaths.ts` 加词条字段：`envTag?: "burn" | "nowall" | "gap_end" | "gap_mid"`，随路径选择传进下一场战斗的 `run` 配置（只写字段与传递，不接结算——结算由数值包统一接）。
- 路线日志（routeLog）显示词条名。
- 不改任何馆内数值与出现概率；词条出现逻辑留 `?` 占位常量并注释「等数值框架」。

### P4 · 文风机器守卫
- 新建 `scripts/proseLint/`：扫描 `storyBeats.ts`（及未来文案表）输出禁词命中报告——禁词表、反转句式（不是…而是…）、否定撑场三连（没/不结尾连续 3 句）。
- 中文禁词有误报（如「只」常用），做成 warn 报告 + 白名单机制，不进 test:combat 红线；报告接 `npm run lint:prose`。
- P2 翻新后的库跑一遍，报告贴 SYNC（目标：强制类 0，warn 类逐条白名单）。

## 创新授权（本窗最大）

用户原话：剧情文案**完全支持执行层创新**。在文风铁律（§4 禁条）、剧情 v3 方向（第一程不开赌馆等已拍结构）、不定数值三条红线之内，你可以也应当大力创新：

- **事页形态**：白描的结构、选项的给法（机制数字的呈现方式）、事页与战斗的咬合方式
- **叙事链**：词条随程推进的连续叙事、同一条路线不同选项长出不同下文、站位叙事的写法
- **写法技巧**：怎么用白描写出环境压迫感、怎么让机制数字长在句子里不生硬、闪句的节奏
- **台账与守卫**：文风翻新的判例体系（什么算「靠模板撑」的实例）、proseLint 的规则设计

创新必须落在文档里可复用：好写法进 `docs/combat/RULES.md` 遭遇节或台账判例，不许只留在对话里。
