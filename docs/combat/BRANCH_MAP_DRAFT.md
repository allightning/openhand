# 肉鸽踢馆 · 树状遭遇草案

> 状态：**已落地分叉卡池 + 同道短战** · 2026-09-02  
> 范围：Combat Lab 唯一产品（10 馆肉鸽）。地图/主线仍冻结。

10 **馆的战斗核与数值先不动。要加的是：馆与馆之间的选择会改下一战的敌人、奖励、彩金，以及你怎么拿到同道。 不是再开一条 15 馆，也不是失败后再开一条平行爬塔。**

## 1. 图怎么长：脊骨 + 枝，不是迷宫

把一局拆成两类节点：

- **馆战（脊骨）**：永远 10 场，编号 1…10。输赢、连胜、榜单都钉在这里。
- **遭遇（枝）**：插在「刚打完第 N 馆、还没开第 N+1 馆」之间。有的馆后 **没有** 遭遇，直接进营地；有的馆后强制 1 次二选一或三选一。

建议密度（可调，先少后加）：


| 打完    | 遭遇？                 | 作用          |
| ----- | ------------------- | ----------- |
| 馆 1   | 无或极短（客栈问路）          | 教「原来能选」     |
| 馆 2   | 有，二选一               | 第一次改下一战     |
| 馆 3   | **同道遭遇**（见 §5）      | 人，不是货       |
| 馆 4–5 | 有一处                 | 稳/肥/险成型     |
| 馆 6   | 无或黑市加强              | 超级奖励仍在营地    |
| 馆 7   | **第二同道遭遇**          | 债、换人、拒收     |
| 馆 8   | 有，且可跨主题（少林线摸到朝廷桩）   | 记忆点         |
| 馆 9   | **终馆抉择预告**（情报，尚未开战） | 让馆 10 选择有根据 |
| 馆 10  | **终局抉择 → 开打**       | 见 §4        |


三条开局路（少林/江湖/朝廷）= 三套 **遭遇卡池 + 敌人皮**，图的拓扑一样。不要做成三套完全不同的 10 馆脚本，否则内容爆炸、也测不完。

每局实际走的是一条路径，但 **可见的下一跳有 2～3 个**，像 Slay the Spire 的「看得到下一层三个点，选一个走」，不是全图迷雾 30 节点。

```
馆1 ─► (无) ─► 馆2 ─► [稳/险] ─► 馆3 ─► [同道遭遇] ─► 馆4 …
                                              └► 馆4'（敌人/奖不同）
```

看得见的信息：节点名、一句后果、风险色（青/金/赤）。不要藏「选了才告诉你打谁」——情报可以不完全，但方向要诚实。

## 2. 遭遇改什么（必须落到三件套）

每个遭遇选项结算 **最多改三类**，写进同一条 `RunModifier`，下一馆开战时吃掉或挂着走：

1. **敌人**：多 1 个替补、换成具名精英、禁某兵刃、抬/降 `stressCap` / `dmgCoef`、加一条馆法（本馆禁位移、必须贴身、眼段提前）。
2. **奖励**：营地免费多抽 1、锁某系谱、跳过黑市、指定淬刃、同道债牌进仓库。
3. **彩金**：立刻 ±一笔；改下一馆底彩系数；解锁/关掉某盘口；强制最低注。

禁止一个选项同时改七八样。玩家要能用一句话复述：「我选了伏击，下场多一个人，但货架多一张谱。」

### 2.1 节点类型（先做这 6 种，够用）


| 类型     | 玩家在干什么        | 典型后果                 |
| ------ | ------------- | -------------------- |
| **客栈** | 听一句、选帮谁       | 小彩金 / 下馆敌人换皮 / 一张定向谱 |
| **赌摊** | 用现有彩金赌小局（非馆战） | 赢：彩金；输：出血但不掉馆序       |
| **伏击** | 选硬闯或绕         | 硬闯=下馆人多奖厚；绕=人少奖薄     |
| **暗桩** | 买情报           | 花彩金看清下两馆敌人与终局选项      |
| **人情** | 答应或拒          | 答应=同道线提前或债；拒=干净但少牌   |
| **岔路** | 纯稳/肥/险        | 只改下一馆三件套，无战斗         |


馆战本身不要变成事件。事件 **不占用馆号**，才保爬塔榜。

### 2.2 稳 / 肥 / 险（分叉的默认语义）


| 枝     | 下一馆            | 营地         | 彩金            |
| ----- | -------------- | ---------- | ------------- |
| **稳** | 人数少或无馆法        | 奖励普通       | 底彩保底          |
| **肥** | 标准人数           | 多 1 免费或更好货 | 可能要先付过路费      |
| **险** | +1 人 / 精英 / 馆法 | 超级向        | 底彩×1.2 或高赔盘解锁 |


同一局不要连续三场「险」，图生成时互斥：险之后下一跳至少一张稳。

## 3. 失败：不要另开亡命线，要「同一棵树上的伤」

爬塔榜要的是 **馆数 + 彩金**。若失败后把你丢进另一条短线，馆数怎么算、彩金怎么比，都会脏。所以：

**失败不换地图，只在原树上盖章。**

### 3.1 三次梯，替代「两次死光」


| 次第          | 现在                | 改为                                                                                                       |
| ----------- | ----------------- | -------------------------------------------------------------------------------------------------------- |
| **第 1 次馆败** | 赊账再战（禁注、满状态、付复活费） | **保留。** 仍是「这馆没过，原地重打」。馆序不变，榜仍可冲。                                                                         |
| **第 2 次馆败** | 直接结算出局            | **带伤过馆。** 本馆记败、**馆序仍 +1**（你确实往上爬了）、不发底彩、剩余彩金再抽一笔伤（建议 20%，可再议）、获得 **伤痕 1**。下一跳 **强制从险枝里抽**（或锁死稳枝）。仍在同一棵树。 |
| **第 3 次馆败** | —                 | **出局。** 结算上榜：馆数、彩金、是否带伤。                                                                                 |


这样第二次失败的惩罚是「后面更难、钱更少」，不是「进度清零」。冲榜的人仍要打到 10；浪的人第二次倒了还能爬，但终馆会很难、彩金很难看。

不要做：失败后进入「亡命 4 馆」独立剧本。那会变成第二个 SKU，和榜单抢语义。

### 3.2 伤痕做什么（挂在 run 上，不另开模式）

`scars: number`（0–2）影响：

- 事件图：稳枝权重下降，险权重上升。
- 赌馆：高赔盘（连破/破眼）可关，或最低注抬高——逼你用现有钱打，而不是用盘口翻盘。
- 终局：有伤痕时「人海」更劝退，「私了」更便宜但奖薄（见 §4）。
- 榜单展示：`第 10 馆 · 彩金 X · 完璧` vs `第 10 馆 · 彩金 X · 带伤`。主排序仍是馆数，其次彩金；完璧只是标签，避免逼所有人重开刷干净。

赊账救命奖励 **仍可留**，它吃的是第一次失败，不和伤痕抢戏。

### 3.3 和「见好就收」的关系

无尽已删。收手只有结算。带伤过馆 **不是** 见好就收：你还在爬，只是脏着爬。若以后要「主动收手上榜」，用现有结算屏即可，不要再做失败支线。

## 4. 终馆抉择（馆 10 开打前）

馆 9 营地或馆 9 后遭遇给 **情报**（可被暗桩加强）。馆 10 进入下注前先选终局，再生成敌人：


| 抉择           | 敌人           | 馆法 / 结构     | 奖励            |
| ------------ | ------------ | ----------- | ------------- |
| **人海**（现行偏这） | 4 人轮番，杂+1 精英 | 空间挤、破招可选    | 货厚、底彩高        |
| **座前**       | 1 具名 + 1 护卫  | 眼段/应激高，人数少  | 中等货 + 称号/完璧友好 |
| **私了**       | 1 人（路数针对你的系） | 可能禁某位移或必须贴身 | 彩金少、一张独特谱或剧情尾 |


伤痕 ≥1 时：人海再 +1 替补或伤系数；私了解锁「降赏保命」——更容易打完 10 馆上榜，但彩金差一截。

选择 **改变的是这一馆的遭遇，不是再打一局附加赛。** 馆号仍是 10。

## 5. 同道：馆 3 / 7 用遭遇战 + 几句词，不用纯点头像

现行：过馆 → 四选一卡面 → 牌包打针。保留「最多 2 人、3 与 7」，改入口。

### 5.1 流程

1. 过 3 或 7 后 **不直接四选一**。
2. 进入 **同道遭遇**（仍不占馆号）：2～3 个带立绘的选项，每项 2～4 句词 + 一种获取方式。
3. 选完可能 **打一场遭遇战**（短、不走完整下注；可禁注或固定小注），或纯对话。
4. 赢/答应 → 该人入伙，牌包按现规则打针（光环/组合卡）。
5. 拒/逃 → 本里程碑可以空过（少 1 同道），或从剩余两人里换成「路遇」弱加入（无债也无组合卡）。



### 5.2 获取方式（同一套人，不同枝）


| 枝      | 剧情核     | 战                 | 入伙代价           |
| ------ | ------- | ----------------- | -------------- |
| **救命** | 他被围，你下场 | 短战 1～2 人          | 下馆敌人可能记仇（+1 杂） |
| **比武** | 擂台分胜负   | 单挑他本人（友好 AI / 低伤） | 无债；赢了才跟        |
| **买命** | 用彩金赎人   | 无战                | 当场扣一大笔；货架暂时变差  |
| **追杀** | 他追你或你追他 | 短战                | 入伙带「债牌」（强但占牌包） |
| **拒**  | 不收      | 无                 | 干净，里程碑空        |


馆 7 第二人优先用 **与第一人有关系** 的卡池（同门、仇家、朝廷对头），让选择影响 **之后的遭遇皮**（馆 8 岔路出现「为他出头」），而不是只加一张牌。

词要短：立绘 + 三句 + 按钮。不要做成主线对话树。

## 6. 生成规则（防内容爆炸）

- **拓扑固定，填的是卡。** 程序只知道「馆 2 后是二选一岔路」；文案/敌人从当前 `path` + `scars` + 已有同道的池子抽。
- **每条开局路 8～12 张遭遇卡即可打底**，三路共享部分「客栈/赌摊」模板，只换名字。
- **同一 run 不抽重复遭遇 id。**
- **馆战敌人仍走现有梯子不重复。** 遭遇只允许：加 `extraEnemyIds`、换本馆主敌为池内未用过的、改系数。不要现场造新敌 id。
- UI：营地之上或营地里一块 **「前路」**：两个按钮 + 一句。不要单独做一张大地图要拖。

## 7. 和现有系统怎么接


| 现有                | 接法                                   |
| ----------------- | ------------------------------------ |
| 营地 / 黑市 / 配装 / 下注 | 遭遇在 **营地之前或之后、下注之前**。先事件，再配装，再下注，再打。 |
| 底彩 / 出血 10%       | 馆败规则按 §3；遭遇里的小赌另算，不叫馆败。              |
| 赊账救命              | 只服务第一次馆败。                            |
| 3/7 同道            | 换成 §5，人数上限不变。                        |
| 三条开局路             | 主题皮 + 遭遇卡池，梯子馆数不变。                   |
| 榜单                | `streak`（馆）+ `pot` + `scars` 标签。     |

## 9. 待你点的数字

1. 第二次失败出血 20% 是否可接受（第一次馆败仍是 10% + 无底彩）。
2. 带伤过馆后 **本馆算不算连胜中断**：建议算中断（streak 清），但 **stage 仍 +1**，否则榜上的「馆数」会和感觉打架。
3. 同道遭遇战要不要走完整下注：建议 **禁注短战**，避免事件比正馆还长。
