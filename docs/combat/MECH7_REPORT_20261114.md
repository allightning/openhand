## 落了什么

### 出射程就补进势

敌我距离大于敌兵刃射程时，队列的净步进至少要能把距离收进射程。净步 = 进势步数 − 退势步数。进势算逼近、拉近、抢步、冲锋、换位。

重抽走 `planFromFirst`，站位先还原再补，规划时的投影不算。龟谱、游走谱的开手走 `commitFoeKit`，同一条保底。血线换势重排的新队列也走这一条。

不够的步进补在队首，先花劲走近。枪、棍一步最多 3，其余最多 2。钩在两步以上用拉近。

### 连续两手没靠近就加码

`CLIMB_APPROACH_STALL` = 2，`CLIMB_APPROACH_EXTRA` = 1，都黄。上一手排招时的距离记在 `foeDistMark`。收势重抽时距离没比这个短，`foeApproachStall` 加 1。满 2 手且人还在射程外，下一队再多 1 段进势。已经在射程里不加。

### 禁对消

同一队进势和退势净位移为零，退势改成同等步数的进势。`advance2+retreat2` 排不出来。原型是游走，而且退完后面还有进势，这一对留下。人还在射程外时，前面再补进势，净步仍然要够。

## 创新思路

1. 进势补在队首。先花劲走近，后面的退势按净步一起算，不会先退开再补。
2. 净零的对消不删段，退势改成同等步数的进势，原来的段数还在。不够再往队首加。
3. 加码是多 1 段，不改伤、不改血。人已经在射程里，距离不再缩短也不加。
4. 补进势放在 `planFromFirst` 还原站位之后。规划时为了预演往前走的那几步，不拿来当真实距离。
