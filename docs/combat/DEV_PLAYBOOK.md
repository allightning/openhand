> **日期：** 2026-09-05  
> **对象：** 开发者（你自己）  
> **目的：** 开工前必须知道「这游戏到底怎么玩」，否则改代码会改错方向。  
> **范围：** 现行玩法（不含爆点包/墨痕/招路图等未实装内容）。

## 一、这游戏是什么（一句话）

**七格石台上的公开意图拆招卡牌**：敌人下一回合要打哪几段、打哪格、多重，全亮给你看；你用手牌（位移/攻击/反架/格挡等）在收势前布置，收势后按队列逐段结算，拆对了免伤+得势+战利品，拆错了挨打。

---

## 二、两种模式（门厅二分）

| 模式 | 一句话 | 现在能玩什么 | 定位 |
|------|--------|--------------|------|
| **踢馆** | 肉鸽爬塔；不破也能爬，破招是上限 | 剧情十馆 · 无尽打榜 · 低阶入门 | 主产品路径（热闹、肉鸽、彩金） |
| **读招** | 硬核短拍谜题；拆错/挨打即败，不靠砍血 | 读招战役试玩（五关）· 新手关/训练馆预习 | 硬核试验区（对照实验、深度） |

**开发者注意：** 两种模式共用同一套战斗核（`sim.ts` / `simV2Hooks.ts` / `intentWeakness.ts`），但胜负条件、锁牌、结算口径不同。改规则前先确认影响哪个模式。

## 三、战斗骨架（七格石台）

### 3.1 场地

- **7 格直线石台**（`BOARD_SIZE = 7`）
- 你与敌各占一格；**面向**决定威胁方向（身前 vs 身后）
- **兵刃距离**：拳 1 / 刀剑钩 2 / 枪棍 3；红格与命中只算身前
- **站位**决定打不打得到、躲不躲得开

### 3.2 回合结构

```
玩家回合（你出牌）→ 收势（主动结束）→ 敌回合（按队列逐段结算）→ 回到玩家回合
```

- **手牌**：上限默认 5、硬顶 10；收势摸 ⌈上限/2⌉
- **劲力**：上限 6 / 开局 5 / 回 3；出牌耗劲
- **敌方队列**：全段亮出；一整回合锁死兑完；不中途补招；播报完才亮下一手
- **收势常亮**：玩家回合任何时刻可点（唯一主动结束回合方式）

### 3.3 敌意图条（核心）

敌人下一回合的每一段招，全亮公开：

| 信息 | 说明 |
|------|------|
| 段序 | 第 1 段、第 2 段…按序结算 |
| 类型 | 打击 / 抢步 / 连打 / 卸力 / 冲锋 / 落桩 / 拉 / 撤 / 闪避 / 霸体 等 |
| 伤害/效果 | 数字或效果描述 |
| 落点/红格 | 打哪几格（威胁范围） |
| 破法 | 怎么拆（位移离格 / 反架 / 不出攻 / 格挡吃满 等） |

**开发者注意：** 意图条是「读招」的核心 UI；改意图呈现前先看 `labV2Ui.ts` `renderFoeIntentStrip`。

## 四、拆招四档（玩家视角）

敌回合结算前，`planBreaks` 对队列每一段打标签：

| 档位 | 代码 | 伤害 | 算破招计数 | 得势 | 典型场景 |
|------|------|------|------------|------|----------|
| **硬拆·破** | `hard` | 全免 | ✓ | +1 势 | 位移离格且耗位移充能；或反架类硬破 |
| **硬拆·追** | `hard`（撤段） | 他仍撤 | ✓ | +1 势 | 打出朝他位移且更近，耗 1 位移充能 |
| **软拆·让** | `graze` | 减半后仍结算 | ✗ | ✗ | 离格但无位移充能；或连打格挡≥8 |
| **打空** | （无 tier） | 0（段落空） | ✗ | ✗ | 开局就不在红格/够不着 |
| **放** | （无 tier，撤段） | 他照撤 | ✗ | ✗ | 没追撤段 |
| **照打** | （无 tier） | 全额 | ✗ | ✗ | 还在红圈里，或没满足任何破法 |

**开发者注意：** 「退步躲了伤但没拆」多数是——打空（本来不在红格）、让（离格但无充能）、照打（仍在红格）。红格跟敌兵刃/抢步投影走，不是「当前脚下」。

## 五、破法表（按意图种类）

每种敌意图有默认弱点（`DEFAULT_WEAKNESS`），可被敌人定义覆盖。

| 敌意图 | 破法类型 | 硬拆条件 | 软拆/其他 |
|--------|----------|----------|-----------|
| **打击** strike | 空间·位移 | 打位移牌 + 收势离红格 + 耗 1 位移充能 | 离格无充能 → 让 |
| **抢步** lunge | 空间·离格 | 同上 | 同上 |
| **连打** barrage | 格挡 | — | 收势格挡≥8 → 让（半效） |
| **卸力** guard | 反架 | 打破绽/刺/点穴/开缝 + 耗 1 反架充能 | 无充能 → 不破 |
| **冲锋** charge | 桩 / 进步 | 场上有桩，朝他进步且收势离开落点 | 横移离开落点但没进步 → 让 |
| **落桩** stake | 破桩 | 砸挡路的桩（攻击消耗其挡次） | 低阶挡 1 次、高阶挡 2 次 |
| **拉** pull | 贴身攻 | 贴身攻击命中 | |
| **撤** retreat | 追 | 朝他位移且收势更近，耗 1 位移充能 | 动了但没更近 → 让；没追 → 放 |
| **闪避** dodge | 不出攻或位移 | 本回合不出攻击，或打出位移 | 结算后你下一张攻击牌卡面伤落空 |
| **霸体** endure | 反架 | 打破绽/刺/点穴/开缝 + 耗 1 反架充能 | 结算后你下一张攻击仍打伤，但不吃击退/拉/眩晕 |

**充能牌分类：**
- **位移充能牌**：`sidestep, retreat, advance, advance2, close, backpalm, push, push2, sweep`
- **追牌**（朝他）：`advance, advance2, close`
- **反架充能牌**：`expose, pierce, rift, marking`
- **落桩充能牌**：`plant, split`（立桩仍是棍的工作）

每打一张对应牌 +1 充能；硬拆耗 1，多段按队列顺序扣。

## 六、硬拆奖励（`applyBreak`）

硬拆一段时依次：

1. **+1 势**（`addQi`）
2. **拆势 +1**（上限 3）：下一张攻击牌吃掉 1 层，兑现真伤 `BREAK_COUNTER_BASE(2) + 兵器品阶`，并附加场上兵器系效果（刀裂创 / 拳击退 / 剑破绽 / 枪远打 / 棍眩晕 / 钩缴械）
3. **连环拆**：同回合第 2 段起硬拆，拆势真伤池 +2，额外 +1 势
4. **战利品**（立刻落账，`breakLootFor`）：

| 破法路径 | 战利品 |
|----------|--------|
| 空间（打击/抢步） | 格挡 +4「让中带架」 |
| 追（撤） | 抽 1 + 下张攻击贴身 +2「追上」 |
| 反架（卸力） | 曝光 +2「看穿套路」 |
| 格挡吃满（刀创） | 回血 +3「铁扛回气」 |
| 桩类 | 劲力 +2「借势回劲」 |

5. **应激**：`tryAppendStressIntent(b, "break")` → 下回合敌规划时追加应激段

软拆（让）只记 `v2GrazedSegments`，**无**势、无真伤、无战利品、无应激。

## 七、招眼（Eye）

- **定义**：队列中**第一个**「可硬拆的攻击段」，且弱点属于位移或反架（`planEyeIdx`）
- **破眼**：硬拆到眼所在段 → **套路全崩**（后续段直接散掉不结算）+：
  - 失衡 2 回合（承伤 ×2，`OFFBALANCE_MULT`）
  - +2 势
  - 拆眼加力 6 并入拆势池（打出时才扣血）
- 软拆眼段 **不能** 破眼

## 八、踢馆模式（肉鸽爬塔）

### 8.1 开局流程

1. **开踢** — 门厅「踢馆」栏
2. **选线** — 少林 / 江湖 / 朝廷（各 10 馆）
3. **选系** — 拳 / 棍 / 刀 / 剑 / 枪 / 钩
4. **庄家垫资** — 仅首馆：彩金 ×2 或 ×3
5. **下注** — 可「不押 · 直接打」
6. **战斗** — 七步石台；赢后营地奖励 / 黑市 → 馆间遭遇 → 下一馆

### 8.2 馆序阶梯

| 馆 | 难度 | 特点 |
|----|------|------|
| 1–2 | easy | 入门：看红格、走开或卸力；`stressCap: 0` |
| 3–6 | mid | 格挡能扛一段；应激开始出现 |
| 7–9 | hard | 轮番替补；敌套路更复杂 |
| 10 | extreme | Boss；终局对决 |

### 8.3 经济

- **彩金**：踢馆货币；过馆底彩、下注、黑市、榜单
- **下注**：开打前托管注额；赢注返还 `注额×赔率`；输馆有注则无底彩 + 剩余 10% 出血
- **黑市**：花彩金买货；价只跟馆序/底彩；可花钱刷新；通常每摊最多买 4 件
- **赊账**：整局 1 次；付复活费 + 救命奖励 → 重打本馆

### 8.4 营地与遭遇

- **营地免费奖励**：谱 / 外功 / 心法 / 道具等
- **同道**：馆 3 / 7 四具名必选一人（伸手 / 点到 / 买命等）
- **遭遇**：馆间短战，不占脊骨馆号（如 5-1）；加黑的整句是机制提示

## 九、读招模式（硬核谜题）

### 9.1 定位

- **硬核短拍谜题**：拆错/挨打即败，不靠砍血
- **对照实验 + 第二试验区**：先在这里试新空间、新拆路、新博弈
- **爬塔弱跟随**：用试验区验证过的规则之「薄发行版」

### 9.2 现在能玩什么

- **读招战役试玩**（五关：收势即判，拆错/挨打即败）
- **新手关/训练馆预习**
- **周挑战**（即将开放）

### 9.3 与踢馆的区别

| 项 | 踢馆 | 读招 |
|----|------|------|
| 胜负 | 砍血 + 存活 | 拆错/挨打即败 |
| 锁牌 | 自由构筑 | 锁牌或极窄牌池 |
| 结算 | 存活与彩金为主 | 拆质量为主（硬拆数、受击、用时） |
| 难度 | 可不破也能爬 | 必须拆对 |

## 十、开发者必知（改代码前）

### 10.1 入口与命令

- **入口**：`combat-lab.html` · `npm run lab`（5175）
- **测试**：`npm run test:combat`（不是 `npm test`）
- **规则真相**：`docs/combat/RULES.md`
- **上架路线**：`docs/combat/LAUNCH_ROADMAP.md`

### 10.2 冻结范围

- **只做 Combat Lab**：`docs/combat/**`、`src/combatLab/**`、战斗核 `src/game/`（sim、labV2、intentWeakness、content 战斗数据）
- **冻结**：`src/map/**`、`src/main.ts`、`src/story/**`、`docs/frozen/**`

### 10.3 关键文件

| 文件 | 职责 |
|------|------|
| `src/game/sim.ts` | 战斗核：出牌、收势、结算 |
| `src/game/simV2Hooks.ts` | V2 钩子：拆招、应激、招眼 |
| `src/game/intentWeakness.ts` | 破法表：意图 → 弱点 |

### 10.4 测试基线

- **乱点基线**：`labMashBaseline.ts` 可测「乱点胜率」；W1-D 用「馆 1 乱点胜率 ≤35%」作硬指标
- **test:combat 绿是底线**，不是体验验收

### 10.5 用户铁律（近期）

1. **手测由用户做**——agent 不开浏览器；`npm run test:combat` 过即交付
2. 选定方向后只做该方向，禁止反复对比已否决方案
3. 未明确要求不要 commit / push
4. 玩家刀 **10/4**（贴身叠 2 裂创，不是 12 秒杀）；敌刀平砍是敌表
5. 出血税 **10%**（否决 25%）。玩家可见用语尽量不挂「破招」；代码 id 可后置
6. **未主动开口前，不改战斗立绘尺寸（168）**。局内不加新水墨框。石台可变宽。没有 `#preview-slot` 预演条；招眼条是敌意图带
