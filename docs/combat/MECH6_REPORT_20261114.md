## 落了什么

### 一敌多谱

变体表在 `src/game/content/foeVariants.ts`。三套：`brute-press`（莽）、`turtle-shell`（龟）、`skirmish-lane`（游走）。精英或座前的每个敌 id 都带这三套，id 写成 `敌id:谱名`。配招种子仍是大轮、敌 id、盐，同轮同敌同盐抽到同一套。

馆 1–3 的杂兵不进变体，仍按馆段在莽夫和乌龟里抽。馆 4 以后的杂兵也还是原来的原型池，变体只给精英和座前。

抽中的 id 写在 `foeVariant`。情报购买结算没动。壳层和风声要读这个字段，才能说出他这局带的哪套。

### 血线换势

`CLIMB_STANCE_SHIFT_HP` = 0.5，黄。敌血从这条线以上第一次掉到线以下，当前意图队列作废，按新谱重排，架势条当场重算。每个敌 id 一场只换一次。再掉、或者血回去再掉，都不换第二次。

变体上写了 `shiftTo` 就用那个。没写就走对照表：莽留莽，龟改莽，游走改莽，刺客留刺客，教头留教头。留在本谱的不播报、不重排。

播报键是 `foeStanceShift`，后面带血线百分比和从哪谱到哪谱。句子由剧情窗补。换完之后，敌窗概率按新原型算。

## 创新思路

1. 变体是三行数据加敌 id 前缀，不给每个敌人各写一套牌。谱的差别在原型池，不在新的伤数字。
2. 配招仍只用 `foeKitSeed`，不抽战斗随机。换势重排用另一颗固定盐，避免把后面的随机序带歪。
3. 不换的谱直接返回。一次旗标只在真正换了队列之后才记下，莽夫跌破血线不会把「已经换过」占掉。
4. 架势条沿用 `publishStance`。队列换了，构成就跟着变，不另做一条架势算法。
