# 剧情三班 · 接到路上 · 2026-11-02

39 条事页仍在 `storyBeats.ts`。这一班把点名的 19 条挂到 `climbPlaces` 的程号上。江湖线打完一程、离开营地时，`queuePostCampBeat` 按**下一场的程号**从该落脚的节点里抽一条还没亮过的。少林、官道用同一张程号表，这两条线的离营不走江湖事页。

第一程的落脚没有节点。进第一场之前不会因为这些页打开赌馆。同程有多条时，一局只亮一条，其余留到下一局。选完一页，页旗清掉；亮过的记在 `s3seen:`，同局不重复。

## 创新思路

1. **节点挂在落脚，不挂在随机日程。** 程号是表。一局在这一程抽一条没亮过的，抽不到就回到原来的赶路。赌馆仍只从选项上的「再押」进来。
2. **第 3 程不跟别的页抢。** 职业三选一单独占这一程，拒绝留在页内，不另做一扇门。
3. **亮过记在旗上，不写进花名册。** `s3seen:` 只表示这页本局亮过。选事页不会把开局那个人记成已经见过。
