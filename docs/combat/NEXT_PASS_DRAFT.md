## 1. 待你点头的两处（草案默认值）

### 1.1 输注「亏出血」——不要清零

你要惩罚重：扣注额 + 扣本馆底彩 + 动没赌的钱。  
若**没赌的钱全没收**，「铤而走险还攒到第 10 馆全包两轮」做不到。

**草案默认：**

1. 开打前**先扣注额**（本金托管，界面写清）。
2. 赢：返还 `注额 × 赔率`（×2 = 净赚一倍注额）。
3. **馆输了**（有注）：注额已扣不退；**本馆底彩不发**；对剩余彩金抽 **10%** 出血税（四舍五入，至少 1）。赢馆但注条件没中：只丢注额，仍发底彩，不抽税。
4. 复活赛：无注、无底彩奖惩（只重打）。

### 1.2 「钱越攒货越贵」

根因是黑市 **彩金 ×14% 地板**。  
**草案：拿掉跟池地板。货架价只跟馆序梯度走。** 刷新费也只跟梯度 + 本摊第几次走。  
暴富靠赌和破招高倍；消耗靠刷新递增加价、卖出半价、输注出血。钱躺着不再受罚。

## 2. 经济目标（用目标锁价，不先锁死每一件的整数）

`B(馆) = 10 + 6×馆`（现行底彩，可沿用）。

| 玩家行为 | 这一馆进账（约） | 黑市购买力 |
|---|---|---|
| 全程不下注 | 只拿 `B` | **刚好 1 件最便宜的**（金创/小货） |
| 能稳定吃到 ×2 档 | 托管后净赚约 `注额 + B` | **至少 2 件** |
| 吃到最高倍（破眼/高难盘） | 净赚更高 | **能一次买下本摊 3 件** |
| 高倍 + 还攒 | 滚到馆 10 | **至少 8 件 = 两摊全包**（馆 10 不限购，可超过 8） |

注额仍用现行馆序帽（30/50/70 → 120 起 → 7 后 +100），再 `min(池, 帽)`。垫资仍仅馆 1、×2/×3。

**赔率（下调破招盘，中档保持「冒险有肉」）：**

| 盘 | 现 | 草案 |
|---|---|---|
| 完璧 / 堆挡 / 本系刀 | 1.5 | **1.5**（结算改为先扣本，实际比现在瘦） |
| 速胜 / 血战 / 赤手 | 2 / 3 / 3 | **2** |
| 不贴身 / 多敌 / 换人等情境盘 | 3 | **2.5**（仅当这一馆确实难才开） |
| 连破注（原连拆） | 4 | **2.5**，馆 3+ |
| 破眼注 | 5 | **3**，馆 5+ |

盘口**跟本队 + 本馆敌人**滚，开三不随机瞎开：枪队少开「不贴身」；挡高的敌少开堆挡；多人轮番可开「换人/集火」；有助战才开赤手。高难盘赔高，但输按 §1.1 出血。

## 3. 黑市价与刷新

**价：** 只跟馆序带（1–3 / 4–7 / 8–10），带内缓涨，过 3、过 7 跳。对齐 §2：最便宜 ≈ `B`；中件 ≈ `0.7×(帽内典型×2净赚)/2`；三件包 ≈ 高倍净赚。

粗锚（开工用测试锁，允许 ±15%）：

- 最便宜（金创/小货）≈ `0.9 B`
- 谱 ≈ `1.1 B`
- 外功 ≈ `1.4 B`
- 淬刃 ≈ `1.8 B`（未开门的馆不出）

馆 10：价仍按 8–10 带，**件数不限**。

**刷新：** 消耗彩金的主通道。

- 基础费跟梯度走（大约半件最便宜货）。
- **同一摊每刷一次，下次 ×1.35**（示例：8 → 11 → 15…），离开营地重置。
- 刷新重滚货架，已买槽仍记买过（或整摊重滚并清空「已买」——开工时默认：**整摊重滚，已买记录清空，但涨价照算**，避免又刷又占便宜）。

**卖出：** 牌库/道具多出来的，按**该种类当前货架价的一半**卖回池。没钱时的抗风险。消耗品无持有下限。

## 4. 配装（大改，但是你要的成长出口）

### 4.1 每人一套

主角和每位同道：**兵刃、出战牌包、小道具、助战符**分开。换人换包。光环卡/组合卡进**该同道自己的包**，不塞进主角。

营地（领奖/黑市/选同道）常驻小队条：谁、什么兵器、牌 **n/上限**、道具/助战几件。点开进配装。

**出战校验：** 上场者牌包张数在该阶段上下限内，才能点开打。其余人的包只在换上时校验（或换人时若不合规禁止换上——默认：**换上前也要合法**）。

### 4.2 阶段（按「即将打的馆」）

| 即将打的馆 | 出战牌 | 助战 | 小道具（种类） |
|---|---|---|---|
| 1–2（过 3 前） | **8～10** | 最多 1 | 最多 1 |
| 3–7 | **10～12** | 最多 2 | 最多 2 |
| 8–10 | **12～15** | 最多 3 | 最多 3 |

下限防极端空手；上限强迫选。消耗品颗数不设下限。馆 10 黑市不限购，但**上场仍受 12～15 / 助战 3 / 道具 3**——多的卖掉或留在包外仓库。

仓库：奖励和黑市先入「拥有」；配装决定带哪些。卖的是仓库或卸下的。

### 4.3 满状态开战

`startLabBattle`：气血满、劲满、势/挡按规则清（与现收势一致）。道具**次数不回满**（带几颗是几颗）。复活赛同样满状态、无注。

## 5. 破招（原拆招）

- 对外名称：**破招 / 连破 / 破眼 / 破势**（原拆势）。
- 再削当场战利品（空间破 +4 挡、追抽 1 等），避免不破就缺资源。
- **保留**角色技能、部分牌、赌馆连破/破眼盘——作为上限，不是过馆门槛。
- 正式条仍可只标打/空/跳过；**高阶教学和训练馆**把破招讲透。战场对老手可用可选「破招提示」开关（默认关，避免新手噪声）。此项可开工时再定，不挡经济。

## 6. 教学与训练馆

### 6.1 新手关拆成两档

**低阶（必做，不进破招）：** 石台与距离、出牌与劲、收势、营地领奖与黑市、下注与底彩（含输注会出血）、配装上下限、换人预告（若有）。迷你闭环：打 → 奖 → 配装 → 买/卖 → 再打。

**高阶（可后做，专教破招）：** 位移充能、硬破与破势、让、追、破架、破眼、连破。明确：正式开踢不破也能过，破了多赚。

门厅：低阶毕业才能正式开踢；高阶标「进阶」。

### 6.2 训练馆加深（仍不走彩金）

现有破招课太浅。每课维持 ①引导 ②自由，但 ②要有失败条件和「这一招为什么破/没破」。

**加柜（非破招）：** 经济与黑市刷新、配装与卖卡、多敌轮番、多同道换人、六系距离（加深现兵器课）、下注盘口怎么读。

破招柜：现 hard/charges/graze/rift/eye/chase/chain 加长，加「门票不够怎么办」「眼在第二段」。
