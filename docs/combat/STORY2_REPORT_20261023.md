## 三条最好的实例

### 1. 沈夜行：把花名册里的「缝」写成能看见的墙，不抄禁字

花名册原句是「夜里刀短，袖里却长。巡的是缝，不是灯。」「却」「不是」不能进事页。

改后遇人：

> 夜巡的灯灭了一排，沈夜行的刀比袖口短一截，刀尖对着墙上一道缝。缝里卡着半张路条，字被潮气浸软。

同路后还是这道缝，纸又卡进去，靴印叠在一起。留下才看到第二页。页上没有「伙伴」两个字。

### 2. 傅壁山：称号是扶壁，场面是肩印

原句「推人撞壁，壁养一队」如果写成「他推人，是为了救人」，就是反转句。

改后：

> 济南药铺外的墙上有新的肩印，傅壁山把一个人推得肩撞上墙，墙把那人弹回半步。他这才伸手去扶，手扶在肋上。

先看见墙和肩印，再看见手。删掉后半句，肩印还在。

### 3. 炭格边的粥棚：一个选项页走出三条下一程

同一段烟、同一只勺。

- 扶进棚里：下一页是周暖香在路上先看挡，赌馆不开。
- 接过条子：进赌馆，单注最高当前彩金 80%，她把勺扣回锅上。
- 把讨债的影子引出烟：下一程多 X 人，这一摊黑市关着。

人、赌馆、敌和黑市都变了。词条 `envtag:burn` 记在旗标上，结算仍不接。

## 创新思路

1. **同路后不是第二张入队卡。** 遇人的「留下」直接打开同路后。玩家看见的是下一步还在做同一件事（缝、肋、空地），不是一张写着职能的按钮。
2. **口气用习惯，不用履历。** 每人只重复花名册里已经有的一个动作，换到路上再做一次。不给新的童年、师门、仇人姓名。
3. **禁字不进正文，意思留下。** 「巡的是缝，不是灯」写成刀尖对着墙缝。机器守卫扫的是字，玩家读到的是事。
4. **成套是同一件器物的前后。** 赌馆四条是同一只扣着的盅：手还没碰、盅开了、注飞了、手离开。黑市三条是同一条帘缝。复活赛两条是躺下和重新站到空地，重打前盅已经收进袖里，所以禁注看得见。
5. **分叉只加一页。** 不另起三套小说。三个选项各自指向已有的同路后、赌馆或「多 X 人 / 黑市关」，下一程的种类立刻不同。
