# 拆招回报改案 · 下次攻击强化（草案）

> 状态：**已落地**  
> 日期：2026-08-28

硬拆成功 = 一层「拆势」。玩家打出下一张攻击牌时才结算真伤与六系附加。让不给拆势。破眼仍崩招+失衡，加力并入拆势池。道具按颗数：一次给 2 颗，用一少一，局内不限次数。

---

## 1. 现在哪里不对

现行：硬拆成功 → **立刻**对敌人扣 `2+品阶` 真伤（无视架势）+ 得势。

玩家读到的问题：

1. **看不见刀从哪来**：人刚撤步，血自己掉了。  
2. **状态栏像 Buff**：写成「真伤 5」，以为下一刀也加 5。其实已经打完。  
3. **和兵器无关**：刀拳枪棍钩拆完都是同一刀数字，六系没有拆招个性。  
4. **和「走开」打架**：空间拆的体感是后退，立刻扣血像隔空打人。

当场真伤作为「以拆为杀」能打死人，但**反馈和兵器适配都弱**。

---

## 2. 改法（建议）

**硬拆成功 ≠ 当场扣血。**  
硬拆成功 = **给你一层「拆势」：下一次攻击带强化，打出时才结算。**

```
看招 → 走开/破架（硬拆）→ 获得拆势 → 你自己出攻击牌 → 打出强化
```

拆和打仍是两步，但第二步是**玩家出牌**，不是系统偷砍。

### 2.1 通用层（所有兵器都有）

| 项 | 规则 |
|----|------|
| 触发 | 硬拆一段 → 叠 1 层拆势（上限 2～3，待测） |
| 消耗 | 打出**下一张攻击牌**时吃掉 1 层 |
| 保底 | 吃层时这次攻击 **部分伤害变真伤**（或额外真伤），数字仍跟品阶走 |
| 过期 | 收势仍在则保留到下回合第一击；或本回合不用就散（二选一，建议**保留到下回合第一击**，避免拆完没牌打） |
| 让 | 不给拆势 |
| 破眼 | 另算：后招散 + 失衡；拆势仍给（眼是硬拆） |

### 2.2 六系个性（吃掉拆势时附加）

打出那一击时，按**场上兵器**加一条，不另开系统：

| 兵器 | 拆势打出时 |
|------|------------|
| **刀** | 额外真伤偏高 / 贴身再叠裂创 |
| **拳** | 击退 1 或撞壁认人 |
| **剑** | 破绽 +1 或点穴 |
| **枪** | 远距不衰减；或锁步（下段难贴你） |
| **棍** | 眩晕 1 段（控制） |
| **钩** | 缴械 1 段 |

原则：每系 **一条**，能在攻击结算里看见（日志：「拆势·棍 眩晕」），不要堆词条。

### 2.3 充能还干什么

不变：充能仍是硬拆门票。  
变的是硬拆的**奖品**：从「当场真伤」改成「拆势」。

连环拆（同回合第 2 段）：再叠一层拆势，或打出时真伤 +2。不要又当场扣血。

---

## 3. 反馈怎么做（不要当状态栏词条）

拆成功时三件事同时发生，短、响、一次说完：

1. **意图段**：角标「破」已有。  
2. **棋盘**：你角色旁闪一下「拆势」印章（不是扣血数字）。  
3. **手牌**：下一张攻击牌描边 / 角标「拆势·棍」——打之前就知道这刀带什么。

打出后印章消失，日志一行：`拆势打出 · 真伤 3 · 眩晕`。

不要：「真伤 5」挂在敌我状态栏里像 Buff。那是上一刀的收据。

---

## 4. 和现有模块怎么接

| 现有 | 改后 |
|------|------|
| `counterHitFoe` 当场扣血 | 改为 `grantBreakMomentum(b)` 叠层 |
| 状态栏 `v2LastTrueDamage` | 删，或只在打出那一帧飘字 |
| 势 `qi` | 可保留硬拆 +1 势（资源），与拆势分开：势是爆，拆势是下一击 |
| 战利品（挡/破绽/回血） | 可留，但不要和拆势抢同一条 UI |
| 新手关① | 硬拆后教：看手牌「斩」带拆势 → 进步 → 打出 |

---

## 5. 风险

- **拆完没攻击牌**：必须允许拆势跨过收势，否则空间拆（先撤）会空窗。  
- **打死人变慢**：当场真伤能拆死；改后要再出一张攻。速胜注、馆主血量要复测。  
- **棍控 / 钩缴械** 可能过强：拆势一层只触发 1 段控制，不叠。

---

## 6. 建议落地顺序

1. 先做**通用拆势 + 手牌描边 + 打出真伤**（六系都一样）。  
2. 新手关①文案改成「拆完强化下一刀」。  
3. 再按刀拳 → 剑枪 → 棍钩加个性。

未拍板前不改数值代码。
