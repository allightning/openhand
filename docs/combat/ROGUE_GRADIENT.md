## 1. 产品口径

- **18 人**：6 主角（开局选系=选人）+ 6 二档（3 馆）+ 6 三档（7 馆）。**单系，无双武器。**
- 全队 **3 坑**（场上 1 + 后场 2）。
- **同系**：弱光环 + **1 张光环状态卡**（偏副机制）。
- **异系**：**2 张组合状态卡**（主融合 + 副融合），可偏强，作为不满光环的补偿。
- **删除**：组合技开闸、通用 `qi` 绝招货币、双武器学牌、换人塞下场者随机牌、枪「适配进化树」。
- 牌只分四类：**攻击 / 防御 / 位移 / 状态**。位移 **±2 是新牌，不替代 ±1**。
- 枪 = **大 C**；拳 = **辅/奶**（伤与棍同列最低档）。

## 3. 拆招兑现

| 事件 | 牌 | 效果 |
|------|----|------|
| 硬拆 → 拆势 | 通用攻击 | **真伤** |
| 硬拆 → 拆势 | 本系攻击 | **副机制特效**（真伤很少） |
| 让 → 让势 | 本系防御 | 本系防特效打满 |
| 让 | 通用卸力 | 只挡 |

主机制：**不依赖拆招也能用**，拆招只放大。副机制：绑拆招特效。绝招是 **7 馆后单独奖励牌**，启动条件只看本系主/副资源。

## 4. 手牌上限

| 规则 | 值 |
|------|-----|
| 默认 / 硬顶 | 5 / **10** |
| 开局发牌 | = 上限 |
| 收势回补 | **⌈上限/2⌉**（5→3，7→4，10→5），**不再**补满 5 |
| 回合结束留存 | 必须 **≤ 上限**（多的弃） |
| 回合中 | 允许暂时超过上限 |
| 谁改上限 | 心法；角色技能有条件 +1 |

**UI 常驻：** `手牌 n/上限 · 收势摸 k`；超上限时高亮须弃。

现行「弃 1 摸 1、次数 = 开局手牌一半」仍可保留，与「收势弃到上限」是两件事。

## 5. 四类牌

| 类 | 起手 | 奖励 |
|----|------|------|
| 攻击 | 通用直取 1 + 本系主攻 1 | 副攻 2、绝招 |
| 防御 | 通用卸力 1 + 本系防 1 | 本系防换页 |
| 位移 | 进步、撤步（±1）**永久保留** | **纵步/大撤 ±2 另增**；换页只加效果（如回马伤） |
| 状态 | 回血 1、回劲 1 | 光环卡、组合卡、绝招启动器 |

前期好上手：起手约 8 张。光环/组合/±2/绝招晚出现。

## 6. 光环与组合卡

**同系人数**只看主武器。2 人半层（更弱），3 人满层。被动光环砍薄（副机制微加），强度主要在 **光环状态卡**。

**异系：** 队伍出现第二个不同主系后，卡组 **+主融合 +副融合**。每回合开始随机把其中 1 张入手。可带伤害，结算路径不得做成「两系攻击牌粘贴」。第三人再异系时，融合对以「场上系 × 主要异系」为准，卡组融合牌最多 4 张。

## 7. 六系

伤档（未换页、无拆势）：**枪 / 刀 / 剑 > 钩中下 > 拳 = 棍最低**。

### 刀 · 贴身爆 + 流血

- 距 2。贴身主攻高伤。
- 流血 n 层每回合结束扣 **2n−1**（1→1，2→3，3→5），帽 4。
- 硬拆本系攻 → +1 流血。让→防：反击流血。
- 绝招：流血 ≥3，「血祭」立刻跳一次并 −1 层。

### 拳 · 辅奶 + 连击

- 距 1。主攻最低档；**撞壁**才有可观伤。
- 连击：本回合第 2 张起攻击 → 治疗或给挡。
- 让→防：反击击退（给枪让出距离）。
- 绝招：连击 ≥3 且敌距壁 ≤1。

### 剑 · 破绽 + 连势

- 距 2。
- **破绽**：状态，持续 2 回合；攻击 **40% 穿盾**。再挂 = 刷新持续，层数不叠。
- **连势**（剑私有）：1 层下次 +2，2 层 +4（2n）。打出攻击吃掉一半层。
- 绝招：连势 ≥4 且目标有破绽。

### 枪 · 远 C + 标尺（副机制，不是适配树）

- **1 格打不出**。2/3/4 格可打，伤正比：草案 4 / 7 / 10。
- **标尺**：枪攻 2 格 +1、3 格 +2、4 格 +3；**被贴身清零**；帽 6。硬拆离格 **+2 标尺**。
- 副两张：① 蓄尺（下次按 +1 格距结算）② 寸截（只打 2 格，不清尺）。
- 本系防让满：击退 1。
- 绝招「苍龙出海」：标尺 ≥4 且敌在 3 或 4 格。
- 撤步换页可带回马效果，**仍是 ±1 位移**，不占副机制槽。

### 棍 · 龟控

- 距 3。伤与拳同低。桩占格、拆冲锋、有桩减伤。眩晕吃拆势才给。
- 绝招：≥2 桩且本回合硬拆过。

### 钩 · 缴械拉距 + 吸血

- 距 2。**距 ≤2 才能缴械**：敌攻击 ×0.2，持续 **2 回合**。
- 吸血：成伤 20% 回血。
- 绝招：目标已缴械。
