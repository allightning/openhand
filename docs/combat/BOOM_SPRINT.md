## S1 · 爆点包节拍表 + 四档视听身份证

**目标：** 破/让/空/打 各有独立感官身份；硬拆有高潮包；可剪 15 秒。

### S1.1 四档事件表（最终版）

| 档 | 屏幕字 | 字号/时长 | 立绘/石台 | SFX | 额外 |
|----|--------|-----------|-----------|-----|------|
| **破**（含追） | 「破」或「追」 | 最大号 · 900–1200ms | 敌格 `board-anim-break` + 刀光 `slash_arc` | 专用高亮音（暂用 clash 满音量+更高一层，或新 `break.mp3`） | 拆势/战利品跳字同窗或 +150ms；可选 80ms 全局微闪 |
| **让** | 「让」+ 半伤数字 | 中号 · 700ms | `board-anim-graze` | 钝击（clash 降调/降量） | 必须显示最终承伤 |
| **空** | 「空」 | 小号 · 500ms | 敌挥空/你侧无受击 | drop 或更轻 | 首次本局副标「未挨·不算拆」 |
| **打** | 「打」+ 伤害数字 | 中号偏警告 · 700ms | 你受击动画 | 明确受伤音 | 单条失败主因 ≤16 字 |

### S1.2 硬拆高潮包时序

```
0ms     段高亮「正在兑」+ 起手挥砍音
120ms   大号「破」弹出 + 刀光挂敌格立绘
120ms   破专用 SFX（满）
200ms   拆势/真伤/掉落跳字
…持有到 ~1000ms
然后    下一段或收束
```

### S1.3 工程落点

| 文件 | 改什么 |
|------|--------|
| `main.ts` | 撕掉 `climbBreakLight` 对破/追的压制；破路径强制走高潮包 |
| `lab.css` | `.lab-fx-break` 加大、加持有；四档色/字/时长分档 |
| `labAudio.ts` | 四档 SFX 映射拆开（即便暂共用文件也要不同音量/播放策略） |
| `labV2Ui.ts` | 段上档位徽标与高潮包联动 |

### S1.4 测试

- `labAudio.test.ts`：破路径不再 light；四档 SFX 映射独立  
- `labHitFeedback.test.ts`：破/让/空/打 各有独立 class 与文案  
- 手测：闭眼听 4 次能猜对档 ≥3；可录 15 秒镜头

### S1.5 验收

- [ ] 四档视听身份证独立  
- [ ] 硬拆高潮包时序 ≤1.2s  
- [ ] 可录 15 秒镜头（亮红 → 应对 → 大破 → 短字）  
- [ ] `npm run test:combat` 绿

## S2 · β 墨痕 v0（硬拆留痕，上限 2）

**目标：** 石台有记忆；下轮踩痕好拆；外行能感知「台子脏了」。

### S2.1 规则

| 项 | 规格 |
|----|------|
| 触发 | 硬拆成功在威胁格留墨痕 |
| 上限 | 同时最多 2 痕；新痕顶旧痕 |
| 效果 | 下轮意图踩痕：被克（易拆/降伤）——先只做「被克」，不做「激怒」 |
| 持续 | 1–2 轮后消退 |
| UI | 淡墨渍，不挡红格；悬停一句「此格有墨，下轮好拆」 |

### S2.2 工程落点

| 文件 | 改什么 |
|------|--------|
| `sim.ts` / `simV2Hooks.ts` | 硬拆成功时写 `inkMarks: { cell, ttl }[]`；结算时检查踩痕 |
| `types.ts` | `Battle` 加 `inkMarks` 字段 |
| `labV2Ui.ts` / `prodBattleUi.ts` | 石台格渲染墨渍；悬停提示 |
| `lab.css` | 墨渍样式（淡墨，不挡红格） |

### S2.3 测试

- `sim.test.ts`：硬拆留痕；上限 2；新痕顶旧痕；踩痕被克  
- `labHitFeedback.test.ts`：墨渍渲染；悬停提示  
- 手测：外行能指出「台子脏了」；内行能利用痕迹

### S2.4 验收

- [ ] 硬拆留痕，上限 2  
- [ ] 下轮踩痕被克（易拆/降伤）  
- [ ] 外行能感知「台子脏了」  
- [ ] `npm run test:combat` 绿

## S3 · 爬塔前 1–2 小时热闹密度

**目标：** 每场至少一次大破；乱点会疼但不靠门闩；外行觉得热闹。

### S3.1 热闹密度指标

| 指标 | 目标 |
|------|------|
| 每场大破次数 | ≥1（馆 1–3） |
| 乱点胜率（馆 1） | ≤35%（先跑基线） |
| 外行「觉得热闹」 | 2 人中 ≥1 人 |

### S3.2 手段（不靠门闩）

| 手段 | 做法 |
|------|------|
| 数值 | 馆 1 `dmgCoef` 上调到乱点疼；保留 `stressCap: 0` |
| 引导 | 开局锁牌引导必出位移/反架；不强制硬拆 |
| 镜头 | 每场至少一次大破（S1 高潮包） |
| 文案 | 「前两馆先学会拆；之后不破也能爬」 |

### S3.3 工程落点

| 文件 | 改什么 |
|------|--------|
| `gauntletPaths.ts` | 馆 1 `dmgCoef` / 段结构上调 |
| `autoLoadouts.ts` | 开局锁牌引导必出位移/反架 |
| `main.ts` | 每场至少一次大破（S1 高潮包触发） |

### S3.4 测试

- `labMashBaseline.ts`：跑馆 1 乱点胜率基线  
- 手测：外行 2 人中 ≥1 人觉得热闹；乱点会疼

### S3.5 验收

- [ ] 馆 1 乱点胜率 ≤35%  
- [ ] 每场至少一次大破  
- [ ] 外行觉得热闹  
- [ ] `npm run test:combat` 绿

## S5 · 外测 + 15 秒镜头验收

**目标：** 外行觉得帅；内行觉得有记忆；可剪 15 秒。

### S5.1 外测剧本

| 人群 | 任务 | 验收 |
|------|------|------|
| 外行 2 人 | 不讲解，玩 15 分钟 | 能指出「爽点是拆对了」；觉得热闹 |
| 内行 1 人 | 玩 30 分钟 | 承认拆招有反馈；愿再开一局 |
| 剪辑 1 人 | 录 15 秒镜头 | 外行看完觉得帅 |

### S5.2 15 秒镜头验收

| 节拍 | 内容 | 验收 |
|------|------|------|
| 0–3s | 亮红威胁 | 外行能感知危险 |
| 3–8s | 一步应对 | 外行能感知动作 |
| 8–12s | 大破 | 外行觉得帅 |
| 12–15s | 短字/战利品 | 外行能复述「破了」 |

### S5.3 验收

- [ ] 外行 2 人中 ≥1 人觉得帅  
- [ ] 内行 1 人承认拆招有反馈  
- [ ] 可剪 15 秒镜头  
- [ ] `npm run test:combat` 绿

## 横切 · 风险与缓解

| 风险 | 缓解 |
|------|------|
| 热闹≠好玩 | 爆点绑定真实破招成功；禁止假高潮 |
| 墨痕脏屏 | 上限 2 痕；不堆状态 |
| 深度嫌浅 | α 硬核另开；爬塔不吹深度 |
| 基础嫌难 | 意图功能名优先；状态三件套 |
| 爆点包花里胡哨 | 单段高潮 ≤1.2s；可关「快速播报」后期再加 |
