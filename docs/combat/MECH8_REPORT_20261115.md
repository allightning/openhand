## 位移入口

落点判定在 `readBoardStep`（`envTags.ts:36`）。缺格后面还有实格，这一步记为跨过，人不落到缺格上。缺格后面没有实格、那一侧有墙，这一步记为撞墙。`walkStand`（`sim.ts:1049`）按步数走完，停在最后一块实格。

确认不改落点的：

- 贴身换位（`sidestep`、敌贴身 `resolveSwap`）：两边已经站在实格上，互换的就是这两格。
- 灼烧只扣站在灼烧格上的血，不挪人。
- 陷阱落在人当前这一格。
- 没有缺格时，`readBoardStep` 的停点和原来的一步循环相同。

播报三句，都带格子数字（第 N 步，N 从 1 数）：`缺格，停在第 N 步`；`跨过缺格，落在第 N 步`；`缺格，桩落不下`。

## 创新思路

1. 走步收成 `readBoardStep` 一种分类。没有缺格时走墙、走占格、走空格，停点和旧循环一样，黄金不用重录。
2. 末端缺格后面没有实板，这一步算撞墙，墙跟到最后一块实板后面。中间缺格后面有实板，这一步只跨过，步数照扣，人只写在实格上。
3. 一步就踩进缺格的进步牌不出。按钮上写停在哪一格，不把一张牌打出去换一个原地。
