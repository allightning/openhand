## 创新思路

### 六系策略怎么判

分在脚本里，不进引擎。每张打得出的牌一个分，取最高。0 分等于这一手收势。

- 拳：距大于 1 就向前步；到了 1 格，攻击分加上击退和伤害。够不着时改打格挡，避免空过等死。
- 刀：同样先贴到 1 格。贴上之后裂创牌优先，其次普通攻击。远处有格挡就先格。
- 剑：目标距 2。距内优先破绽、点穴，其次攻击。
- 枪：人在 2–4 格里就打。在外面先走回这个带。没有步可走时仍打攻击——引擎在 4 格及以外给枪伤，死守「没有步就干等」会把开局距 5 打成空转。贴身（距 ≤ 1）先撤，撤不了再看别的。
- 棍：格挡分最高，攻击分压到 12。距大于 3 才考虑向前。蓄力牌面还没进引擎，这里用「少出手、多格挡」代替。不把桩当棍的主语。
- 钩：距大于 1 优先拉。距 ≤ 2 优先缴械。否则向前，再否则格挡，再否则打。
- 先攻后移（P1 尺）：第一张够得着的攻击，否则第一张位移，否则收势。不打格挡。随机合法牌做对照，抽牌用策略自己的 rng。
- 手牌超上限时，丢掉最后一张「既不是够得着的攻击、也不是位移」。前面的牌留在手里，爬塔按「手里已有的同名扣掉」重配时，后面的牌才进得了手。丢掉排头，排头下一手又回来。

退步、剑圈、枪退算向后。该贴身时这些牌分是 0，避免自动手自己把距离拉开。

### 指标取舍

- 手数 = 玩家回合开始次数。封顶 40。到顶另计一列，和「正常打完」分开。
- 空手 = 回合开始时，没有打得中的攻击，也没有位移可出。只有格挡的手算空手。六系用同一把尺，格挡流不会因为「出了卸力」被算成手头有活。
- 承伤 = 血条下降的累加。回血不把已挨的打冲掉。
- 胜 = 自己血还在，且敌方活口没了或阶段已是胜。
- 偏差用区间外的相对距离，区间内记 0。锚点还没被这套模拟校过，手数偏离只警告，不让进程失败。空手率和胜率越界才失败。
- 使用率的分母是「这张牌进过手」，含一回合里临时摸到的。观察名单回答「摸到了打不打」，不回答「牌组里有没有」。

### 值得固化的平衡工作流

1. 改石台或牌池之后，跑两次 `npm run sim:climb`，stdout 必须一致。不一致就先查种子和 `Date.now`，再查规则。
2. 表头四个指纹写进每次报告。费和变了，胜率不能和上一张表直接比。
3. `--check` 留在 `test:combat` 外面。空手率是硬红线。手数锚点在数值重推完成前只警告。
4. 看观察名单之前先分两类：摸到但距离不够，和摸到了策略仍不打。前者是开局距和牌序的问题，削牌面解决不了。
5. 四十手且承伤接近 0，单列「僵持」。不要把它平均进「座前应该 7–9 手」。
6. 汇率在有结算口之前不进扫描。没有口就乘一个伤害系数，扫出来的表会冒充汇率结论。
7. 策略、旋钮、阈值都留在 `scripts/climbSim/`。结算核继续只暴露 `makeBattle` 三参和 `setBattleRng`。
