# 反应窗专篇（2026-10-30 汇总定稿）

真源地位：本页是反应窗的完整规格。简表在 `RULES.md`「反应窗家族」条；定位在铁律 §2 与 Notion 北星；逐件数值 TBD 随第四层层帽与数值核二班。

## 1. 定位（10-30 拍）

**中核，不是全部，不是点缀**——过招系统的引擎盖、爽点四柱之一（表现 / 构筑 / 猜招 / 反制）。**数量封顶**（七系各一件，不加新窗种）、**改造打开**（羁绊 / 外功 / 心法 / 兵器可强化窗 = 「反应窗流」构筑身份）、**对等补齐**（敌方窗长开）。资源占战斗内容 15-20%，是柱子不是屋顶。

动机依据：玩家讨厌的不是输，是「只能看着」——反应窗把敌方回合也变成你的回合。横向验证：三国杀响应（闪 / 无懈）、MTG 瞬间（插入对方回合）、只狼 / 影之刃零（操作型反应）。**我们的独位：动作游戏的神经，卡牌游戏的脑**——决策窗（选不选、耗不耗蓝），不是操作窗（按不按得中）。

## 2. 通用规则

- 判定在敌出招中途：敌段暂停 → 弹窗 → 选择 → 继续（结算新能力，机制核已落）
- 全部耗蓝；各有触发条件；玩家侧每场帽 1-2 次
- **UI = 圆形弹窗**：边沿进度条 = 思考时间（默认 5 秒，设置档 3/5/10），内写招式名 + 耗蓝
- 触发时画面停触发帧，不提前跳终态（表现铁律兼容）

## 3. 七系逐件（10-29 用户亲刀）

## 4. 设计原则

1. **勾引维度**：反应窗的前半局是勾引、后半局才是惩罚。敌人不做对应动作时窗不该死——玩家要有把窗「钓亮」的手段（压逼加挡、耗逼回复、背墙诱冲、主动贴脸）。
2. **三重奖励检**：每件窗的收益至少占位置 / 伤害 / 资源三样里的两样。透棍当前只有伤害，**补破挡**（打穿敌挡层一部分）。
3. **构筑对构筑**：每件窗是一个敌型的答案；配武器系 = 配「我能惩罚哪种敌人」，与敌配招原型池咬合。
4. **锦上添花不是必修课**：高手靠窗打上限，新手当窗不存在也能玩（难度调节器）。

## 5. 语义场边界（防混淆）

- 断息（打断回蓝）≠ 断劲（枪副，双枪同距扣蓝）——触发不同，文案必须分清
- 透棍「真伤」是条件词（按敌挡层数），不许泛化成通用力量词
- 瘸跛 + 缴械 → 吸血 50%×2 与旧噬血（缴械回血 30%）**并存**（默认）：缴械单条件走旧版，瘸跛 + 缴械走强化版。**瘸跛 = 被钩拉回状态的命名（11-02 拍：非机制翻新）**；吸血比例数值随 28 重定
- 剑偷势与破绽不同：破绽是叠在敌身上耗层穿挡，偷势是把敌叠层转为我剑势

## 6. 敌方反应窗（对等补齐）

三件：**拆招**（玩家出 4 费以上绝招，敌耗自己段数拆掉降效）/ **缠手**（玩家同系连出 3 张，敌插入一段逼近）/ **读破**（玩家同招连用 3 次，敌该招免伤一次）。投放节奏推荐：精英 6 馆起 + 座前必有（待拍 25）。每场帽：敌方 0-1 次。

## 7. 落码状态

- **已落（机制核）**：反应窗结算能力（敌段暂停-选择-继续）+ 回马枪**旧参数**（后手 + 停 2 格 + 废剩余位移 + 耗蓝 2）
- **待改**：回马按本专篇新参数（血 <50% + 拒 3 格 + 圆窗 5 秒）
- **待落**：其余六件 + 圆窗 UI + 敌方三件——反应窗扩包
