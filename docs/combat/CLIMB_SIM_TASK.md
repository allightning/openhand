# 任务卡 · 平衡工作台（自动对局平台 + 策略库 + 全十馆跑局 + 旋钮 sweep + 报告）

2026-10-23 主窗派发。测试窗，MEGA 版，五个阶段。只新建 `scripts/climbSim/**`。**不许改** `src/**` 任何文件（9 格窗与卡池窗在飞）。

## 做完的样子

一条命令跑完全十馆自动对局，输出场均手数 / 胜率 / 空手率 / 承伤曲线 / 牌使用率；每系一种策略；旋钮可批量 sweep 出 markdown 报告；有阈值门。这是后面拍汇率、敌曲线、层帽的度量尺。

## 阶段

### P1 · 基础自动对局 + 指标
- `scripts/climbSim/` 入口，`package.json` 加 `sim:climb`。
- 只调用现有 `makeBattle(enemyId, rc, run)`，不改形参（9 格窗正在往 Battle 加字段；字段缺省时按现行板跑，表头注明板长）。
- 自动手：能出就出费得起、距离够的攻击牌，否则位移，否则收势。种子固定，跑两次输出一致。
- 指标：场均手数、胜率、空手率（一手无牌可打且无位移可出）、场均承伤。默认馆 1 杂兵 / 馆 5 精英 / 馆 10 座前各 10 局。

### P2 · 策略库
- 每系一种自动手策略（策略在脚本层，不进引擎）：拳 = 贴身叠连击推墙；刀 = 贴身叠裂创；剑 = 叠剑势打破绽；枪 = 控 2-4 格打距离档；棍 = 站桩蓄力（蓄力未落码前先用现有棍牌模拟憋招：低出手高格挡）；钩 = 拉近缴械循环。
- 随机策略作对照基线。每策略跑同一批局，出分系指标表。

### P3 · 全十馆整局
- 按现有爬塔馆序敌人表驱动整局：10 馆连打、带伤过馆、馆间奖励用简单启发自动选（回血优先于随机牌）。
- 输出整局指标：通关率、每馆手数曲线、血线曲线、死在第几馆分布。
- 对照锚点：杂兵 4-5 手 / 精英 5-6 / 座前 7-9；全局目标 40 分钟换算（一手 ≈ 25-35 秒，只在报告里换算，不进代码）。

### P4 · 旋钮 sweep + 报告
- `knobs.ts`：汇率 / 回劲 / 敌 HP 系数等旋钮集中（注释指向 Notion 数值框架 https://app.notion.com/p/400427beba9c810696c6d0057a419b13 ），默认全 1.0。
- sweep 模式：批量组合旋钮 × 固定种子，输出 `docs/combat/sim-reports/<日期>.md`：每张表带旋钮值、指标、与锚点偏差。
- 牌使用率表：每张牌出次数 / 被摸次数，<5% 进观察名单列在报告尾部。

### P5 · 阈值门
- `sim:climb --check`：空手率 >5% 红；场均手数偏离锚点 >30% warn；胜率超出 0-100% 显然区间红。
- 不进 `test:combat`（耗时），独立命令，供主窗与统筹按需跑。

## 口径

- 引擎内禁 `Math.random`；脚本内自备种子 rng，走现有 rng 注入口；没有口就在脚本层包，不改引擎。
- 文件超 300 行拆、函数超 80 行抽。
- 表头永远注明：板长、旋钮版本、种子、卡池版本（卡池窗重排后重跑即可）。

## 边界

**准许：** 新建 `scripts/climbSim/**`、`package.json` 加 `sim:climb`、`docs/combat/sim-reports/`、SYNC 自己那一节。
**禁止：** `src/**` 一切修改（含测试与类型）、冻结区、git commit、为了好跑改任何伤害 / 血 / 费用 / 摸牌、读 Notion（旋钮注释写 URL 即可）。

## 验收

`npm run sim:climb` 出全表；同命令两次数字一致；P3 整局跑通 10 馆；`--check` 阈值门能红能绿；`npm run test:combat` 与 `typecheck:combat` 保持开工时结果。
