## 1. 这是什么游戏

玩家在 **七步石台**（7 格）上打牌。站位决定打不打得到、躲不躲得开。敌人下一手招式 **整条意图亮出**。玩家出牌、走动、叠状态，点 **收势** 结束自己的出牌。

门厅进两种玩法（一个 IP、一个入口 `combat-lab.html`，不是两款 App）：

| | 行路（climb） | 登门（break） |
|---|---|---|
| **卖点** | 十程肉鸽：选线选系、下注、过程奖励、同道、黑市 | 短拍谜题：看懂招、站对格 |
| **怎么赢** | 打气血；**不破也能走** | 气力承诺战役看 **架势**；拆错/挨打即败 |
| **意图** | **全段亮出**（铁律） | 试行 C：对打可半隐后段；行路禁止跟改 |
| **优先级** | **根本。先打好玩、打爽、打舒服** | 另一条模式。用户点名「登门 / 破招 / 训练馆」再动 |
| **代码分叉** | `setLabRuleset("climb")`；开局不削段 | `isBreakAlign()`；`qiCommit.ts`、训练馆、破法表 |

仓库名 Openhand。在线试玩：https://allightning.github.io/openhand/  
本地：`npm install` → `npm run lab` → 终端提示的 `127.0.0.1:5175`（`combat-lab.html`）。

玩家向短说明：[PLAY.md](./PLAY.md)。

## 2. 爬塔玩家循环（代码现行）

1. 门厅 **开程** → 选线（少林 / 江湖 / 朝廷，默认 **10 程**，后端支持 `routeLength` 9/10/12）→ 选兵器系（拳 / 刀 / 剑 / 枪 / 棍 / 钩）。  
2. 开场白描（可跳过），直接第一战。不垫资，不下注。  
3. 打赢：营地当铺（金创 / 谱 / 小货）→ 事页。选项可开赌馆（单注最高彩金 80%、一局 ≤3 次）、黑市、换城、追兵。江湖从 12 人抽 5，没抽到的不出现。程 **4 / 7** 同道里程碑；江湖线关陌生人四选一，入队走剧情「见过」后果。  
4. 整局 **1 次赊账**（复活费 + 救命奖励，满状态重打本程；复活赛禁下注）。再破产出局。  
5. **9 程起**可上第 4 人（同道上限 3，光环仍按 3 人算）。  
6. **无尽踢馆**：无馆间遭遇，馆序可过 10，与正赛分榜。

经济、花名册、手牌上限等对照：[ROGUE_GRADIENT.md](./ROGUE_GRADIENT.md)。**设计真源在 Notion**；本文件与 `RULES.md` 只写代码已落部分。

**待遭遇窗**：剧情选项写入 `routeLength`（短 9 / 长 12）。带伤过馆已拍板保留（代码已有）。

## 3. 战斗骨架（铁律 = 必须守）

改规则：**先改 RULES.md 再改码。** 用户要求与铁律冲突：先不落地，写冲突点等用户定。

### 3.1 已是铁律、且应对齐代码的

- 7 格石台；红格 = 结算落点。兵刃圈：**拳 1 / 刀剑钩 2 / 棍 3 / 枪只能打 2–4**。  
- 手牌：默认上限 **5**、硬顶 **10**；留存不超上限。  
- **收势常亮**：结束你的出牌；玩家中期任何时刻可点；教学锁牌/换人步也不灭，仅讲解弹窗期间挡。  
- 敌方意图条：**全段亮出**；**打完一招少一个**，打完的段不得留在条上；不中途补招。回合开始亮本手。条件不够则跳过该段，不改条。  
- 兵刃底速：**拳 8 / 剑 7 / 刀钩 6 / 枪棍 5**。后续可用牌 / 外功改先机。并手玩家先。  
- **格挡**：局内受击减少，**不随回合清**。  
- **裂创只跟注、不计直伤**；**回合结束**按层扣。预演：括号内只留伤害构成，裂创等效果跟在括号后；构成合计必须 = 预演掉血。  
- 复活赛禁下注、满状态重打。爬塔开局 **不削段不打折**（读招才削）。  
- **所有界面按钮不允许重叠。音乐同一时间只播一首。**  
- 图鉴带数值。事页一段白描（约 6–10 句）+ 2–3 选项带数字；死亡评论才写长；战斗闪句带数字或人名。

### 3.2 以代码为准、文档可能滞后

摸牌（回合开始 ⌈上限/2⌉）、弃牌常亮、收势门闸、意图条命运、敌 `advance`、开战距、格挡不随回合清等 **已在 `sim.ts` 落码**。若本文件与 `RULES.md` / Notion 和实机不一致，**以 `sim.ts` + `climbCaps.ts` 为准**，再回写 Notion。

**快刀不是核心。** 兵器/外功里仍可有先机或伤害加成，不要当独立核心机制宣传。

劲力旧合同（上限 6 / 开局 5 / 回 3）、拆招四档作为爬塔胜负 —— 已剔除。爬塔落实前不主动开新机制。

读招仍可能用旧拆招四档 / 气力承诺 / 架势，见 RULES「读招胜负」。不要把读招半隐意图改回爬塔。

## 4. 六系（核副已落 sim，数字以 Notion / climbCaps 为准）

每系 **1 核 + 1 副**，互斥。别系凡牌 / 外功 / 心法 / 符 **不做这两个的主语**。

| 系 | 核 | 副 |
|---|---|---|
| 拳 | 击退 | 连击 |
| 刀 | 贴身高伤 | 裂创 |
| 剑 | 剑势 | 破绽 |
| 枪 | 距离档 | **断劲**（立刻扣敌劲；扣不动挂下一次自然工资；**不转血**。不要写折手、断筋） |
| 棍 | 桩 | 裂桩：敌裂桩→我方格挡；我裂桩→爆炸范围晕 N 段。桩不能放敌人身后那一格；爆炸伤双方 |
| 钩 | 拉近成功才 **缴械**（只跳 **下一次有伤**，不封整回合） | **噬血**（只对缴械目标回血） |

叠层只给：拳连击 / 刀裂创 / 剑势。  
**破招连势已回收**，爬塔不要再用连势。

数字（扣劲量、噬血%、晕段数、状态上限）以 Notion 为准，**遭遇窗不要自己编**。晕 defer、三人摸牌、霸体结束 −1、分池 ×3、置换费−1、弃牌/收势门闸 **已在 sim 落码**。核副锁死；凡精绝不要求六系同数；扩展机制可走牌/兵/功。

## 5. 文风（铁律）

白描：先写看见的、发生的、数字。一句能说完就说完。战斗内以通俗易懂为先（**按钮名 + 数字**）。遭遇才是长文。

禁止（全文，含遭遇、地名、选项、牌面 flavor、图鉴风味、门厅、播报）：

1. 为古风堆关联词：便/却/只/亦/忽/遂/乃/方/而，以及于是/终究/其实/所谓/归根。换皮仍算失败。  
2. 表象→真相反转：不是 A 而是 B；看似 X 其实 Y。能直接说 B 就说 B。一场遭遇最多 1 处反转，且玩家必须真的可能误会。  
3. 假对峙收束：把「请点选项」写成江湖哲理。  
4. 段段哲理、说教收句。  
5. 连续超短句排比；「像/仿佛/如同」式比喻心理。  
6. 后半句否定撑场：不问姓、不问来路、没叫号、没报上姓连用。能写看见什么就写看见什么。

验收：删掉「不是…是…」、末句哲理、以及后半句的「不问/没叫/不报」，场面还在，才算过。

主线 `src/story/**` 冻结，文风专项也不改。

## 7. 精简开发流程

### 7.1 谁说话、谁干活

| 你想做的 | 跟谁说 | 哪扇窗干活 |
|---|---|---|
| 玩法 / 数值 / 六系 / 先机骨架 | 主窗 | 核玩（`.cursor/lanes/1-核玩.md`） |
| 全文文风、统一用词 | 主窗定口径 | 改游戏里的句子：开遭遇窗（或文风专项），不要六扇一起开 |
| 馆间故事、同道口气 | 遭遇 | `2-遭遇.md` |
| 按钮叠了、看不清、预演条 | UI | `3-ui.md` |
| 两首歌叠着、切曲、出招声 | 音频 | `4-音频.md` |
| 读招关卡 / 破法 | 读招 | `5-读招.md` |
| Godot / 特效练习 | 特效 | `6-特效.md`（默认不接入） |
| Lovart / 包装纹样 | 视觉 | `7-视觉.md`（默认不入库） |
| 测完要提交、交叉验收 | 统筹 | `T-统筹.md` |

**跟主窗说 ≠ 主窗施工。** 主窗改 SYNC 口径，专窗改代码。一次最多 **两个** 并行执行窗，文件集不重叠。

### 7.2 每扇执行窗怎么做

1. 读本文件（产品全貌）→ `SYNC.md` 文首 + **自己那节收件箱** → 铁律 `.cursor/rules/combat-ironclad.mdc` → 本车道提示词。  
2. 只改准许文件。爬塔落实以前 **不主动开新内容、新机制**。  
3. 改完跑 `test:combat` + `typecheck:combat`。  
4. **禁止 git commit。** 提交只由统筹窗：测试通过 + 用户同意。  
5. 收工只改 SYNC 自己那一节的「本班 / 已收 / 回主窗」。机制/用词变更必须写进对应收件箱，不要只写在对话里。  
6. `.cursor/handoff.md` 是日记，不是现行板。

未锁、未落代码的草稿（SYNC 文首、Notion）**不要**当已实现去做界面、遭遇正文、音效或测试。

### 7.3 统筹窗额外职责

产品大方向讨论、交叉测试、按指示写回修提示词、**唯一 git commit**。默认不改 `src` 业务代码。急救改码须用户点名文件。
