## 创新思路

1. 手数偏差分成五类再读：早死、锚内阵亡、偏快、久攻未胜、僵持。三手死掉和三手清场用的是同一段锚，胜率把它们分开。馆 2、3、7 手数很像锚，人是全灭的。
2. 标黄旋钮不进 0.85/1.15 的乘数扫描。裂创的尺是「回合结束跳血 / 新增层」。破绽的尺是「穿挡次数 × 4 / 新增层」。比值靠近 1、胜场又短，记成样本被截断，不把 2 改成 1。
3. 馆阶先机用反事实。对局照旧跑，记账时另算 `foePace + climbEnemyPaceBonus(馆)`。后手率 10% 变成 24%，主窗能看见接线之后先机会不会开始值钱，又不用改结算。
4. 使用率分三筐：出过、摸到出 0、整池没摸到。没摸到的 108 张不进废牌名单。观察名单只回答「进了手打不打」。
5. 校准报告的闸是同种子两跑 stdout 一致。`--check` 仍留在 `sim:climb` 上，夜校这跑不把红线变成进程失败，红线写进表。

白班策略库没改：拳贴身，刀贴身叠裂创，剑叠破绽，枪守 2–4，棍先格挡，钩先拉。随机对照用拳牌。蓄力牌面和飞刀仍不在这套自动手里。
