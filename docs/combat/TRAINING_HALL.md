# 训练馆

> 状态：**已落地** · 2026-09-01 适配追 / 敌多元  
> 入口：拆招版门厅 · 与新手关六局、开踢并列，**不走彩金**

## 1. 定位

| | 新手关 | 训练馆 | 开踢 |
|--|--------|--------|------|
| 谁来 | 第一次 | 卡点回炉 / 换兵器练熟 | 真正玩 |
| 结构 | 六局连着、强制脚本 | **每课两关，第二关不强制脚本** | 十馆经济 |
| 成长 | 迷你闭环（奖/市） | 无 | 有 |

训练馆不是第三条踢馆线。过关不加牌、不加彩金、不上榜。

## 2. 每课两关

```
目录点开某课
  ├─ ① 引导     脚本出牌（与新手关同款锁手牌）
  └─ ② 训练     适配同一机制的真打，手牌自由，可输可重来
```

- ① 和 ② **都可以单独进**，互不强制。没打过引导也能进训练。
- ① **教案走完即转自由打**：脚本手牌只覆盖教案步骤；最后一步完成后发还真牌堆。
- ① **收势常亮**：任何教案步都不灭（仅敌方讲解弹窗期间挡）。换人步点收势 = 跳过换人。
- ① **自由打手牌跟场上兵刃走**。
- ② **不锁牌、不钉站位**。开局意图仍按该课主题布置。

### 兵器

一系一课。①：该系走开硬拆 → 拆势打出。②：该系起手脚自由打。  
另课 **换人**：① 同新手⑥（结语文案指向训练馆「追」课）；② 拳已在队，自由换打。
