## 1. 壳：时长与馆数

### 1.1 目标

- 玩家每步思考约 **5–10 秒**
- 测试阶段 **一整轮约 10 分钟** 结束（含下注 / 领奖）

### 1.2 时长粗算

| 环节 | 估时 |
|------|------|
| 战斗（约 4–6 回合 × 2–4 决策） | 40–70 秒 / 馆 |
| 下注 + 领奖 + 黑市 | 15–25 秒 / 馆 |
| **合计 / 馆** | **约 60–90 秒** |

→ **8 馆 × ~75 秒 ≈ 10 分钟**  
→ 10 馆偏紧；15 馆更像 15–20 分钟，不适合作「测试标准局」。

### 1.3 推荐壳结构（拍板用）

| 模式 | 馆数 | 用途 |
|------|------|------|
| **标准踢馆（测试 / 首发）** | **8 馆** | 1–2 教学 · 3–5 成形 · 6–7 加压 · 8 馆主 |
| **长线踢馆（内容够后再开）** | 12–15 馆 | 现有三条路线素材复用 |
| **无尽模式（后期）** | 独立入口 | 标准通关后解锁；不塞进标准局末尾 |

**阶段映射（8 馆标准局）：**

| 馆 | 角色 | 拆招教学重点 |
|----|------|--------------|
| 1 | 教学 | 来锋 + 位移硬拆 |
| 2 | 教学 | 让 / 格挡软拆 |
| 3 | 破眼 | 固定带眼的敌人 |
| 4 | 伙伴里程碑（可保留） | 拆法外功开始成形 |
| 5–6 | 加压 | 变招 / 应激体感 |
| 7 | 期中多敌 | 抢位母题 |
| 8 | 馆主 | 综合考试 |

> 现有 15 馆数据可 **裁成前 8 + 标记后 7 为长线/无尽素材**，不必删内容。

## 2. 拆招「核心决策点」定义（改法总标尺）

每一场战斗玩家真正在做的决策应是：

```
看意图母题 → 决定本回合拆哪几段 → 打牌制造条件（位移/反架/格挡/桩）→ 硬拆拿反打与势 → （可选）押注兑现
```

**凡奖励 / 外功 / 心法 / 兵器 / 被动 / 卡，若只加伤、加血、加资源且不改变「怎么拆」——标为「壳型」；应逐步改为「核型」或降权。**

### 2.1 核型效果分类（改法只许落在这些桶里）

| 桶 | 含义 | 示例方向 |
|----|------|----------|
| **B1 拆条件** | 更容易达成硬拆 | 位移充能 +1；离格也算让→破 等（慎用） |
| **B2 拆回报** | 硬拆 / 破眼更赚 | 反打 +N；硬拆抽 1；硬拆 +彩金 |
| **B3 拆工具** | 手牌更像拆招工具 | 位移牌更便宜；格挡门槛相关 |
| **B4 拆信息** | 更好读招（暂缓表现） | 预览强化（后期） |
| **B5 承压续拆** | 活下来多拆一回合 | 小回血 / 劲，但文案绑「多拆一拍」 |
| **B6 赌兑现** | 拆招进度直接换钱 | 硬拆 +1 彩金；破眼注加成 |

壳型（加攻、无条件伤、纯血海）**逐步降权或改写**，不是立刻删光——避免壳散掉。

## 7. 卡牌靠拢（起手 + 奖励残谱）

### 7.1 原则

- **不新增大种类**；改 **奖励池权重** + 少量牌效微调 + 文案标注「拆招工具」。
- 起手已含位移（retreat/sidestep/advance）—— **保留**；奖励池 **提高位移 / 反架 / 落桩 / 格挡** 权重，压低纯攻重复。

### 7.2 工具牌标签（策划用，可进 tip）

| 标签 | 卡例 | 服务拆法 |
|------|------|----------|
| 位移充能 | sidestep, retreat, advance, advance2, backpalm, push… | 来锋 / 抢步硬拆 |
| 反架充能 | expose, pierce, marking, rift | 卸力硬拆 |
| 落桩 | plant, split | 冲锋 / 落桩 |
| 格挡软拆 | defend, brace, ironform | 连打「让」、刀创硬吃 |
| 贴身条件 | cut, hookpull, thrust | 拉 / 吐纳硬拆 |
| 纯输出 | strike×n 等 | **壳**；奖励权重↓ |

### 7.3 残谱奖励权重（建议）

| 池 | 权重 |
|----|------|
| 位移 / 身法 | 35% |
| 反架 / 点穴 / 破绽 | 20% |
| 格挡 / 桩 | 20% |
| 本系攻击（可重复） | 15% |
| 功能（抽牌/蓄劲等） | 10% |

### 7.4 起手微调（可选，慎改）

| 系 | 建议 |
|----|------|
| 全局 | 保证每系起手 **≥3 张位移标签**（现约 3–4，达标则不动） |
| spear/hook | 本系攻击重复多：奖励池少再给 thrust/hookpull，多给位移与功能 |

## 9. 黑市改法表

现摊位：金创 / 残谱 / 道具 / 外功 / 淬刃。

| 货 | 现 | 靠拢 |
