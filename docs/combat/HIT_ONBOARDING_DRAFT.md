## 0. 一句话目标

普通玩家在**示范闭环**里完整走通「打→奖→买→再打」，并打出「拆！／让／眼破」；  
毕业后再进正式选线／选系／下注。  
六系按**上手难度 × 拆招上限**分层，牌与技能必须服务拆招，不做平行体系。

| # | 原则 |

### E.1 流程

```
门厅
  ├─【新手关】三帧 → 六局 → 回门厅
  ├─【训练馆】每课：引导（锁牌）+ 训练（自由，可选）

```

### E.2 第 ② 局后：伙伴与换人

| 项 | 规格 |
|----|------|
| 选项 | **三人、三系**（例：拳 / 枪 / 棍，具体 ID 实现时定；**必有拳**） |
| 引导 | UI 高亮拳选项 + 一句：「选拳手上场，下一息点换人，体会换人」 |
| 若点错 | 允许选别人，但 coach 仍提示「下次可换拳练换人」；**推荐强制第一次只能点拳**（更稳，实现优先） |
| 换人教学 | 示范③开场或②末：强制／高亮「换人·拳」，换上后 1 句说明耗劲／登场；然后继续破眼脚本 |
| 目的 | 只教**换人存在**，不教共鸣／组合技百科 |

### E.3 闭环壳（简而全）

| 环节 | 做法 | 不做 |

## F · 六系操作梯度与拆招适配（定稿方向）

> 定位更新：**上手梯度要分明**；中后期兵器要「难操作、高拆招收益」，并用**拆招向牌／技**重绑，禁止长期游离于拆招外的平行体系。

### F.1 三档

| 档 | 兵器 | 操作手感 | 数值／拆招 | 定位 |
|----|------|----------|------------|------|
| **入门** | **拳、刀** | 功能简单，好上手 | 拆招门槛低，收益稳，适合新手与示范 | 外发默认、示范锁刀、拳作换人教学 |
| **进阶** | **剑、枪** | 要算距离／破法，操作难一档 | **面板可略低**，但**拆招收益上限更高**（反打／眼／充能回报更好） | 正式局追求上限的人 |
| **高阶** | **棍、钩** | **特有机制**，下限很高（普通玩家难玩好） | 上限 ≥ 剑枪，甚至更高；机制必须**改成服务拆招** | 老手／做攻略向 |

### F.2 各系与拆招的关系（改法北星）

| 系 | 现状问题（体验） | 定稿方向 |
|----|------------------|----------|
| **刀** | 相对顺 | 保持「斩＋位移」清晰；示范与入门主力 |
| **拳** | 相对顺 | 贴身拆、换人教学；简单拆工具 |
| **剑** | 需抬拆招操作感 | 强化点穴／破绽等**反架／破眼路径**；伤可略收，拆回报拉高 |
| **枪** | 需抬拆招操作感 | 强化距离读招、抢先／锁步与**来锋硬拆**联动；上限靠拆不靠纯戳 |
| **棍** | 桩／控制与拆招适配弱 | **保留桩**，但桩要变成拆工具：拆冲锋、拆位移段、硬拆加成／充能，而不是另开「种桩玩法」；控制（眩晕等）应对「拆完窗口」服务 |
| **钩** | 缴械、拉近／甩出未玩满 | 缴械＝拆某类意图的硬条件或强让；拉近／击飞＝**制造／离开红格**的拆位工具，每次位移类钩都要写进拆招充能或破法 |

### F.3 卡牌与技能总则

1. 新牌／改牌先问：是否改变「怎么拆」或「拆了赚什么」？否则降权或改写。  
2. 入门系：少特殊规则，多通用拆工具（位移、挡、轻反打）。  
3. 进阶系：规则稍多，但每条规则指向破法／眼／距离。  
4. 高阶系：特殊机制保留辨识度，**必须能在意图条上读到「因为我有 X，所以这段能拆」**。  

### F.4 分期（与 E 的关系）

| 批 | 内容 | 何时 |
|----|------|------|
| **E** | 示范闭环（刀＋拳换人） | **下一步开工** |
| **F0** | 文档／选系 UI 标注三档（入门／进阶／高阶） | 可与 E 并行 |
| **F1** | 刀拳微调（保入门手感） | E 后 |
| **F2** | 剑枪：降纯伤、抬拆回报与破法牌 | E 后 |
| **F3** | 棍：桩↔拆招重绑；钩：缴械／拉近↔拆位重绑 | F2 后，单独开草案细表 |

**本定稿不要求立刻改全六系数值**；E 只锁刀／拳教学路径。F3 开工前再出「棍钩拆招适配」专项表。
