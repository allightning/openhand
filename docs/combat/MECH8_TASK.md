## 拍定口径（铁律 + 主窗）

- **不可站**：任何位移（玩家牌、敌位移、拉近/击退/换位）的落点不许是缺格；落点非法时停在最近合法格。
- **可跨过**：位移路径经过缺格不挡路（缺口是「没板子」，不是墙）。
- **初始站位**不落缺格；`gapFieldFor` 按词条返回实际缺格下标：`gap_end` = 缺板子末端一格（缺左侧最后一格还是右侧，随墙侧同侧末端）；`gap_mid` 本班只接字段与结算通用路，投放表不投。
- **墙**：缺格时墙在板上最后一**实**格后（铁律已拍）。
- **落桩**（桩师）不可落在缺格；灼烧格与缺格不重叠（投放表保证，结算不用防）。
- 播报一句白描 + 数字，禁铁律 §4 禁词。
