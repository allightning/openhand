# W1 预改进草案（详细）

> **性质：** 设计草案，供拍板；未动手改代码前可改目标与取舍。  
> **范围：** 仅 W1——拆招反馈 · 意图/状态可读 · 前段禁乱点 · 门厅主路径。  
> **不在本案：** 黑市/赌馆/构筑方向（W2）、7 格大改与剧情路线条（W3）、新 BGM 接线。  
> **日期：** 2026-09-05 · 判断依据见 `IMPROVEMENT_CHECKLIST.md` 与试玩反馈。

---

## 1. W1 要解决的一句话

让玩家在第一小时里：**听得见拆、看得懂招、乱点会疼、尝过一次「破」的高潮**——且踢馆与读招战役用同一套高潮，不再「主线更哑」。

---

## 2. 现状解剖（代码事实，不是感想）

| 现象 | 现行实现 | 对反馈的解释 |
|------|----------|--------------|
| 踢馆拆招「没感觉」 | `climbBreakLight()`：肉鸽爬塔时故意把破招 SFX/气势压到 light（约 0.55） | **主产品路径在主动压反馈**；深度玩家骂哑火，与此同向 |
| 四档有字色、缺身份 | `.lab-fx-break/graze/miss/hit` 主要是颜色差；SFX 大量共用 `clash`/`drop` | 眼可辨一点，耳难辨；「闭眼听档」不及格 |
| 意图条已有档位徽标 | `labV2Ui` 段上有 破/让/空/打 与 tip（招名·数值） | 缺**破法动词**常驻；花名优先时仍像谜语 |
| 乱点基线工具已有 | `labMashBaseline.ts` 可测乱点胜率 | W1-D 可用「馆 1 乱点胜率」作硬指标，不必凭感觉 |
| 馆 1–2 文案偏站位入门 | ladder `stressCap: 0`；提示「看红格、走开」 | 「不破也能爬」前移到开局 → 乱点可过与口号一致，但毁了愉悦点强制体验 |

**草案结论：** W1 不是从零发明反馈，而是——**撤掉主线压反馈、把四档做成感官事件、把意图补上破法一层、用数值把门闩拧到乱点疼、第一次硬拆给镜头。**

---

## 3. 目标与非目标

### 3.1 目标（W1 出口）

1. 非深度：能指出「爽点是拆对了」；馆 1 乱点明显吃瘪或失败。  
2. 深度：承认「打出硬拆有感觉」；踢馆与读招战役反馈同级。  
3. 任意被试：抽 5 段意图，能说出威胁与应对类型（位移/反架/不出攻等）。  
4. 状态：战内出现的状态，悬停能答效果+来源。

### 3.2 非目标（本波禁止膨胀）

- 不加新破法 kind、不改六系大数值、不开新菜单系统。  
- 不解冻地图、不接 BGM 大包（四档可用现有 SFX 重映射或 4 个短音占位）。  
- 不做「完美教学关 20 关」；只保证**必经一次硬拆高潮**。

## 4. 支柱 A · 拆招反馈规格

### 4.1 设计原则

- **一档一事件**：破 / 让 / 空 / 打 = 独立的视 + 听 + 短字，禁止「只有战记多一行」。  
- **硬拆是高潮，其它是语法**：让/空/打要清楚，但时长与体量必须小于硬拆。  
- **踢馆满分量**：废除（或反转）爬塔 `climbBreakLight` 对破/追的压制；若担心吵，只压「打」的受伤音，不压「破」。

### 4.2 四档事件表（感官身份证）

| 档 | 屏幕字 | 字号/时长 | 立绘/石台 | SFX（占位策略） | 额外 |
|----|--------|-----------|-----------|-----------------|------|
| **破**（含追） | 「破」或「追」 | 最大号 · 持有 **900–1200ms** | 敌格 `board-anim-break` + 刀光 `slash_arc` | 专用高亮音（暂用 clash 满音量+更高一层，或新 `break.mp3`） | 拆势/战利品跳字 **同窗或 +150ms**；可选 80ms 全局微闪（宣纸亮一下） |
| **让** | 「让」+ **半伤数字**（如 让 6） | 中号 · 700ms | `board-anim-graze` | 钝击（clash 降调/降量，与破区分） | 必须显示最终承伤 |
| **空** | 「空」 | 小号 · 500ms | 敌挥空/你侧无受击 | drop 或更轻 | 副标小字「未挨·不算拆」（首次本局显示，其后可省略） |
| **打** | 「打」+ 伤害数字 | 中号偏警告 · 700ms | 你受击动画 | 明确受伤音（与破不同） | 见 4.4 失败主因 |

读招战役 / 训练馆 / 踢馆：**同一张表**，禁止再分 light/full 两套气势（A4）。

### 4.3 硬拆「高潮包」时间轴（A2）

单段硬拆建议时序（可 ±100ms）：

```
0ms     段高亮「正在兑」+ 起手挥砍音（可短）
120ms   大号「破」弹出 + 刀光挂敌格立绘
120ms   破专用 SFX（满）
200ms   拆势/真伤/掉落跳字（若有）
…持有到 ~1000ms
然后    下一段或收束
```

**工程落点（预估）：**

- `main.ts` `playFoeRecapThen` / `outcomeToFxKind`：破路径强制走高潮包；删或收窄 `climbBreakLight` 对 break 的减量。  
- `lab.css`：`.lab-fx-break` 加大、加持有；可与 `.lab-fx-big` 合并策略。  
- `labAudio.ts`：四档 SFX 映射拆开（即便暂共用文件也要不同音量/播放策略，便于日后换资产）。  
- 测试：`labHitFeedback.test.ts` / `labAudio.test.ts` 断言破路径不再 light。

### 4.4 挨打主因一条（A5）

当 outcome=打，在跳字下或教练条给 **唯一** 主因（优先级从高到低，只取第一条为真的）：

1. 仍在红格（未离威胁）  
2. 离格但无位移充能 → 「让本可成，缺位移」——若实际是打，则写清为何不是让  
3. 破法不对（反架类未出破绽牌等）  
4. 兜底：「这段照打」

禁止一次堆三条。文案 ≤16 字。

### 4.5 第一次硬拆镜头（与 D3 合流）

本局（或本馆）**首次**硬拆：

- 高潮包时长 +200ms  
- 教练条/战记高亮一句固定文案（可关，默认开）：  
  - 踢馆：「这就是拆——他这招作废了。」  
  - 读招：「段破。照这样做下去。」  
- 计入 `localStorage` 或 run 标记，避免每馆啰嗦（可选：每线第一次再提一次）

## 5. 支柱 B · 意图条可读规格

### 5.1 段面信息架构（B1/B3/B5）

每段按钮信息层改为固定四槽（视觉可折行，语义顺序不变）：

| 槽 | 内容 | 例 |
|----|------|-----|
| 1 序 | 第 n 段 | 1 |
| 2 功能名 | **kind 功能名优先**；花名作副标或 tip | 打击（「劈山」可 tip） |
| 3 威胁 | 伤害/效果数字 + 落点提示 | 12 · 红2–3格 |
| 4 破法 | 短动词，来自 `weaknessTip` / 压缩版 | 位移离格 |

**常驻 vs 悬停：**

- 窄屏：槽 1–3 常驻，槽 4 悬停或段下第二行。  
- 宽屏：四槽常驻。  
- W1 验收以「悬停必见破法」为底线，「常驻破法」为优。

### 5.2 威胁色带（B2）

按「预估对我伤害 / 当前 HP」分三档描边或底纹（具体阈值可调）：

| 档 | 条件（草案） | 表现 |
|----|--------------|------|
| 危 | 段伤 ≥ 当前 HP，或 ≥ HP 的 45% | 深朱描边 |
| 疼 | ≥ HP 的 20% | 褐警示 |
| 软 | 其余 | 默认墨线 |

跳过段：灰 + 「劲不足」类原因（已有 skip 则暴露原因文案）。

### 5.3 兑段高亮（B4）

播报中 `foePlaybackSegIdx` 对应段：强高亮「正在兑」；已结算段降对比；未兑段保持。  
（意图整队刷新逻辑已 defer——保持，不回退。）

### 5.4 花名政策（B5）

- `foeIntentAlias`：可保留风味，但 **可见主标题改为功能名**，花名进 `data-tip` 末尾。  
- 验收：不认识花名也能选应对。

## 6. 支柱 C · 状态可读规格

### 6.1 状态三件套（C1）

统一数据结构（概念）：

```text
id / 短名 / 效果一句 / 来源一句 / 服务决策一句（内部）
```

玩家可见：短名 · 效果 · 来源。  
悬停角标、残谱、状态栏共用同一文案表（避免三处各写各的）。

### 6.2 获得跳字（C2）

上状态时走 fx 队列一类：`裂创 +2` / `滞步 1`，颜色用现有 `lab-fx-cardStatus`。  
与硬拆高潮同帧时：状态跳字可晚 150ms，避免字叠死。

### 6.3 前 3 馆状态白名单（C4）

| 允许（例） | 暂藏/合并（例，拍板时按实表勾） |
|------------|----------------------------------|
| 裂创、位移相关、格挡、眩晕/滞步等「战内立刻影响站位或承伤」 | 解释不清、或仅服务后期构筑的冷门印记 |

规则：进馆 1–3 的敌人 kit **不得**施加白名单外状态；白名单外状态可留在馆 4+ 或训练柜。

### 6.4 本局状态回顾（C3）

残谱或侧栏「本局状态」：只列本局出现过的 id + 三件套。W1 可用最小实现（残谱一节），不做独立 wiki 页。

## 7. 支柱 D · 前段禁乱点规格

### 7.1 量化门闩（推荐主指标）

用现有 `labMashBaseline` 思路扩一条 **馆 1 配置乱点胜率**：

| 指标 | 现状（待跑） | W1 目标 |
|------|--------------|---------|
| 馆 1（三线抽样或江湖线）乱点胜率 | 先跑基线写入本表 | **≤ 35%**（可调，但必须低于「轻松过」体感） |
| 馆 1「零硬拆通关」率（策略：从不主动满足硬拆） | 待测 | **≤ 20%** 或通关后强制标记未品尝 |

若基线已经很低，则 D 侧重「强制品尝」而非加伤。

### 7.2 手段菜单（只选 2 个组合，避免又骂又哄）

**推荐组合 R（草案默认）：**

1. **数值：** 馆 1 `dmgCoef` / 段结构上调到乱点疼（保留 `stressCap: 0`）。  
2. **门闩：** 馆 1 胜利条件增加「本场至少 1 次硬拆」——未达成则：敌不降服 / 或收势后敌进入「压打」额外段直到达成或战死。  
   - 更硬选项：未硬拆直接不能算胜（读招式）。踢馆建议用「压打」少一点挫败文案。  
3. **镜头：** 第一次硬拆走 4.5。

**备选组合 S（若不愿改胜负）：**  
只加伤 + 开局锁牌引导必出位移，无硬拆门闩——弱于 R，仅当门闩争议大时用。

### 7.3 口号对齐（D5）

- 玩家可见：「前两馆先学会拆；之后不破也能爬。」  
- 代码/文案：馆 3+ 再强调不破可爬；馆 1–2 教学与门闩一致。

### 7.4 门厅主路径（D4）

W1 最小改动：

- 主 CTA 文案改为直达「开踢」或「低阶入门（含强制硬拆体验）」二选一——**只留一个主大钮**。  
- 实验台 / 多训练入口视觉降一级（仍可点）。  
- 不做大改 IA（留给以后）；先解决「10 秒不知道点哪」。

## 9. 验收剧本（外测用）

### 9.1 非深度（约 25 分钟）

1. 不讲解，只给链接。  
2. 观察首击点击哪个入口（记是否找主 CTA）。  
3. 馆 1：允许乱点——是否在 2 次尝试内明显吃瘪/失败。  
4. 引导其打出一次硬拆后立刻问：「刚才爽的是什么？」——目标答出拆/破类。  
5. 指一段意图问：他多重、怎么应对。

### 9.2 深度（约 40 分钟）

1. 踢馆打到能多次硬拆；问反馈是否够。  
2. 读招战役打 1–2 关；问是否仍「更干」。  
3. 指 3 个状态角标：效果与来源。  
4. 主观分：拆招反馈 1–5（目标 ≥4）。

### 9.3 通过线

- 非深度 2 人中 ≥1 人能指出爽点；馆 1 乱点指标达标。  
- 深度 1 人反馈分 ≥4，且不认为读招更哑。  
- `npm run test:combat` 绿。

## 11. 风险

| 风险 | 缓解 |
|------|------|
| 高潮包过长拖慢节奏 | 硬拆 1.0–1.2s，让/空更短；可设「快速播报」选项后期再做 |
| 门闩劝退急性子 | 压打 + 强提示「走出红格/打位移」；失败主因一条 |
| 功能名干掉花名风味 | 花名进 tip，不进主标题 |
| 状态文案工程量大 | W1 只覆盖前 3 馆白名单 + 本局出现集 |
