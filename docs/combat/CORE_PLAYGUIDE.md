# 新核心玩法攻略 · 气力承诺制（v0.1）

> **日期：** 2026-09-05  
> **地位：** `CORE_REBUILD.md` 的玩法说明书。拍板前必读——看完这份，你应该能脑内打完一场完整战斗。  
> **一句话：** 敌人出招全亮给你看，但你的气力永远不够全防——每回合都在赌「拆哪段、吃哪段、留多少气打下轮」。

---

## 一、屏幕上有什么（战斗界面）

```
┌─────────────────────────────────────────┐
│  敌方：江湖刀客    HP 18/18   气势威胁 ●●  │
│                                          │
│  敌方队列（全明，从左到右依次结算）：        │
│  ┌───┐ ┌───┐ ┌───┐ ┌───┐               │
│  │扫 │ │刺 │ │蓄 │ │   │  ← 本回合 3 段 │
│  │4伤│ │6伤│ │力 │ │   │               │
│  └───┘ └───┘ └───┘ └───┘               │
│   格1   格2   格3                        │
│                                          │
│  ─────── 七步石台 ───────                │
│                                          │
│  你：HP 30/30   气力 ⚡⚡⚡(3)  气势 ▲0     │
│                                          │
│  手牌（每回合抽 4 张）：                   │
│  [横拦·架] [点穴·拆刺] [退步·闪] [扫叶·攻]  │
└─────────────────────────────────────────┘
```

**五个要素：**
1. **七步石台**：你站一格（1–7）。来招落在**红格**上；你不在红格 = 该段打空。
2. **敌方队列**：敌人这回合要出的招，从左到右结算，**全部亮明**并标红格。
3. **气力 ⚡**：每回合回满到 3，永远不够全防。
4. **气势 ▲**：硬拆 +1，挨打清零。3/5/8 解锁增益。
5. **墨痕**：硬拆成功的**石台格**留一轮；他再打这格自动被克。

## 二、四种牌（你的全部动作）

| 牌型 | 费气 | 效果 | 判定 |
|------|------|------|------|
| **拆**（拆招） | 2⚡ | 指定一段，若牌型克制该招 → **硬拆**：该段作废 + 返 1⚡ + 气势+1 + 该格留墨痕 | 克制错 → 白扣 2⚡，该段照常打你 |
| **架**（招架） | 1⚡ | 指定一段，伤害 -3 → **擦破**：吃小伤，气势不变 | 稳定但平庸 |
| **闪**（闪避） | 1⚡ | 指定一段，完全躲开，但无反击无气势 | 保命牌 |
| **攻**（进招） | 1~2⚡ | 直接打敌方 HP（1⚡=3伤 / 2⚡=6伤） | 不防，纯换血 |
| **过**（不出牌） | 0 | 存 1⚡到下回合（上限 5⚡） | 蓄爆 |

**克制表（拆牌专用，就三条，一眼记住）：**

| 敌招 | 用什么拆 |
|------|----------|
| 扫（横斩） | 拆·压（下压式） |
| 刺（直取） | 拆·点（点穴式） |
| 撞（贴身） | 拆·引（卸力式） |

> 特殊段：**蓄力段**不能拆不能架——它不掉血，但下回合敌方队列 +1 段且伤害 +2。**你只能选择：这回合用攻牌打断它（攻牌打蓄力段 = 伤害×2），或者吃下回合的强化。**

## 三、一回合怎么打（逐步）

以上面界面为例。敌方队列：**[扫 4伤] [刺 6伤] [蓄力]**。你有 3⚡，手牌：[横拦·架] [点穴·拆刺] [退步·闪] [扫叶·攻(1⚡/3伤)]。

### 第 1 步：读队列，算账

- 全覆盖成本：拆扫 2⚡ + 拆刺 2⚡ = 4⚡ > 你的 3⚡。**兜不住。**
- 蓄力段不打断 → 下回合对面 4 段且更疼。
- **这就是每回合的核心时刻：你必须放弃点什么。**

### 第 2 步：落子（不可逆！）

你把牌拖到队列格上，**放下就不能收回**。几种打法：

**打法 A · 稳：** 拆刺（2⚡，克制成 → 硬拆，返 1⚡）→ 剩 2⚡ → 架扫（1⚡，4伤→1伤）→ 剩 1⚡ → 扫叶攻蓄力段（1⚡，3伤×2=6伤，打断蓄力）。
结果：吃 1 伤，硬拆 1 次（气势 1），敌 -6 HP，蓄力被断。**完美回合——但前提是你手里正好有这三张牌。**

**打法 B · 贪：** 拆刺（2⚡→返1⚡）→ 攻×2（2⚡，打敌 9 伤）。
结果：扫 4 伤全吃，气势 1，敌 -9 HP。**用血换节奏，赌下回合抽好牌。**

**打法 C · 龟：** 架刺（1⚡，6→3伤）→ 闪扫（1⚡）→ 过（存 1⚡）。
结果：吃 3 伤，气势 0，下回合 4⚡ 开局。**蓄力段没管，下回合对面 4 段——龟是有代价的。**

### 第 3 步：结算（像放电影）

队列从左到右逐段演出：你的拆/架/闪依次触发，墨色飞溅，硬拆有大顿帧。**结算阶段你只能看——所以落子那一下就是全部决策。**

## 四、气势：高手的滚雪球

| 气势 | 解锁 |
|------|------|
| ▲3 | 攻牌 +1 伤 |
| ▲5 | 每回合 +1⚡（预算 3→4） |
| ▲8 | **必杀**：本回合可打出「绝式」（0⚡，12 伤 + 清敌方一段队列） |

- 硬拆 +1 气势；**任何一段没防住（空档全伤）→ 气势清零**。
- 所以硬拆返气（2⚡出返1⚡）是引擎：手顺时 3⚡ 能拆两段还余 1⚡ 进攻，气势连涨。
- **爽感曲线：连拆 3 次 → 气力变多 → 拆得更多 → 必杀收尾。这就是可剪的 15 秒。**

---

## 五、墨痕：这回合的拆，是下回合的局

- 你硬拆成功的那一格，留**墨痕**一轮。
- 下回合敌方队列若再用这一格出招 → 该段**自动被克**（不用出牌，直接作废 + 你气势 +1）。
- **于是你开始想一步棋：** 「这回合我拆格 1 不拆格 2——因为看他套路，下回合他大概率回格 1 出扫，墨痕白赚一段。」
- 敌人不是傻子：精英/Boss 被留痕后，下回合**有意避开**墨痕格的概率上升 → 你又在赌他避不避。

## 六、精英战：招路图（深度层）

精英/Boss 的招式不是独立段落，是一张**依赖图**，开战时亮给你看：

```
        扫(起)
          ↓
   刺(承) ──→ 架(转)
          ↓
        怒击(合·12伤)
```

- 规则：敌方按「起→承→转→合」走招路。**你硬拆掉「承」节点 → 后面的「合」直接瘫痪**（他蓄不出怒击）。
- 拆「起」= 只少一段 4 伤。拆「承」= 废掉 12 伤的怒击。**同一个硬拆，价值天差地别。**
- 但「承」段往往配重兵（伤害高/带护），拆它风险大。
- **博弈：识别他的招路咽喉，决定值不值得把 2⚡ 和一次硬拆机会押上去。**

## 七、Boss 战：起手式（读人层，Boss 限定）

- Boss 队列**只亮前 2 段**，后段扣着。
- 但 Boss 有**起手式**（站姿图标，100% 可读，无随机）：
  - 🗡 刀尖朝下 → 后段是「扫」系
  - 🗡 刀尖平指 → 后段是「刺」系
  - 🛡 收刀入怀 → 后段是「撞」系
- 你可以花 1⚡「**盯梢**」直接翻开一段暗牌。
- **决策：信自己的读（省 1⚡ 但赌错吃大的），还是花气买确定？**
- Boss 三阶段，每阶段换一套招路图 + 起手式节奏变快。

## 八、一场完整战斗演示（普通馆 · 江湖刀客 HP18）

**你的牌库 12 张：** 拆·压×2 / 拆·点×2 / 拆·引×1 / 架×2 / 闪×2 / 攻(1⚡)×2 / 攻(2⚡)×1

**T1：** 敌队列 [扫4][刺6][蓄力]。手牌：架/拆点/闪/攻1。
→ 拆点刺（2⚡，硬拆！返1⚡，气势1，格2留墨痕）→ 架扫（1⚡）→ 攻1打蓄力（1⚡，6伤，断蓄）。
**你 29HP / 敌 12HP / 气势1。**

**T2：** 敌队列 [撞5][扫4][刺6]——注意：格2 又是刺，撞上你的墨痕！
→ 墨痕生效：刺段自动作废，气势+1（▲2）。手牌：拆压/攻1/攻2/闪。
→ 拆压扫（2⚡，硬拆！返1⚡，气势▲3：攻牌+1伤）→ 攻2撞脸（2⚡，7伤）。
**你 29HP / 敌 5HP / 气势3。撞 5 伤？不——撞段你没管，吃 5 伤。你 24HP。**

**T3：** 敌队列 [扫4][扫4][刺6]。手牌：拆压/拆压/架/攻1。
→ 拆压格1（2⚡→返1⚡，▲4）→ 拆压格2（2⚡→返1⚡，▲5：下轮+1⚡）→ 攻1（1⚡+1气势伤=5伤）。
**敌 0HP。战斗结束。**

**全场回顾：** 3 回合，你做了 9 个决策，吃了 6 伤，打出 4 次硬拆，T2 的墨痕是 T1 埋的。**「T1 拆格 2 留痕 → T2 白赚一段」——这就是这游戏想让你上瘾的那一下。**

## 九、构筑三方向（江湖线首发）

| 流派 | 核心思路 | 代表卡 |
|------|----------|--------|
| **省气流** | 低费高效，架/闪强化，稳字当头 | 「铁桥手」架 0⚡ 但每回合限 1 次 |
| **返气流** | 硬拆循环，气势发动机 | 「连环卸」硬拆返 2⚡ 而非 1⚡ |
| **蓄爆流** | 存气过牌，一回合必杀 | 「闭息」过 = 存 2⚡；「绝式·扫叶」8⚡ 20伤 |

## 十、防龟/防赖皮设计（边界问题）

| 问题 | 对策 |
|------|------|
| 一直架/闪龟着不打？ | 蓄力段惩罚 + 敌方气势威胁（拖久了对面段数变多） |
| 抽不到克制牌干瞪眼？ | 牌库 12 张抽 4，克制牌占 5/12；架/闪是万能保底；「过」存气等下轮 |
| 气力上限 5 会不会憋大招无敌？ | 上限 5 + 气势空档清零，憋气=放弃防御=挨打泄气势 |
| 普通关也要读招路图？ | 不用。普通关纯气力取舍；招路图精英起；起手式 Boss 限定。三层难度阶梯 |
