## 创新思路

这些是本包自己定的，建议收成音频规范。数值和六系主语仍归核玩。

1. **五层，不按招式各做一条。** 座位（BGM 与短句，互斥）→ 打击总线（命中、拆、擦、撞墙、打空，段间互掐）→ 身法（挥空、移步、换人、蓄力）→ 印记（裂创、破绽、断劲、噬血、缴械、钉）→ 壳（纸墨、确认、弃牌）。新机制先归层，再决定要不要新键。
2. **一把键一个占位。** `windup` 与 `whiff` 永不并格。连击重放和挥空可以暂时同一文件，键必须分开，换素材时才不会一改全改。
3. **命名。** 命中 `{school}_hit`。该系独有动作 `{school}_{verb}`（`dart_pin`、`staff_burst`）。跨系印记用裸动词（`disarm`、`bleed_tick`）。石台环境 `env_{tag}` 与 `wall_{结局}`。手牌壳层用动词，摸、弃、置换三把不合并。
4. **占位听感就这四句。** 碰到身体或兵器用 clash。空气里的动作用 swing。没有接触的一下用 drop。纸、墨、从条上拿掉用 page。page 禁止进打击总线。封条、翻页、弃牌可以和起手叠，不占「一声打击」。
5. **没有出口就不播。** 允许的出口只有三种：按钮、已经在长的 fx 队列、壳层已经在跑的阶段拍或意图封条。log 差分只认核玩已经写进 `battle.log` 的那几个词。新词条要声，核玩加 fx 名或阶段拍，音频再加一行映射。不要在 `sim.ts` 里放 Audio。
6. **段间阈值绑 `FOE_WINDUP_MS`，不要另写毫秒魔法数。** 同一段的挥空加结算留下；下一段起手掐掉上一声打击。
