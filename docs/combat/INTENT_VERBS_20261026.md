# 过招系统全设计 · 意图动词谱（v0.1 待拍）

2026-10-26 主窗出。地基：铁律「意图信息结构」条（L0 情报 / L1 架势 / L2 反应窗 / L3 读懂，全明全隐都否，结算规则不变只分层显示）。本稿把四层填成可落地的完整设计。原则：新动词必须改变玩家应对函数；给工具不给固定解；武侠感——看破架势是极限，知道连招就不叫过招。

## 1. 架势类型表（L1）

敌每手亮**一个主架势 + 段数**，不亮每段内容。**六类（2026-10-26 用户修订）**：

| 架势 | 含义 | 玩家直觉 |
|---|---|---|
| 伤势 | 主打伤害 | 防 / 挡 / 拉开 |
| 进势 | 主位移靠近 | 控距；背墙系警惕或利用（回马枪口） |
| 退势 | 主位移远离 | 追；贴身系抢步 |
| 守势 | 叠挡 / 回血 | 破挡（破绽 / 断劲）或抢攻 |
| 蓄势 | 大招前奏 | **打断窗口**（他在运气——截杀或打断） |
| 诡势 | 墙联动 / 控制 / 反应窗 / 虚招 | 未知标记；情报或读懂解锁 |

命名（用户拍）：伤害就叫「伤」，靠近就叫「进」。**疲势删除**——旧系统本就没有敌人疲惫机制，「这手安全」标出来等于白送情报；弱手靠段数与读懂自然发现。

要点：**蓄势必须可见**（打断玩法的地基）；**诡势 = 未知**，它是 L0 情报的货架（「这货的诡势是撞墙」值一条情报钱）；段数本身就是信息量（伤势 ×3 vs ×1，威胁量级不同）。

## 1.5 显示形态：聚合模型（2026-10-26 用户拍）

**意图条 = 聚合标签，不列段格、不列顺序、不列内容**：「伤势 ×2 · 进势 ×1」。具体出什么、怎么出、什么顺序出，全部隐藏。

三个配套：

1. **表现力全部放在出招瞬间**：每段执行时全程命名演出（招式名大字 + 数字 + 演出）。预告是克制的，亮相是张扬的——敌不动你不知，敌一动惊艳。招式的穿插感不死于预告，活在出招流（横扫 → 逼近 → 横扫）。
2. **读懂的招名累积进聚合**：读懂的招在聚合标签下挂名——「伤势 ×2：横扫、？」；越打越明直接在条上可见。名字按架势归类挂，**不显示顺序**；顺序永远隐藏，顺序感是命门级情报（「他的连招习惯」）。
3. **识破谱**：敌用过的招进「识破」面板（名字 + 效果清单），本场内可查，复活赛保留。

**干预反馈（聚合版，原则不变：反制产信息）**：

| 干预 | 聚合表现 |
|---|---|
| 晕（削段） | 被削那段的架势计数立刻 −1（伤势 ×2 → ×1，划掉动画）——告诉你削的是哪势 |
| 缴械 | 敌挂 chip；执行到攻击段时该段跳过注「缴械」 |
| 断劲 | 计数不变；敌蓝条扣；劲不足的段执行时灰留 |
| 钉 / 回马枪 | 位移段执行时步数 −N 注「钉」/ 作废注「回马」 |

玩家看到的永远是动作的直接后果，不是系统评语；机制结算一律不变。

**动词谱在聚合世界的修正**：对调（依赖可见顺序）**死亡**，从谱里拿掉；迟滞可救——聚合计数挂徽：「伤势 ×2（一迟）」，你知道有一段会晚一手，不知道是哪段。其余动词不受影响（连环 / 蓄爆 / 墙崩 / 虚招 / 读破均与顺序显示无关）。

## 2. 敌配招结构（2026-10-26 用户扩建：底座 + 二层，上限不写死）

**原则（用户拍）**：上限不定死——底座先行、二层预留接口、产能跟不上再砍、数量不写死。复杂度不管，条理要清。

**底座 · 原型池（性格骨架）**：莽夫 / 乌龟 / 游走 / 刺客 / 教头。一类架势偏一点就是一个新敌，最保守安全的底座。馆 1-3 只放莽夫 / 乌龟（新手可读），4-6 加游走 / 刺客，7+ 加教头。同大轮同一敌人配招不变，跨大轮随剧情选项变。

**二层扩展（三件，全预留接口，首版可只落一件）**：

1. **敌光环**：配招带光环词缀（「刀阵」：其伤势 +X；「铁壁」：每手开场挡 +X）。与玩家光环对轰 = 构筑对构筑。
2. **敌羁绊**：配招按牌意同源判定——某系 / 某标签牌 ≥N 张给羁绊被动（≥4 伤势 =「狂」伤 +X；≥2 墙招 = 墙词条亮起）。敌羁绊是情报与读懂的新货架（「这货有狂」）。
3. **敌牌库与成长**：敌人有牌库——**局内随回合牌库上限增多**：一场战斗有弧线，前几手基础招、越打越深（新牌进队列），TTK 锚内完成 escalation，不无头苍蝇；**轮内随馆序有成长路线**（同一大轮敌配装沿馆段升级，可读）；**轮间随种子与剧情选项变**。

**生成管线（每个敌人）**：馆段 → 抽原型 → 配牌 6-10 → 词条（墙 / 环境）→ 羁绊判定 → 光环词缀 → 成长轨（局内上限曲线 + 轮内档位）。全部数据表驱动，代码不写死原型数 / 光环位 / 羁绊位上限。配招生成进 `foeCatalog` 上层，不改 HP 曲线（NUMGEN 已落）。

## 3. 反应窗家族（L2，2026-10-29 用户亲刀拍定七系）

定义：出招中途插入的判定，耗蓝反应；**每场帽：玩家侧 1-2 次，敌方 0-1 次**——过招是点睛，不是弹幕。**反应窗跟武器系走**（与核副同轴），七系各一件。UI = 圆形弹窗：边沿进度条 = 思考时间（默认 5 秒），内写招式名 + 耗蓝。

| 系 | 窗 | 触发 | 效果 |
|---|---|---|---|
| 枪 | 回马 | 我方血 <50%（暂定）+ 背墙；敌向我位移且目的地 ≤2 格 | 敌拒在 3 格，瓦解本回合后续全部位移（含位移技能 / 招式） |
| 拳 | 截拳 | 敌存在蓄力 + 距我 ≤2 格 | 贴脸：打断 + 蓄力层清零 + 基础 1 费伤害（可被羁绊 / 兵器改变）；距 2：主动位移上去，只阻止本次 |
| 飞刀 | 断息（名待定） | 敌单纯回复（回血 / 回蓝；吸血不算） | 阻止回复 + 给等于预回复量的伤害；回蓝则扣等量蓝，敌后续按现有蓝即时判定 |
| 刀 | 弹反 | 敌贴脸；本回合每受击 2 次后第 3 段 | 格挡一部分 + 回敬一部分；计数回合清；克高连击 |
| 剑 | 偷势（名待定） | 射程内敌为叠层系别，且我方尚未给敌叠层 | 敌本次攻击叠的层转化为我的剑势层；每回合约一次 |
| 钩 | 瘸跛（名待定） | 敌从 ≤2 格向外位移、目的地 >2 格 | 拉回原位 + 上「瘸跛」；瘸跛 + 缴械 → 下两次攻击吸血 50% |
| 棍 | 透棍 | 每回合限一次；敌已有挡再加挡 | 耗蓝真伤，按敌挡层数计；可憋到敌最后一次加挡再用 |

**定位（2026-10-30 用户拍）**：中核，不是全部，不是点缀——过招系统的引擎盖、爽点四柱之一（表现 / 构筑 / 猜招 / 反制）。**数量封顶**（七系各一件，不加新窗种）、**改造打开**（羁绊 / 外功 / 心法 / 兵器强化窗 = 「反应窗流」构筑身份）、**对等补齐**（敌方窗长开）。两条设计原则：**勾引维度**——反应窗的前半局是勾引（高伤压制逼敌加挡 → 透棍亮；消耗战逼敌回复 → 断息亮；背墙站位诱敌冲锋 → 回马亮），后半局才是惩罚，敌人不做对应动作时窗不该死，玩家要有把窗「钓亮」的手段；**三重奖励检**——每件窗的收益至少占位置 / 伤害 / 资源三样里的两样（透棍单薄，补破挡）。

主窗审稿注（落码前过）：①回马以新版为准（血 <50% + 拒 3 格 + 圆窗），机制核已落码的旧版（后手 + 停 2 格）随扩包改；②飞刀窗与断劲同语义场（都扣敌蓝），触发不同可共存，文案要分清；③剑窗窄触发 = 对叠层系特攻，是特色不是缺陷；④透棍「真伤」是条件词（按敌挡层数），不许泛化成通用力量词；⑤瘸跛 / 断息 / 偷势命名过文风；⑥数值全 TBD，随第四层层帽与数值核二班。

敌方侧（精英 / 座前）：

| 窗 | 触发 | 效果 |
|---|---|---|
| 拆招 | 玩家出 4 费以上绝招 | 敌耗自己段数拆掉，绝招降效 |
| 缠手 | 玩家连出 3 张同系 | 敌插入一段逼近 |
| 读破 | 玩家同一招连用 3 次 | 敌该招免伤一次（惩罚复读） |

敌方窗给对等感，也给反制空间（预料有拆招就骗招）。**反应窗与架势咬合**：蓄势可见 → 截拳有价值；敌有读破 → 复读流收敛。

## 4. 读懂细则（L3，2026-10-26 用户改拍：重打读懂）

- **识破谱废止**。不设面板、条上不累积招名——问号满屏与「长达几排的招式」都是病，且跨敌继承会让后期自动全解锁、半明系统崩塌。
- **场内**：聚合条保持纯净（伤势 ×2 · 进势 ×1，永不挂名）；招名只在**出招瞬间**亮相 + 战斗播报可查。场内「读懂」= 玩家自己的记忆——高手记招，面板不喂。
- **场外（重打读懂）**：战斗失败后重打同一关，该敌**配招全亮**（底细级）——死了不白死，重打带着他的底。虚招敌人的「会虚招」标记随此给出。
- **跨敌不继承**：新敌人 = 新问号；每个敌人配招独立生成，前期见过的招不自动解锁后期敌人。
- **与 L0 的关系**：底细情报 = **预支的死亡经验**——同一个内容（敌配招全亮），两个获取口：花钱买（黑市 / 奖励）或花命拿（死后重打）。L0 与 L3 不再叠床架屋，是同一情报的两条命。

## 5. 情报经济（L0）

| 档 | 内容 | 获取口 | 定价锚（占位） |
|---|---|---|---|
| 风声 | 下一战敌原型 + 架势倾向 | 馆间事页免费选项（喝茶打听） | 免费 / 彩金 5% |
| 底细 | 敌配招全亮（6-10 张） | 黑市 / 奖励池「小道消息」档 | 彩金 15% |
| 命门 | 墙词条 + 反应窗 + 弱点（怕贴身 / 断劲敏感） | 黑市高价 / 赌馆赢档 / 剧情特殊选项 | 彩金 30% |

不买能打过（架势 + 读懂保底），买了能精准备战——配装界面从此有「下一场打谁」的上下文。假情报、时效：第一版不做。

## 6. 动词谱（新动词，逐条拍）

| 动词 | 效果 | 应对函数 |
|---|---|---|
| 迟滞 | 该段延后一手打出 | 爆发牌晚一手交 |
| 对调 | 敌两段顺序互换 | 读序，挡 / 闪时机重排 |
| 连环 | 两段必须连续，中间不可插 | 不能等间隙回血，提前布防 |
| 蓄爆 | 蓄势后一段大伤 | 打断窗口（截拳 / 抢杀） |
| 墙崩（词条） | 对墙边玩家专用 | 离开墙边或硬吃 |
| 虚招 | 亮出的架势是假的，出手才见真 | 只信读懂 / 反应窗；**风险件** |
| 读破 | 敌反应窗：惩罚复读 | 换招 |

**虚招风险提示**：被骗感的来源。建议只给刺客原型，且敌用过一次虚招后，读懂系统永久标记「会虚招」——被骗一次是教训，不是冤案。

## 落地节奏（四包）

1. **L1 架势 + L3 读懂**：显示层改造，不动结算——最稳的先做
2. **L2 反应窗扩**：截拳 + 敌方拆招（回马枪已落）
3. **L0 情报 + 敌配招**：内容结构 + 经济口
4. **动词逐个**：迟滞 / 对调先行，连环 / 蓄爆随棍与敌曲线，虚招最后
