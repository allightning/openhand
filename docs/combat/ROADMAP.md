## 1. 破产 & 复活经济（待实现）

### 1.1 状态机

```
正常 → [输馆且 pot < 破产线] → 破产（整局首次）
     → 弹出：赊账 + 三选一救命奖励（本局 buff）
     → 扣复活费 R(stage)，不扣光 pot
     → 满血重打本馆

再破产 → 全局失败（无第二次赊账）
```

### 1.2 复活费 `R(stage)`

建议与当馆 `P_max(stage)` 联动：

```
P_max(stage) = 模拟「从开局到该馆、每馆全押且赔率×3全中」的彩金峰值（离线表或公式）
R(stage)      = round(P_max(stage) / 3)
```

| 条件 | 行为 |
|---|---|
| `pot >= R` | 可付复活费 |
| `pot >= 2R` | 经济设计上「峰值可撑两次」（仍只允许破产 1 次） |
| `pot < P_max/3` | 破产区，**不可复活** → 直接结算 |

> 实现时先在 `gauntlet.ts` 加 `reviveCost(stage)` / `bankruptcyThreshold(stage)` 表，用测试锁 `R` 与 `P_max` 比例。

### 1.3 救命奖励（本局专用，强力）

三选一，**仅本 run 有效**，过关或全局失败后清除。方向示例（需平衡）：

| 奖励 | 效果 |
|---|---|
| 赌坊密令 | 本局每次硬拆 +2 彩金；破眼额外 +10 |
| 断头饭 | 立刻回满血 + 下 3 馆敌攻总督 −10% |
| 暗桩 | 本局开局 +2 位移充能；第一次硬拆必破眼 |

### 1.4 庄家垫资（第 1 馆）

- 删除 `WAGER_BANKER_STAKE` 全局垫资
- 第 1 馆开擂前：选「垫 40」或「垫 60」（二选一，不叠加）
- 第 2 馆起：无垫资，`stakeMax = pot`

### 1.5 替换旧「赎身」

- 旧 `redeemGauntletRun`（赔光全部彩金）→ 改为 **付 `R(stage)` 的破产复活**
- 无 pot 且不在赊账流程 → 直接出局

## 2. 黑市通胀（待实现）

在 §31.16 基础上：

```ts
price = floor(BASE[kind] × stageMul(stage) × tierMul)
stageMul = 1 + 0.35 × (stage - 1)
cap = freeRewardEV(stage) × 0.8
```

- 货物强度：金创/谱/道具/外功/淬刃 的 **品质池** 随 `stage` 和 `tier` 提升
- 不把所有变量都算死：同档允许 2–3 档随机价，留「捡漏/被宰」空间

## 3. 踢馆曲线 & 敌人编排（待实现）

### 3.1 馆序表改造

每条 `GAUNTLET_LADDER` 条目扩展：

```ts
{
  stage, enemyId,           // 主敌
  bench: EnemyId[],         // 轮番替补，路径内不重复
  waves: 1 | 2,             // 1=单人；2=主+替补轮番
  hpMul, segBonus, dmgCoef, // 现有
  rewardTier,               // 免费奖励池档位
}
```

### 3.2 不重复

- `run.facedEnemies: Set<EnemyId>` 本局已遇敌人
- `rollNextEnemy(pool)` 过滤已遇
- 第 8 馆+（无尽）：池子用尽才允许重复，且换皮肤/变体

### 3.3 梯度（解决「7 馆后都一样」）

| 段 | 馆 | 变化 |
|---|---|---|
| 教学 | 1–2 | 1 敌，低段数，明示出招谱 |
| 成长 | 3–4 | 轮番 2 敌，奖励跳一档 |
| 高压 | 5–6 | 2 敌 + 应激上限+1 |
| 峰值 | 7 | 当前难度锚点 |
| 无尽 | 8+ | `hpMul/dmgCoef/segBonus` **每馆递进**（非持平）；超级奖励频率↑ |

### 3.4 轮番上场（2 人规则）

- 场上：主角 + **1 个活跃敌人**（前排）
- 替补在侧栏显示血条；前排倒下 → 替补入场，**不清意图队列规则重写**
- 最多 2 个敌人在「本馆名单」内，不同时 3 人站桩
