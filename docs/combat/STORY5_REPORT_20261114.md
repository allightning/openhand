不等机制核六班落码。结算以后把占位键推进播报或旗标，壳层按键取句子。没改 `src/game`。

游走的原型 id 是 `skirmish`。键上写 `wander` 时读同一句。

## 血线换势

家族键 `foeStanceShift`。看见的是架势条和段数，不写「他急了」。

| 键 | 播报 |
|---|---|
| `foeStanceShift:turtle` | 他肩上的守势收下去，进势顶到条上，亮着的段数改成 X。 |
| `foeStanceShift:skirmish` | 他退着的步子停在原地，进势压到条上，亮着的段数改成 ?。 |
| `foeStanceShift` | 他的架势条换了一截，旧的段收掉，新上来的段数是 ?。 |

`foeStanceShift:wander` 等于游走那句。别的子键（教头、刺客、莽夫不变）走 fallback。最近八条播报里出现键，战斗页换成上表的句子。

## 一敌多谱 · 风声

买情报之前能读到的一句。不写伤，不写段数，不写 X 或 ?。

| 键 | 风声 |
|---|---|
| `foeVariant:brute` | 听说他这局肩往下沉，步子往前送，条上尽是进。 |
| `foeVariant:turtle` | 听说他这局脚钉在原地，肩扛着守，条上守着没有往前冲。 |
| `foeVariant:skirmish` | 听说他这局脚跟着你转，肩不落死，条上退和进轮着亮。 |

`foeVariant:wander` 等于游走那句。

## 跨轮记忆

挂在已有重打页 `s2-revive-rematch`。旗标决定把哪句放在正文前面。没有旗标时，页还是原来的「重打之前」。

| 键 | 旗标 | 开场 |
|---|---|---|
| `s2-revive-rematch:elite` | `rematch-elite` | 他认出你的脸，袖口还留着上一场溅上的血，这一把禁注，伤从满状态再算，数字是 ?。 |

## 创新思路

1. **换势用一个家族键加子键。** 龟和游走各一句，教头、刺客和认不出的来路共用 fallback，机制核不用为每种不变的原型再要一句。
2. **风声停在看见的肩和步。** 买之前只说这局他往前、钉着，还是跟着转。段数和伤留到买下之后。
3. **重打差分不另开一页。** 句子挂在已有的 `s2-revive-rematch` 上，旗标一到就放在原来的白描前面。
