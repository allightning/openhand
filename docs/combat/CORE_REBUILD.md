# P1 修订 · 核心机制重塑（深入骨髓）

> **日期：** 2026-09-05  
> **地位：** 取代 `NEXT_PHASE.md` 的 P1。旧 P1（爆点包→可读性→墨痕→多段）全部降级为「重塑定型后的抛光层」。  
> **用户拍板：** 现在的破招系统本身不认可，它是核心玩法无趣的原因；P1 = 重塑玩法与核心机制，不是修补。

---

## 一、自我否定：旧 P1 错在哪

旧 P1 的顺序是：爆点包（ juice ）→ 意图可读 → 状态可读 → 墨痕 → 多段应激 → 数值。

**这六件事全是「放大器」和「补丁」，没有一件动「核心动词」。**

给一个「对答案」系统加震动、加墨爆、加提示，结果是：**一个更好看的对答案系统**。外行第一分钟觉得帅，第十分钟发现还是那套配对作业；深度玩家反馈会更狠——「你们只是在失败的系统上撒金粉」。

用户判断正确：**先换骨头，再谈皮相。**

---

## 二、病根重诊：不是「反馈弱」，是「没有取舍」

之前我们把深度玩家的抱怨归因为「拆招反馈失败、博弈感弱」，于是开出处方「放大反馈」。这是误诊。真正的病根有三层：

### 2.1 每格都有独立标准答案

意图全明 + 破法表 1:1 对应 = **每回合是一道有标准答案的配对题**。
找到答案靠「学」，执行答案靠「点」。中间没有紧张感——因为不存在「选错」的真实风险，只存在「没背熟」。

### 2.2 资源不构成约束

对照杀戮尖塔：**它的敌方意图也是全明的**，为什么好玩？因为费用有限、手牌随机——你**看得到所有威胁，但兜不住所有威胁**。每回合的快感来自取舍：「这刀硬吃，换斩杀线」。

我们恰恰相反：看得全、也兜得住 → 没有取舍 → 没有心跳。

### 2.3 回合之间互不相欠

上一回合的选择不影响下一回合。没有铺垫、没有滚雪球、没有「我这刀拆得漂亮，下轮赚翻」的连贯感。每场战斗是 N 道独立小题，不是一盘棋。

### 2.4 一句话病根

> **我们做的是「看图对答案」，好玩的战斗必须是「有限资源下的承诺与取舍」。反馈弱只是结果，取舍缺席才是病因。**

---

## 三、好玩破招系统的四个必要条件（设计宪法）

重塑后的核心，每回合必须同时满足：

| # | 条件 | 含义 | 反面（现状） |
|---|------|------|--------------|
| 1 | **取舍** | 资源永远不够全覆盖，必须放弃一些东西 | 看得全也兜得住 |
| 2 | **承诺** | 出手不可逆，落子有代价 | 可以慢慢试、随时改 |
| 3 | **连贯** | 本回合选择改变下回合局面 | 每回合独立小题 |
| 4 | **读人** | 存在技艺性的不确定（精英/Boss 层） | 全部明牌，无猜度 |

**武侠幻想自检：** 过招的快感 = 「我读到你、我赌对了、我气势压你」。四条全中才有这个幻想。

---

## 四、三个候选核心（诚实对比）

### 方案 A · 气力承诺制（取舍为骨）

- 每回合气力有限（如 3 气），出招/架/闪全花气，气力预算 **恒小于** 全覆盖所需。
- 意图依然全明（保可读性），但你**兜不住** → 每回合选「硬吃哪段、换哪段、拆哪段」。
- **硬拆返气**：完美拆解返还 1 气 → 连拆滚雪球 → 「气势」条：连拆数越高，增益越强，断连则泄。
- 博弈点：资源分配 + 风险定价。

**优点：** 机制被验证过（StS 式张力）；改动可量化；构筑（卡牌=气的效率）立刻有意义。  
**缺点：** 骨架是借来的，需要自己的第二层（否则是换皮 StS）。

### 方案 B · 半隐读人制（读人为魂）

- 敌方只亮前 1–2 段，后段隐藏；但敌人有**起手式**（站姿/刀位/呼吸）暗示后段类型。
- 可花气「盯梢」揭示一段；不盯就是赌。
- 博弈点：扑克式读人，贴「读招」副标。

**优点：** 最贴武侠幻想；深度天花板高；直播/视频效果极好（主播猜招）。  
**缺点：** 与「意图全明防挫败」的既有方针冲突；随机性失控会毁掉硬核公平感；新玩家门槛陡增。

### 方案 C · 招路图破局制（连贯为深）

- 敌方招式互相依赖成图（扫→接刺→接架），拆关键节点 → 整路瘫痪。
- 拆的不是「这一段」，是「这条路的咽喉」。
- 博弈点：识别套路 + 选断点，跨回合规划。

**优点：** 真正的新东西，市面无同款；天然多回合连贯；硬核深度来源。  
**缺点：** 单独做核心太「解谜」——普通玩家看不懂图就无从下手；需要依附一个更直觉的骨架。

---

## 五、推荐：A 为骨 + C 为深 + B 为调味

> **一句话：把「看图对答案」改成「气力不够用的承诺制过招」，再用招路图做深度层，半隐读人只做精英/Boss 的调味。**

| 层 | 用什么 | 作用于 |
|----|--------|--------|
| 骨架（每回合心跳） | A 气力承诺 | 全部战斗 |
| 深度（跨回合棋感） | C 招路图 + 墨痕 | 精英/Boss/硬核 |
| 调味（读人刺激） | B 半隐意图 + 起手式 | Boss 与硬核限定 |
| 爽感（滚雪球） | 气势条（硬拆返气连拆增益） | 全部战斗 |

**为什么不全上 B：** 读人制是高手玩具，做主线骨架会把非深度玩家直接劝退（与「门面热闹」定位冲突）。它做 Boss 限定，反而是「终局仪式感」。

**为什么 A 必须当骨架：** 它是四个必要条件里「取舍+承诺」的直接来源，且实现风险最低、数值可调。

## 六、新核心规则草案（v0.1，可纸面推演）

### 6.1 回合结构

```
敌方亮队列（3–5 段，全明）
  ↓
我方获得气力 Q（基础 3，连拆/装备可涨）
  ↓
我方行动（任意顺序，落子不可逆）：
  · 出招卡：花气，攻击某段/某格
  · 架/闪卡：花气，应对某段
  · 过：存 1 气到下轮（上限 5）
  ↓
结算：按队列顺序逐段判定
  · 硬拆（完美克制）→ 返 1 气 + 气势 +1 + 留墨痕
  · 擦破（部分克制）→ 小伤 + 气势不变
  · 空档（未应对）→ 全伤 + 气势清零
```

### 6.2 关键新机制

| 机制 | 规则 | 设计目的 |
|------|------|----------|
| **气力预算** | 每回合气力 < 全覆盖成本（约 70%） | 强制取舍（条件 1） |
| **落子不可逆** | 出的牌进结算队列，不可撤回 | 承诺（条件 2） |
| **硬拆返气** | 硬拆返 1 气，当回合可再用 | 高手滚雪球，爽感来源 |
| **气势条** | 连硬拆 +1，空档清零；气势 3/5/8 解锁增益 | 连贯 + 可剪镜头 |
| **墨痕** | 硬拆格留痕 1 轮，敌踩痕段被克 | 跨回合布局（条件 3） |
| **招路图** | 精英/Boss 招式成依赖图，断咽喉瘫整路 | 深度层（条件 3+4） |
| **起手式** | Boss 后段隐藏，站姿暗示类型；花气盯梢揭示 | 读人层（条件 4） |

### 6.3 卡牌重排原则

- 每张卡 = 「气力效率 + 应对面 + 副作用」三元组，不再有「万能对答案卡」。
- 构筑方向 = 气的经济学：**省气流**（低费高效）、**返气流**（硬拆循环）、**蓄爆流**（存气一波）。
- 江湖线首发 3 个方向正好对应。

### 6.4 旧系统迁移

| 旧 | 新 |
|----|----|
| 破法表 1:1 对答案 | 气力预算下的应对选择 |
| 四档判定 | 保留（硬拆/擦破/空档/命中），但硬拆挂钩返气+气势 |
| 意图全明 | 普通关保留；Boss 后半段转半隐 |
| 弱点系统 | 并入招路图「咽喉节点」 |
| 墨痕（未做） | 保留，作为连贯层 |

## 八、风险（不留情面）

| 风险 | 说明 | 对策 |
|------|------|------|
| **重构代价** | 卡牌、敌人、奖励、测试基线全部作废重写 | 接受。烂核心上的一切都是沉没成本 |
| **A 骨架像 StS** | 气力+取舍是被验证的，也被做过很多次 | 气势+墨痕+招路图是我们的第二层；皮相是水墨武侠 |
| **P1.2 可能失败** | 裸原型没人想再玩 = 规则还得改 | 这正是原型先行的意义：失败成本 = 1 周，不是 3 个月 |
| **气力制数值难调** | 预算 70% 是拍脑袋，要实测 | P1.1 就把气力/成本做成配置表，可调 |
| **半隐意图翻车** | Boss 读人做不好 = 纯随机挨骂 | 起手式必须 100% 可读（图案级区分），做不到就砍 B |

## 十、拍板点

1. **骨架选 A（气力承诺）+ C 深度 + B 调味**——还是你想赌全 B（读人制主线）？
2. **P1.2 好玩验证不通过就回炉**——接受「可能多花 1–2 周改规则」吗？
3. 气力预算初始定 **70% 覆盖率**（每回合必漏至少一段）——还是更狠 60%？

默认：A+C+B 混合 / 接受回炉 / 70% 起步可调。
