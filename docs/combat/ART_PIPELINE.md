# 水墨武侠素材生产线（草案 v1）

方向：水墨武侠 · 微暗黑。参照：墨境 / 暖雪 / 影之刃 / 弈仙牌 / 大神。
用法：流程照走，提示词是「大致版」，精确措辞你自己微调。AI 工具主用即梦 / 可灵（中文水墨最强），MJ / SD 也行（附录有英文风格块）。

---

## 一、流程（六步，顺序不要乱）

### 第 0 步：风格圣经（半天，只做一次）
1. 花瓣网 / Pinterest 建情绪板，搜「水墨 武侠」「墨境」「暖雪」「国风 游戏 UI」，收 15–20 张。
2. 写一页风格圣经，就四条：
   - 色板：墨黑 `#1a1410` 底 · 宣纸米 `#e8dcc4` 面 · 朱砂红 `#c0392b` 只给关键反馈 · 大量留白。
   - 笔触：写意枯笔为主，润笔晕染为辅；不要工笔细描。
   - 禁忌：厚涂、油画、赛博、日式动漫脸、3D 渲染、照片感。
   - 「暗黑」= 压明度 + 墨晕染，不是纯黑底。
3. 打印或钉在生成工具旁边，之后每张图对照验收。

### 第 1 步：定标图（最关键）
- 挑「主角 · 待机」这一张反复生成，调到满意为止。
- 这张之后当**风格垫图**：MJ 用 `--sref`，即梦 / 可灵传参考图，后面所有图都垫它，保证全套一个画风。

### 第 2 步：战场第一批（优先级最高）
战场背景 → 主角 5 姿势 → 夜袖 5 姿势 → 刀光 / 受击 / 死亡特效 → 音效包。
理由：战斗屏是玩家 90% 时间看的屏。
姿势五个：**待机 / 主动防御 / 攻击 / 拆招应对（核心，必须有）/ 死亡**。受击帧暂时复用「防御」姿势。

**进度（2026-08-31，二次修正）**：沈夜行立绘已定标入库——**原图直用**（`public/art/char/hero/full.png`，`scripts/full_hero.py` 纯拷贝不改图，含即梦角标/印章——用户两次定稿「不用你改，大小适宜就好」；清角标版 full.jpg 与抠图版 idle.png 均已停用删除）；刀光从用户特效样式图提取白墨入库（`vfx/slash_arc.png` 弧光 / `vfx/slash_line.png` 横斩，screen 混合，演出事件自动触发）；音效 4 个 + 战斗 BGM 入库（`audio/`，设置面板双音量）。水墨匾额/3:2 画框布局**已随布局回退撤下**。

**进度（2026-09-01）**：仿沈夜行风格补齐拆招花名册 **18 人**各一张立绘（`public/art/char/<id>/full.png`，`src/art/charArt.ts` 的 `CHAR_DIR`）；踢馆 **6 张具名精英独占** + **9 张杂兵 archetype**（按门派×兵刃复用，`resolveFoeCharDir`）。局内姿势仍回落各自 `full.png`。**待生成**：沈夜行其余 4 姿势、夜袖全套、战场背景。

### 第 3 步：UI 细节
卡框纹样、状态图标、印章、门厅 / 训练馆背景。
注意：**UI 边框别用 AI 生成**（尺寸对不齐、没法九宫格拉伸）。AI 只出「纹样素材」（回纹、云纹、墨点），边框用 CSS + 纹样贴图拼。

### 第 4 步：包装层
十馆场景 3–4 套轮换、墨晕转场、LOGO、加载图、结算图、BGM。

### 每张图的验收流程
生成 → 去底（纯色底生成，remove.bg / rembg / PS 魔棒；**仓库内可跑 `scripts/cutout_hero.py`**：泛洪去纸白 + 去角落印章/logo + 裁 bbox + 缩放到 520px 高）→ **缩到游戏内实际尺寸看**（立牌约 190px 宽，缩完一团墨就重做）→ 对照风格圣经 → 按命名规范入库。

### 1. 角色：沈夜行（刀系主角）· 立绘 + 局内 5 姿势

参考图 DNA（用户 2026-08-30 选定的四张即梦图）：宣纸白底 + 淡墨远景、枯笔衣纹、朱砂红只在腰带/刀鞘/印章、斗笠为剪影识别点、立绘右上角落款印章。

**先生成立绘，满意后用即梦「角色参考」垫这张立绘，再生成 5 个局内姿势**——一致性全靠这一步。

实装备注（2026-08-31，二次修正）：立绘已生成入库，局内站位**原图直用**（`char/hero/full.png`，`scripts/full_hero.py` 纯拷贝）；清角标与抠图流程（`cutout_hero.py`）均已停用——用户明确「不用你改」。姿势图生成时仍**不要印章、不要落款**；风格需与 full.png 一致（垫「角色参考」）。当前 5 姿势全部回落 full.png，补齐哪张就把 `src/art/charArt.ts` 的 `POSE_FILE` 对应键改过去。

#### 立绘（竖版 2:3 或 3:4）

```
武侠水墨立绘，年轻刀客沈夜行，束发戴墨黑斗笠，灰白写意劲装内衬深墨，腰系朱砂红布带，手持环首单刀，刀身斜指地面，侧身而立，斗笠阴影压眉，神情沉静，写意水墨，枯笔衣纹，大块墨色，宣纸白底，远景淡墨山水一抹，右上角朱砂印章落款，全身像，竖版构图，游戏角色立绘
```

微调旋钮：想更贴参考图就把「内衬深墨」去掉；想更「夜行/暗黑」就把外衣改「墨青」。

#### 局内 5 姿势（纯白底、无远景无印章、侧面朝右、人物占画面约 80% 高）

每条开头都是同一段固定描述，**一个字别改**，只换动作句：

```
固定描述：年轻刀客沈夜行，束发戴墨黑斗笠，灰白写意劲装内衬深墨，腰系朱砂红布带，手持环首单刀
共用后缀：全身像，头顶与脚下各留少许空白，人物完整入镜不裁切，侧面朝右，中国水墨画，写意，枯笔衣纹，纯白色背景，无场景无道具无阴影无远景无印章，人物居中，2D 游戏角色素材
```

为什么这样写（实装教训）：局内精灵是「抠出来贴在石台上」用的——远景/印章/落款会被抠图脚本当背景剔除，反而增加边缘损耗；人物贴边或被裁切会让 5 张图的高矮胖瘦不一致，切姿势时闪。所以后缀里钉死「完整入镜 + 四周留白 + 无任何背景元素」。

- **待机**：`自然站立，刀尖下垂点地，呼吸沉稳，宽袖垂落，静中有势`
- **主动防御**：`马步下沉，单刀竖立身前封挡，另一手扶刀背，目视前方，戒备如山`
- **攻击**：`跨步前冲，双手挥刀斜劈瞬间，衣摆与衣袖随势扬起，刀势凌厉`
- **拆招应对（核心）**：`侧身斜立，刀身斜架于身侧作引带卸力状，似刚拨开对方兵刃，重心后坐，衣袂随转身飘动，行云流水，以巧破力`
- **死亡**：`单膝跪地，单刀脱手斜插身旁，上身缓缓前倾，斗笠低垂，脚下墨色晕染扩散`

完整一条示例（待机）：

```
年轻刀客沈夜行，束发戴墨黑斗笠，灰白写意劲装内衬深墨，腰系朱砂红布带，手持环首单刀，自然站立，刀尖下垂点地，呼吸沉稳，宽袖垂落，静中有势，全身像，头顶与脚下各留少许空白，人物完整入镜不裁切，侧面朝右，中国水墨画，写意，枯笔衣纹，纯白色背景，无场景无道具无阴影无远景无印章，人物居中，2D 游戏角色素材
```

验收：缩到 190px 宽看剪影——斗笠、单刀、红腰带三个识别点必须还在；哪个姿势的刀/腰带/斗笠飘了，就把垫图权重调高重生成。

其他角色照此换固定描述即可，夜袖示例：`黑衣女刺客夜袖，宽袖遮手，身段轻盈，墨色劲装，腕系朱砂红绳`。

### 2. 场景（横版战场背景）

```
[场景]，横版构图，近景空地留白给角色站位，远景山水淡墨晕染，中国水墨画，写意，微暗黑，夜色 / 白天，宣纸质感，2D 游戏背景
```

场景词示例：`码头石台`、`山林演武场`、`茶馆外街`、`客栈庭院`。
要点：中间区域必须空（要站角色 + 摆格子），细节放远景。

### 3. 特效（黑底白墨，代码里用 screen 混合叠加）

```
[特效]，纯黑色背景，白色与淡墨笔触，水墨飞溅，动态感强，2D 游戏特效素材
```

特效词示例：
- 刀光：`一道弧形刀光，枯笔飞白`
- 受击：`墨点炸开飞溅`
- 死亡：`大团墨色晕染扩散`
- 拆招闪光：`朱砂红笔触炸开`（这张用红墨）

实装备注：若生成图是红底/彩底（用户 2026-08-31 的样式图即红底），跑 `scripts/extract_slash.py`——按「高明度低饱和=白墨」提取到黑底，其余压黑。已入库 `vfx/slash_arc.png`（攻击/斩杀）、`vfx/slash_line.png`（拆招/受击），触发映射见 `src/art/vfxArt.ts`。

### 4. UI 纹样（只出纹样，不出完整 UI）

```
中国传统纹样，[回纹 / 云纹 / 冰裂纹]，墨线白底，扁平，矢量感，无缝平铺
```

### 5. 音效（不用 AI，去音效站搜）

爱给网 / 耳聆网 / freesound.org，关键词：
`刀剑挥砍` `拳脚命中` `纸张翻动` `水滴` `鼓点` `古琴 氛围` `箫 武侠`。
每类下 2–3 个备用，统一转成 mp3/ogg 进 `public/art/audio/`。
