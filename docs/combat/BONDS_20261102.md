# 缘分谱（2026-11-02 主窗出稿，全托版）

上位：铁律「身份层 = 职业 ∨ 缘分」。本稿 = 缘分全案：规则、进阶、18 人缘分线。命名：人物关系 = 缘分；武器系构筑 = 牌意。数值随数值阶段（标黄处另行回拍）。

## 一、规则

- **三类缘分**：特定对（A×B 旧识）/ 群像（同门 3 人组）/ 旧怨（负缘分，有牙）。
- **不配职业者必有至少一条缘分线**（18 人全覆盖）；有职业者也可带缘分（两轴独立）。
- **进阶三段**：初识 → 同路 → 生死。随剧情节点（同行程数 / 关键事页选择）推进。每段效果升级：初识 = 基效；同路 = 基效 ×1.5（取整）或附加小件；生死 = 基效 ×2 或解锁「连携」。
- **连携型缘分**：效果 = 换人后被换入者获得「自己当前武器系 × 换下者当前武器系」的 fuse 牌（见武器谱细则第四节）。
- 缘分效果只许放大当事人已有的主语（系核副 / 职业技能 / 身板方向），不发明新机制主语——与牌意同纪律。

## 五、覆盖校验

18 人每人在 ≥1 条线：特定对 8 对盖 16 人次 + 群像 6 组盖 18 人 + 旧怨 2 组盖 4 人。无孤员。新增人物进池时，必须先给缘分线再放行（写进内容验收）。
