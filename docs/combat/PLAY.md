**在线（不用装环境）：**  
https://allightning.github.io/openhand/

## 一句话玩法

单人单刀，连踢多家武馆。每场敌招**全亮**，读懂意图、走位拆招、反打取胜。  
赢一场拿战利品、攒彩金；敢下注赢更多；**输一场连胜清零**（整局有一次赊账救命）。

---

## 开局流程

1. **开踢** — 门厅大按钮  
2. **选线** — 少林寺 / 江湖 / 朝廷暗线（**肉鸽踢馆** 各 10 关；拆招是上限不是通关门槛）  
3. **选系** — 拳掌 / 棍 / 刀 / 剑 / 枪 / 钩（起手 14 张固定牌组）  
4. **庄家垫资** — 仅首馆：彩金 ×2 或 ×3（推荐敢押选 ×3）  
5. **下注** — 完璧 / 速胜 / 血战 / 不贴身 / 堆挡 / 本系刀等；连拆与破眼后期才开。可「不押 · 直接打」  
6. **战斗** — 七格石台，手牌 5 张，劲力回合恢复  

---

## 战斗里要关注什么

| 元素 | 说明 |
|------|------|
| **意图条** | 敌人接下来每一段招式的类型与伤害，全公开 |
| **拆招四档** | **破**（硬拆，反打真伤+得势）/ **让**（半伤）/ **空**（打不着）/ **打**（全额吃招） |
| **破眼** | 拆掉招眼 → 敌人失衡，承伤翻倍，处决窗口 |
| **势** | 主要从拆招来；挨打会清零 |
| **彩金** | 头顶徽章显示；过馆有底彩，下注对了翻倍 |

悬停意图段、牌面、按钮大多有 tooltip，不懂就鼠标放上去看。

---

## 过关之后

- **战间奖励** 多选一：残谱 / 外功 / 心法 / 道具 / 助战（同阶层随机）  
- **外功、心法** 要先选「给谁学」  
- **第 4 / 7 / 12 关** 可能出**伙伴**三选一（更高阶奖励）  
- **黑市** 可花彩金买货（价随馆序涨）  
- 回血约 **30% 最大气血**，劲回满，势清零  

第 7 关之后可继续无尽踢馆，或「见好就收」带着彩金上榜。

---

## 破产与赊账

- 输馆且彩金够 **复活费** → 可赊账一次：付复活费（不是全部彩金）+ 救命奖励四选一 → 满血重打本馆  
- **整局只有 1 次**赊账；再输直接出局  
- 彩金太低进「破产区」→ 不能赊账，直接结算  

---

## 反馈时请带上

1. 玩到第几馆、选的哪条线哪一系  
2. 有没有「点系别进不去」或战斗卡死（F12 控制台截图）  
3. 拆招爽不爽：**你一局硬拆了几段？哪一下最爽？**  
4. 手机 / 电脑、浏览器型号（当前主要测桌面 Chrome / Safari）

---

## 已知限制（测试版）

- 主线地图、大地图探索**未开放**，门厅里「实验台」折叠层是调参用，普通玩家可忽略。  
- 数值仍在迭代，以 `npm run test:combat` 与策划文档为准。  
- 最佳纪录存在**本机浏览器** localStorage，换设备不共享。
