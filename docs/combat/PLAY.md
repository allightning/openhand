## 两种玩法（门厅二分）

| 模式 | 一句话 | 现在能玩什么 |
|------|--------|----------------|
| **踢馆** | 肉鸽爬塔；**不破也能爬**，破招是上限 | 剧情十馆 · 无尽打榜 · 低阶入门 |
| **读招** | 硬核短拍谜题；**拆错/挨打即败**，不靠砍血 | **读招战役试玩**（五关）· 新手关/训练馆预习；周挑战即将开放 |

一句话总钩子：七步石台上，先看懂他要打哪一格，再决定你出哪一张。

## 玩家用语表（统一口径）

| 用语 | 意思 |
|------|------|
| **七步石台** | 战斗场地 7 格；站位决定打不打得到、躲不躲得开 |
| **意图 / 意图条** | 敌人接下来每一段招，全亮公开 |
| **破（硬拆）** | 合法拆掉这一段：免伤或按规则处理，并记拆、得回报 |
| **让** | 离格但没凑够硬拆条件 → 半伤 |
| **空** | 他够不着你 → 这段打空 |
| **打** | 你还在威胁里 → 全额吃招 |
| **位移** | 进步/撤步等走动牌；攒「位移」充能后才能把某些段做成硬拆（界面不强调「破招充能」） |
| **破眼** | 拆掉招眼 → 他失衡，承伤窗口 |
| **彩金** | 踢馆货币；过馆底彩、下注、黑市、榜单 |
| **替补** | 下场/下馆多一名敌人 |
| **多抽** | 营地免费奖励多抽一张 |
| **暗桩** | 情报：预知下两馆人名 |
| **底彩** | 过馆固定进账的倍率相关 |
| **黑市** | 花彩金买货的摊 |
| **支线 / N-k** | 馆间短战，不占脊骨馆号（如 5-1） |
| **入伙** | 同伴加入队伍 |
| **短打 / 禁注** | 同道短战：不占馆号、本场不能赌 |
| **开盅** | 赌摊点下去才定输赢 |

读招战役上线后，结算会更强调「拆质量」；踢馆仍以存活与彩金为主。

## 踢馆 · 开局流程

1. **开踢** — 门厅「踢馆」栏  
2. **选线** — 少林 / 江湖 / 朝廷（各 10 馆）  
3. **选系** — 拳 / 棍 / 刀 / 剑 / 枪 / 钩  
4. **庄家垫资** — 仅首馆：彩金 ×2 或 ×3  
5. **下注** — 可「不押 · 直接打」  
6. **战斗** — 七步石台；赢后营地奖励 / 黑市 → 馆间遭遇 → 下一馆  

**无尽踢馆：** 无馆间遭遇，馆序可过 10；与正赛分榜。

## 战斗里要关注什么

| 元素 | 说明 |
|------|------|
| **意图条** | 每一段类型与伤害，全公开 |
| **四档** | 破 / 让 / 空 / 打（见上表） |
| **破眼** | 招眼被拆 → 承伤窗口 |
| **彩金** | 踢馆顶栏；过馆有底彩 |

悬停意图、牌面、按钮多有说明。

---

## 过关之后（踢馆）

- 营地免费奖励（谱 / 外功 / 心法 / 道具等）  
- 黑市花彩金  
- 馆 3 / 7：**同道四具名**必选一人（伸手 / 点到 / 买命等）  
- 遭遇短文里**加黑的整句**是机制提示（如「袋里多几文彩金」）  

---

## 破产与赊账

- 整局 **1 次**赊账：付复活费 + 救命奖励 → 重打本馆  
- 再破产或彩金过低 → 出局结算
