## 两种玩法

| 模式 | 一句话 |
|------|--------|
| **行路** | 十程肉鸽。站位、构筑、彩金。**不破也能走。** 这是现在的主菜。 |
| **登门** | 硬核短拍。看懂招、站对格。登门关 + 训练馆预习。 |

七步石台上，先看他要打哪一格，再决定你出哪一张。

## 用语

| 用语 | 意思 |
|------|------|
| **七步石台** | 战斗场地 7 格 |
| **意图条** | 敌人接下来每一段招。行路里全亮；打完一段少一个 |
| **收势** | 结束你的出牌（按钮一直在） |
| **彩金** | 行路货币：当铺、事页赌馆、黑市、过程底彩 |
| **同道** | 江湖：路上帮过之后才入伙。少林 / 朝廷仍馆 3 / 7 四选一 |
| **替补 / 多抽 / 暗桩** | 下场多一个敌人 / 营地多抽一张 / 预知下两馆人名 |

## 行路流程

1. 开程 → 选线（少林 / 江湖 / 朝廷，各 10 程）→ 选系（拳刀剑枪棍钩）  
2. 开场白描（可跳过），直接第一战。不垫资，不下注  
3. 打赢：当铺 → 事页。选项才开赌馆 / 黑市 / 换城 / 追兵  
4. 整局 1 次赊账（付费满状态重打本程，禁下注）。再破产出局  

无尽行路：无程间遭遇，与正赛分榜。

战斗里看：意图、双方站位、手牌、劲、格挡/裂创等状态、收势。悬停多有说明。
