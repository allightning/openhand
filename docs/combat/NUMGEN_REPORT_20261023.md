## 创新思路

1. **冻 131 id，不读「现在的注册表长度」。** 并行窗往 `CARD_REGISTRY` 塞飞刀时，生成器仍只给开工名单报价，避免半成品入汇率。
2. **构筑层跳过，不当超带削。** 光环/连携/组合的毛当量留给牌意核，牌面生成器不拿费用×5 去砍它们。
3. **目录血 = 锚 / 梯乘子。** 只动 `foeCatalog` 也能让段内有效 HP 落进 §6；梯 hpMul 越往后越大，目录血要往下写。
4. **同 ID 跨馆跟低档。** 座前偏瘦写进报告，不把馆 5 做成 460 海绵。这是自由度铁律「有解不砍系统」在数据层的对应：先不靠加血拖时长。
5. **抽满定价，让肥牌暴露。** 若把抽折成 0，带内会假涨、`brace` 类永远看起来公平。超带名单才是给主窗的决策面。
6. **撞墙期望 0.6，不把墙伤当必中。** `push` 因此落在带内并微升到 9，而不是按 8 真伤标成超模。
