# 少林线 BGM · 普通×2 · 精英×2 · Boss×1

> 先读 `00_总则与批次说明.md`。  
> **身份证：禅堂呼吸 · 木鱼/磬/低钟脉冲 + 竹笛长音 + 古琴空弦 · 稳。**  
> 不要热闹琵琶扫弦当主驱动力（那是江湖）。时长每首 **3–5 分钟**。无词。

入库：`shaolin_normal_a/b` · `shaolin_elite_a/b` · `shaolin_boss`

---

## 普通 A · 《少林·晨钟入定》

**用途**：少林线普通馆 · 播单第一首  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，少林线普通关循环曲《少林·晨钟入定》。
场景情绪：山门晨雾，僧兵练桩；克制、沉、内力在骨里转，不是狂打。
身份乐器（必须听得出）：木鱼或磬做缓慢稳定脉冲（像呼吸），远钟偶尔一击；竹笛吹长音主句；古琴用空弦与少音点墨。可加极轻的箫垫，不要加二胡哭腔领奏。
打击：以木石感为主（木鱼、磬、轻鼓），禁止热闹锣鼓与琵琶快扫主导。
节奏：中慢到中板，方整，像马步——稳。
曲式（3–5 分钟）：钟/木鱼引入 → 笛主题 → 琴点缀丰满 → 一次克制的抬升（内力外放一瞬）→ 落回入定动机循环。
高潮：1–2 次轻推，峰要「沉厚」不要「尖锐啸叫」。
混音：殿堂残响，中低频稳，高频不过亮。
普通关：可循环、不烦、禅武感清楚。
无歌词；允许极远梵唱气声（听不清字）。
```

### 短负面

```
二胡哭腔主旋律，热闹琵琶扫弦主驱动，朝廷编钟仪仗颂，电子底鼓，流行唱词，轻佻酒肆
```

## 普通 B · 《少林·罗汉桩风》

**用途**：少林线普通馆 · 播单第二首  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，少林线普通第二首《少林·罗汉桩风》。
场景情绪：练功场上风过罗汉桩，棍影方正；比《晨钟入定》更有「形体、步伐」，仍守禅武，不开江湖酒意。
身份乐器：木鱼/轻鼓给出更清晰的步点，竹笛主题略更有棱角，古琴或中阮做低支撑；主骨架仍是少林脉冲，不是弦乐叙事歌。
节奏：中板，方正，可有短促重拍像落步。
曲式（3–5 分钟）：步点引入 → 笛/棍意主题 → 中段略紧 → 轻高潮 → 再现循环。
与 A 差别：A 入定晨钟，B 桩风形体；同族音色，旋律与律动形状要不同。
无歌词。
```

### 短负面

```
江湖二胡主奏，朝廷宫调肃杀主轴，流行唱词，电音，嘈杂市井锣鼓盖过木鱼
```

## 精英 A · 《少林·戒律如铁》

**用途**：少林线精英馆 · 播单第一首  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，少林线精英关《少林·戒律如铁》。
场景情绪：戒律压肩，对手是护寺高手；空气冷，动作更重，内力相撞有金石声。
身份乐器：木鱼/磬脉冲加密或加重；低钟更沉；竹笛句更短、更利；可加低音鼓与共鸣腔，做「铁」感。古琴可加按音噪质，增加摩擦感。
节奏：中板，密度明显高于普通关；重拍更狠，但仍方整。
曲式（3–5 分钟）：戒律压迫引入 → 主题 → 两次推进（第二次更重）→ 短收再循环。
高潮：2–3 次，峰要「厚重撞击」，不要江湖式尖叫刃光。
混音：低频更重，残响略收一点以增加压迫。
无歌词；远梵唱气声可略增，仍无字。
```

### 短负面

```
二胡领全曲，琵琶热闹扫弦主部，轻松门厅，电子舞曲，流行唱词，喜剧锣鼓
```

## 精英 B · 《少林·棍风过岗》

**用途**：少林线精英馆 · 播单第二首  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，少林线精英第二首《少林·棍风过岗》。
场景情绪：齐眉棍破风，岗上人影不动；比《戒律如铁》更「动势、直线冲力」，略少宗教压抑、略多武僧对决。
身份乐器：鼓点与木鱼形成棍击韵律，笛吹出短促冲句，可加一声远钟做段落句读；禁止改成琵琶刀马旦。
节奏：中板偏主动，重拍像出棍。
曲式（3–5 分钟）：风/棍引入 → 冲势主题 → 两三次推高 → 陡落到桩步动机循环。
与精英 A 差别：A 戒律压迫，B 棍风冲势。
无歌词。
```

### 短负面

```
江湖夜路弦乐主轴，朝廷仪仗编钟主轴，门厅空灵无战斗感，流行唱词，电音
```

## Boss · 《少林·伏魔殿》

**用途**：少林线终局 Boss  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，少林线终局 Boss 曲《少林·伏魔殿》。
场景情绪：殿门落下，罗汉阵开；这是山门最后一战，慈悲收起，只剩降魔。
身份乐器：低钟与大鼓成为重量核心，木鱼/磬仍在呼吸层；竹笛在蓄力段拉长，在爆发段收成利刃短句；古琴低音轰鸣。可加一层男声梵唱气垫（无歌词、无经文可辨），增强终局神圣压迫——仍是少林，不是西洋圣歌合唱墙。
节奏：必须有「屏息入定 → 降魔爆发」；爆发段落鼓与钟最重。
曲式（3–5 分钟）：暗殿引入 → 压抑主题 → 假高潮 → 更深回落 → **全力伏魔高潮** → 余烬钟鸣收束可循环。
高潮：至少一次全力段；要比精英明显更大、更不可回头。
混音：全批次少林曲中动态最大、低频最沉；高潮后要留得出「烟散」空间。
无歌词清唱。
```

### 短负面

```
二胡哭腔主奏，琵琶江湖扫弦主驱动，朝廷朱门宴乐，电子舞曲，流行唱词，全程平铺
```
