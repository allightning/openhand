# 门厅 BGM · 三首（空灵 / 舒缓）

> 先读 `00_总则与批次说明.md`。  
> 旧「门厅主页」曲作废，本批 **重新生成 3 首**，入库：`hall_a` / `hall_b` / `hall_c`。  
> 时长：**3–5 分钟**（不要卡死 3:00）。无词。可循环。

三首共用气质：**空灵、舒缓、远、留白**。差别只在「时辰/天气」色调，不要写成三首战斗曲。

---

## hall_a · 《静门·雾起》

**用途**：门厅默认主曲候选 A · 晨雾入馆  

### 提示词

```
游戏背景音乐，中国水墨武侠，门厅主页循环曲《静门·雾起》。
情绪：空灵、舒缓、清冷、安稳；像黎明山门未开，雾气刚起，人还没拔刀。
主导乐器：古琴主旋律（少而疏，多空弦与余韵），洞箫远句轻轻应答；极轻的古筝点缀，不要扫弦热闹。
织体：大量留白，声部要薄；可加极远的风声或水汽纹理，音量很低，当空气不是当音效炫技。
节奏：慢板，几乎无鼓；若有心跳感，只用极轻的木鱼或一击远钟，每分钟少得可以数清。
曲式（总长 3 分半到 5 分）：引入（琴独白）→ 箫进入薄层 → 中段微微丰满但仍克制 → 轻轻回落再回主题，方便无缝循环。
高潮：最多一次「轻轻抬高」，立刻落回安静，禁止战斗鼓点、禁止催促感。
混音：宽残响、远距离感，中高频柔，低频干净不轰。
风格参考气质：禅意空间乐、水墨游戏大厅，不是新世纪电子，不是流行古风歌伴奏。
无歌词，无人声清唱；允许极远气声垫底但听不清字。
```

### 短负面

```
战斗鼓点，催促节奏，电音鼓，流行男声女声唱词，热闹琵琶扫弦，二胡哭腔领奏，史诗管弦大高潮，恐怖惊吓音效， Brostep，摇滚
```

## hall_b · 《静门·雨巷》

**用途**：门厅备曲 B · 夜雨听廊  

### 提示词

```
游戏背景音乐，中国水墨武侠，门厅循环曲《静门·雨巷》。
情绪：空灵、舒缓、微潮、内收；像廊下落雨，油纸伞靠墙，灯影不动。
主导乐器：洞箫或尺八气质的长音领句，古琴用短句点墨；可加极轻的铃/碰铃远点，像檐上水珠，不要做成节奏主轨。
织体：比《雾起》略湿、略暗一档，但仍是舒缓门厅，不是悲伤叙事主题曲。
节奏：慢板，无战斗鼓；雨声纹理可有，但要低频柔和、不抢旋律、不做成写实白噪音墙。
曲式（3–5 分钟）：雨意引入 → 箫主题 → 琴与箫对答 → 中段略增一层薄弦垫（极轻）→ 收回雨意与主题，宜循环。
高潮：一次轻推即可，像风把雨帘掀开一瞬，马上合上。
混音：潮湿空间感，残响长，避免干近人声感。
无歌词；不要流行古风编曲堆砌，不要电子舞曲底鼓。
```

### 短负面

```
军鼓，战鼓，催促感，史诗合唱，流行唱词，吵闹打击乐，恐怖突然惊吓，赛博电子主节奏，二胡主导全曲
```

## hall_c · 《静门·月阶》

**用途**：门厅备曲 C · 月下石阶  

### 提示词

```
游戏背景音乐，中国水墨武侠，门厅循环曲《静门·月阶》。
情绪：空灵、舒缓、微亮、干净；像月光照在七步石台空阶上，无人比武，只剩夜色。
主导乐器：古筝以疏离单音与泛音为主（禁止密集快扫当主部），古琴低频空弦垫底，可加极轻的玻璃感钟铃远鸣。
织体：三首门厅里最「亮」的一首，但仍克制；高音要透，不要刺。
节奏：慢到中慢，几乎无鼓；允许极少的远钟作为呼吸标记。
曲式（3–5 分钟）：月色引入（高音疏点）→ 主题句缓缓成形 → 中段加一层极薄和声垫 → 主题再现并淡出到可循环的空。
高潮：轻抬一次，像云过月，瞬间回暗。
混音：夜空般开阔，高频细但不噪，低频少而净。
无歌词。这是门厅，不是 Boss，不要做成决战前奏。
```

### 短负面

```
Boss战鼓，快板武打，史诗管弦堆叠，流行人声，电子底鼓，紧张悬疑持续嗡鸣过强，嘈杂市井锣鼓
```
