# 江湖线 BGM · 普通×2 · 精英×2 · Boss×1

> 先读 `00_总则与批次说明.md`。  
> **身份证：夜路刀意 · 二胡/板胡领句 + 琵琶扫拂 · 活节奏。**  
> 不要木鱼长脉冲主骨架（那是少林）。时长每首 **3–5 分钟**。无词。

入库：`jianghu_normal_a/b` · `jianghu_elite_a/b` · `jianghu_boss`

---

## 普通 A · 《江湖路·夜雨独行》

**用途**：江湖线普通馆 · 播单第一首  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，江湖线普通关循环曲《江湖路·夜雨独行》。
场景情绪：雨夜赶路，刀在鞘里，路边酒旗湿透；有孤意，但不绝望，适合长时间多局循环。
身份乐器（必须听得出）：二胡或板胡领出主旋律（带一点滑音与气口），琵琶用短扫与滚奏做节奏与刃光点缀；可加竹笛短句穿插，但笛不要盖过二胡。
打击：轻身的板鼓/堂鼓点到为止，有脚步与刀鞘轻碰感；禁止军乐大鼓碾压。
节奏：中板，可有轻度切分，像走路；律动清楚，方便出牌呼吸。
曲式（3–5 分钟）：夜意引入 → 二胡主题 → 琵琶加入推动 → 一次轻高潮（刀意抬高）→ 落回主题变奏 → 收束可循环。
高潮：1–2 次轻推，峰要「亮」不要「炸」。
混音：略潮的夜空气，二胡靠前但不过载，琵琶中景。
这是普通关：可听、不烦、有江湖味，不是终局决战。
无歌词。
```

### 短负面

```
木鱼主脉冲，禅钟长鸣当主骨架，朝廷编钟仪仗，史诗管弦终局，电子舞曲底鼓，流行唱词，恐怖惊吓
```

## 普通 B · 《江湖路·酒旗出村》

**用途**：江湖线普通馆 · 播单第二首（A 放完切 B）  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，江湖线普通关第二首《江湖路·酒旗出村》。
场景情绪：天色刚亮，出村上路，酒意未散，刀客互相打量；比《夜雨独行》更开朗半档，仍是江湖不是庙会。
身份乐器：板胡或二胡主句更「硬朗」一点，琵琶扫弦比例略增，可加短笛对答；保留江湖弦乐身份证，不要换成古筝主奏。
打击：轻快板鼓，节奏比夜雨曲略活，仍属中板。
曲式（3–5 分钟）：脚步引入 → 开朗主题 → 中段略紧（像遇劫前的警觉）→ 一次轻高潮 → 主题再现循环。
与 A 的差别：A 偏冷雨孤意，B 偏酒气赶路；乐器家族相同，旋律与情绪必须能区分。
无歌词。普通关，禁止 Boss 级大鼓终章。
```

### 短负面

```
少林木鱼主骨架，朝廷宫调仪仗，终局史诗合唱，电子大鼓，流行唱词，同 A 旋律复制
```

## 精英 A · 《江湖路·刀口夜》

**用途**：江湖线精英馆 · 播单第一首  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，江湖线精英关《江湖路·刀口夜》。
场景情绪：夜更深，刀已出一寸；对手不是杂兵，空气绷着。比普通关明显更压迫。
身份乐器：二胡/板胡旋律更利、更短促，琵琶扫弦与绞弦噪声质感增加；可加低音弦垫或低阮，做暗压。
打击：堂鼓与板鼓密度上升，切分更凶，但仍是江湖武戏鼓，不是西洋军鼓墙。
节奏：中板偏快，或同速但织体更密。
曲式（3–5 分钟）：压迫引入（低音+碎弓感）→ 刃主题 → 两次推进高潮（第二次更高）→ 短暂收势再入循环位。
高潮：2–3 次，峰要比普通关更尖、落得更陡。
混音：中低频更沉，高音刃感更亮；不要糊成一团噪音。
无歌词。精英关：危险、锋利，尚未到「不可回头」的 Boss。
```

### 短负面

```
木鱼禅意主脉，朝廷编钟颂歌，轻松茶馆，儿歌感，电子电音主节奏，流行唱词
```

## 精英 B · 《江湖路·狭路相逢》

**用途**：江湖线精英馆 · 播单第二首  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，江湖线精英第二首《江湖路·狭路相逢》。
场景情绪：两拨人堵在窄路，先出手的活；比《刀口夜》更「对峙、碰撞」，略少阴郁、略多 sparring 张力。
身份乐器：二胡/板胡与琵琶对打感更强（句短、答快），可加锣轻亮一击做冲突点，不要改成锣鼓喧天庙会。
打击：对答式鼓点，密度高，留出呼吸空拍（空拍也要有紧张）。
曲式（3–5 分钟）：对峙引入 → 交替主题冲撞 → 两到三次推高 → 陡落回对峙动机循环。
与精英 A 差别：A 阴冷刃意，B 狭路碰撞；同族乐器，不同戏剧形状。
无歌词。
```

### 短负面

```
少林钟磬主骨架，朝廷仪式颂，轻松舒缓门厅风，史诗管弦盖过民乐身份，流行唱词
```

## Boss · 《江湖路·寨门尽处》

**用途**：江湖线终局 Boss  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，江湖线终局 Boss 曲《江湖路·寨门尽处》。
场景情绪：寨门内最后一人；刀光见底，退路没有。必须一听就是「这局不一样」。
身份乐器：二胡/板胡仍是灵魂，但音区与力度拉满；琵琶用强扫与滚奏当刃雨；可加低音鼓与深弦垫托住终局重量——重量要压在「江湖弦乐」上，不是换成西洋管弦主奏。
节奏：有「屏息段 → 爆发段」；爆发段鼓点最重，但仍可辨江湖武戏。
曲式（3–5 分钟）：不祥引入（可低吟气声垫底，无歌词）→ 主题压抑呈现 → 第一次假高潮 → 回落蓄力 → **全力大高潮**（本曲最高点）→ 余烬收束到可循环的压迫动机。
高潮：至少一次明确全力段，前后对比要强；普通/精英听完再听这首，应感到「升级到头」。
混音：低频最沉的一首江湖曲，高音刀光最亮，动态范围最大。
无歌词清唱；不要做成电影预告旁白。
```

### 短负面

```
木鱼禅堂主骨架，朝廷宫宴雅乐，轻松门厅，电子舞曲，流行唱词，全程平铺无高潮
```

## 江湖线自检

| 档 | 应听到 |
|---|---|
| 普通 | 二胡/琵琶清楚 · 能长时间听 · 有夜路或酒气 |
| 精英 | 更密、更利、更压 |
| Boss | 有蓄力与全力高潮 · 仍是江湖不是少林/朝廷 |
