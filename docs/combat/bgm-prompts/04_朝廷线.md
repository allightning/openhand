# 朝廷线 BGM · 普通×2 · 精英×2 · Boss×1

> 先读 `00_总则与批次说明.md`。  
> **身份证：仪仗肃杀 · 古筝/扬琴点线 + 箫 + 编钟/大鼓仪仗 · 方正。**  
> 不要二胡哭腔领全曲（那是江湖）。时长每首 **3–5 分钟**。无词。

入库：`court_normal_a/b` · `court_elite_a/b` · `court_boss`

---

## 普通 A · 《朝廷·夜叩衙门》

**用途**：朝廷线普通馆 · 播单第一首  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，朝廷线普通关循环曲《朝廷·夜叩衙门》。
场景情绪：夜访衙门深巷，灯笼冷，规矩比刀快；肃、净、带一点官威，但还不是问斩。
身份乐器（必须听得出）：古筝或扬琴以清晰点线勾旋律（颗粒感、珠落感），洞箫吹冷句；编钟或磬式远击做仪仗句读。可加极轻的鼓，方正打在板上。
禁止用二胡哭腔当主旋律；琵琶若出现只能点缀，不能江湖化扫弦主导。
节奏：中板，方正、仪式感，像脚步踩在石板品级上。
曲式（3–5 分钟）：巷深引入 → 筝/扬琴主题 → 箫对答 → 一次克制抬升（官威显形）→ 落回主题循环。
高潮：1–2 次轻推，峰要「冷亮」如刀鞘碰玉，不要江湖野性炸点。
混音：厅堂残响，中高频清楚，低频有但不浊。
普通关：可长时间听，朝廷味一眼可辨。
无歌词。
```

### 短负面

```
二胡哭腔主奏，木鱼禅脉冲主骨架，热闹市井锣鼓，电子底鼓，流行唱词，轻松门厅无压迫
```

## 普通 B · 《朝廷·廊下朱灯》

**用途**：朝廷线普通馆 · 播单第二首  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，朝廷线普通第二首《朝廷·廊下朱灯》。
场景情绪：朱灯照廊，文书未干，暗线在礼法下走动；比《夜叩衙门》略「华」、略「表面从容」，骨子里仍冷。
身份乐器：古筝/扬琴主句偏流转，箫更柔一点但仍冷；编钟轻点保持朝廷身份证。可加极薄弦垫增加「深宅」深度。
节奏：中板方正，律动比 A 略从容，不要写成茶馆小调。
曲式（3–5 分钟）：朱灯引入 → 华而冷的主题 → 中段暗线收紧 → 轻高潮 → 再现循环。
与 A 差别：A 夜叩肃杀，B 廊下表面从容；同族乐器，旋律气质要能分。
无歌词。
```

### 短负面

```
江湖二胡主轴，少林木鱼主轴，流行唱词，电音，狂欢锣鼓
```

## 精英 A · 《朝廷·锁链声》

**用途**：朝廷线精英馆 · 播单第一首  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，朝廷线精英关《朝廷·锁链声》。
场景情绪：诏狱气息，规矩变成锁；每一步都有品级与罪罚的重量。比普通关明显更压迫。
身份乐器：古筝/扬琴改为更短、更硬的点刺句；箫变气声更多；编钟与大鼓层加厚；可加金属摩擦质感的低音垫（抽象即可），强调「锁」。
节奏：中板，重拍更狠，休止更冷（空拍像审讯沉默）。
曲式（3–5 分钟）：锁链/压迫引入 → 审讯主题 → 两次推进高潮 → 陡落回锁动机循环。
高潮：2–3 次，峰要「冷硬裁定」，不要少林降魔钟墙，也不要江湖刀啸。
混音：中低频压迫感↑，高频金属亮边。
无歌词。
```

### 短负面

```
二胡领奏，木鱼禅意主脉，轻松华宴歌舞，电子舞曲，流行唱词
```

## 精英 B · 《朝廷·绣春在袖》

**用途**：朝廷线精英馆 · 播单第二首  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，朝廷线精英第二首《朝廷·绣春在袖》。
场景情绪：锦衣暗线，笑里有刀；比《锁链声》更「诡、快、贴身」，略少牢狱沉，略多宫廷权术锋刃。
身份乐器：扬琴或古筝快速点线制造心计感，箫句更短；编钟做不规则句读（仍方正骨格，不要乱成爵士）；鼓点更密但干净。
节奏：中板偏紧，像跟踪与反跟踪。
曲式（3–5 分钟）：窥伺引入 → 机锋主题 → 两三次推高 → 收回袖中刃动机循环。
与精英 A 差别：A 锁链诏狱，B 绣春权术；同朝廷身份证。
无歌词。
```

### 短负面

```
江湖野路主轴，少林入定主轴，门厅空灵无锋，流行唱词，电音丢拍
```

## Boss · 《朝廷·殿前赐死》

**用途**：朝廷线终局 Boss  

### 提示词

```
游戏战斗背景音乐，中国水墨武侠，朝廷线终局 Boss 曲《朝廷·殿前赐死》。
场景情绪：殿前跪与不跪之间；赐死剑出鞘，礼法走到尽头。必须一听就是朝廷终局。
身份乐器：编钟与大鼓升为仪式主重量；古筝/扬琴在蓄力段做冷点刺，在爆发段化作密集珠瀑；箫在屏息段拉长冷音。可加极低的男声齐诵气垫（无字、无经文可辨）增强「诏令」感——仍是国风仪仗，不是西洋歌剧合唱。
节奏：方正到极致；「静场屏息 → 赐死一击式爆发」对比要强。
曲式（3–5 分钟）：殿前死寂引入 → 压抑仪仗主题 → 假高潮（像宣读）→ 更深静场 → **全力赐死高潮** → 钟鼓余烬收束可循环。
高潮：至少一次全力段；全线动态最大、仪式感最满。
混音：厅殿巨大空间，低频钟鼓最沉，高潮后高频要收得干净。
无歌词清唱。
```

### 短负面

```
二胡哭腔主奏，木鱼禅堂主骨架，轻松门厅，电子舞曲，流行唱词，全程平铺无裁定感
```
