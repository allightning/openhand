# 破招深度方案（重拟）· 空间与博弈优先

> **日期：** 2026-09-05（同日晚修订：爆款约束下的落地重判）  
> **地位：** 取代「W1 = 播大声 + 馆 1 强制硬拆」为主线的思路。旧稿 `W1_DRAFT.md` 降为**辅线备忘**。  
> **你的约束（已吸收）：**  
> - 破招要有深度与博弈，但 **禁止盲加深度变成复杂难玩**。  
> - **双模式保留**：爬塔存在、不强势；硬核 = 对照实验 + 第二试验区。  
> - **反对**「第一关没硬拆就输」当留人手段。  
> - **承认** 7 格直线是博弈天花板之一。  
> - **爆款约束（同日补强，优先级更高）：** 买断制要扛住前 **1–2 小时退款窗**；需要 **15 秒可传播黄金镜头**；要 **热闹** 拉基础玩家凑场；深度玩家是长线 IP，但不能当首发唯一入口。

## ★ 爆款约束下：α / β / γ 哪个真正可落地？

### 先说结论（可直接拍板）

| 路线 | 对「热闹/15秒爆点」 | 对「基础玩家前1–2小时」 | 对「深度/IP」 | **落地判断** |
|------|---------------------|-------------------------|---------------|--------------|
| **β 墨痕** | 高（墨炸、留痕，好拍） | 中高（规则一句话能懂） | 中（加一点跨回记忆） | **首发必做、最可落地** |
| **爆点包**（旧反馈升级成「传播件」） | **最高** | **最高**（不学规则也能觉得帅） | 低（不增加博弈） | **首发必做，与 β 同捆**——这不是阿谀式「播大声」，是获客燃料 |
| **α 招路图** | 中（走对边再爆才好看；讲解易臭） | **低**（认知税，像加作业） | **高** | **可落地，但只能进硬核/精英后段**；禁止当开场主规则 |
| **γ 改拓扑** | 中（板子新奇可拍，教学贵） | **低**（重学站位=退款友好敌人） | 高（真加空间） | **首发不可行**；仅当 αβ 仍不够且有专班时开 |

**一句话：**  
真正能同时服务「凑热闹 + 少退款」的，是 **「爆点包 + β 墨痕」**；  
真正能服务「深度玩家把 IP 走下去」且仍可做的，是 **α 放进硬核/后期**，不是塞进第一小时；  
**γ 现在别开**——加深空间的同时最伤基础玩家黄金时间。

盲加 α 当主规则 = 你担心的「变复杂难玩」；只做深度不做热闹 = 买断前两小时退款。

---

### 为什么不是「主投 α+β」一张饼？

α 的问题不是不够深，是 **深在错误的层**：

- 基础玩家要的爆点是身体记忆：亮红 → 走开 → **砰·破** → 全场热闹。  
- α 要的是大脑记忆：看图选边、算支路。  
- 两者可以共存，但 **必须分层**：门面热闹，里间下棋。  
- 若第一小时就教招路图，15 秒素材会变成「UI 讲解」，传不出去。

β 正好卡在中间：规则浅、画面闹、又给深度一点「盘面有后果」。

γ 是大手术：工程、教学、品牌「七步」叙事全动，**最不像首款爆款的第一枪**。

---

### 目标重排（买断制实话）

```text
第一优先级：15 秒黄金镜头可传播 + 前 1–2 小时热闹、好懂、想再打一局
第二优先级：深度玩家在硬核/后期感到「有博弈、值得专精」（α）
第三优先级：空间大改（γ）——有证据再开
```

深度玩家重要，但是 **留存与口碑的第二引擎**；  
基础玩家凑热闹，才是 **愿望单、退款率、首发曲线的第一引擎**。  
IP 靠深度养，爆款靠热闹点火——顺序反了会两头空。

### 可传播「15 秒黄金镜头」规格（必须可剪）

固定节拍（预告片/短视频/进游戏第一场都对齐）：

1. **0–3s** 意图条亮红，威胁清楚（热闹：危险感）  
2. **3–8s** 玩家一步位移/一记反架，动作干净  
3. **8–12s** **大破**：字号、刀光、墨炸、敌受击、音效满（β 墨痕砸在石台上）  
4. **12–15s** 一句短反馈：「破！」或掉一点可见战利品跳字  

验收：不懂规则的人看完会说「好像挺帅」而不是「好像挺难」。  
这不是降低品位，是 **获客件**；深度在硬核里再给。

### 前 1–2 小时（退款窗）做什么 / 不做什么

| 做 | 不做 |
|----|------|
| 每场至少一次「看得见的热闹高潮」（不靠强制失败门闩） | 开场教完整招路图 |
| 意图一眼可读；状态少而吵 | 堆状态充深度 |
| 墨痕留在石台上（β），让重复开打有「脏了的台子」记忆 | γ 换板子重学 |
| 爬塔前几馆：**好玩、好胜、好拍** | 馆 1 未硬拆则负 |
| 硬核入口写清「试验/高难」 | 硬核当唯一主 CTA |

「热闹」≠ 无脑：是 **反馈密度与镜头密度**，不是取消拆招。

### 修正后的落地主线（取代文中「默认主投 α+β」）

首发主捆（基础玩家 / 退款窗 / 传播）：

## 2. 病根重述（比「反馈不足」更准）

现行破招的趣味结构大约是：

```text
全亮意图队列 → 对照破法表打勾 → 结算四档 → （回报偏默）
```

这更像 **批改作业**，不像 **博弈**：

| 博弈需要的 | 现状 |
|------------|------|
| 互斥取舍（拆 A 就接不住 B） | 弱；常变成「充够能拆的都拆」 |
| 跨回合记忆（我改了盘面） | 石台几乎无记忆，每回合重读红格 |
| 对手回应（他因我的拆而变招） | 有一点 pattern/应激，不够成「招路」 |
| 空间分支（站位打开不同未来） | **7 格一线拓扑太贫**，站位选择少 |
| 未完美信息或承诺（有赌） | 全亮 + 锁队，信息过满，少「赌他下一手」 |

所以：再补状态、再大声效，**不增加状态空间维度**，深度玩家仍会说博弈弱。非深度则连作业都懒得做——两边同时嫌，是结构问题。

---

## 3. 设计原则（新）

1. **试验区优先**：一切破招创新默认先上硬核关卡表；爬塔只同步「已验证切片」。  
2. **禁止用教学门闩冒充深度**：可做引导关，但通关条件不以「必须硬拆一次」当留人核心。  
3. **空间必须加维**：要么改拓扑，要么在 7 格上加 **第二轴/记忆层**；禁止「只加更多意图 kind」。  
4. **拆是走路线，不是打勾**：一次硬拆应改变「下一张招路图」或「石台局势」，而不只是免伤计数。  
5. **反馈是税后的利息**：玩具可玩之后，再统一高潮包与可读性（旧 W1-A/B/C 可择要并入）。

## 4. 创新方向（三选一为主，可混）

下面三个都比「播大声」新。建议 **主投一个做可玩原型**，另外作废或降级，避免又平行开火。

---

### 方向 α ·「招路图」Break Route（推荐主投）

**一句话：** 敌人亮的不是一串孤立段，而是一张 **小招路图**（3–5 个节点）。你的硬拆是在图上 **选边走**；走通打开杀机/破绽节点，走偏则敌切支路压你。

**为何新颖：** 把「读招」从批改变成 **走图博弈**（接近卡组构筑里的路线选择，但是战内、空间耦合）。竞品少有「全亮意图 + 图行走」。

**与七格关系：** 节点绑定 **站位条件**（在某格/某距/某面向才能走这条拆边）。7 格仍窄，但 **决策对象从「段」升级为「边」**，有效策略空间大于格数。

**最小原型（硬核 3 关）：**

| 关 | 教什么 |
|----|--------|
| Rα1 | 一张三节点直线路：拆①→打开②的杀机格 |
| Rα2 | 分叉：拆上路得势，拆下路安全但慢 |
| Rα3 | 拆错进支路：敌加一段压打；可再拆扳回 |

**爬塔薄版：** 普通敌仍可用线性队列；精英/Boss 才挂招路图（不强势，但存在辨识度）。

**风险：** UI 要画小路图；需克制节点文案。  
**不做：** 一上来全图鉴 50 种路。

---

### 方向 β ·「墨痕石台」Stage Memory（强力搭档 / 可与 α 合并）

**一句话：** 硬拆在威胁格留下 **墨痕**（1–2 回合）。下轮意图踩痕：被克（易拆/降伤）或被激怒（改路）。石台有记忆，站位有跨回含义。

**为何补博弈：** 解决「每回合盘面无历史」；在不增加格数时增加状态。

**最小原型：** 仅打击/抢步硬拆留痕；痕上再拆有加成；敌「避痕」AI 一条规则即可。

**风险：** 痕迹 UI 脏；要严格上限（同时最多 2 痕）。

---

### 方向 γ ·「改拓扑」环台 / 双轨（空间真理党）

**一句话：** 承认直线 7 格不够，改品牌几何——例如 **六环 + 中宫**，或 **5 格 × 上下盘**，或 **7 格 + 面向/肩线第二轴**（人占一格，刀势占邻接「势格」）。

**为何：** 直接提高邻接与夹击可能性；博弈最「硬」。  

**代价：** 工程与教学最重；品牌「七步」要重解释（七步可改为「七势」或保留七步为丈量单位而非七格）。  

**建议：** 作 **备选大改**；仅当 α+β 原型仍被深度判「博弈不够」时启动。不要与 α 同周开工。

## 5. 推荐总案（已按爆款约束修正）

```text
首发主捆：爆点包 + β 墨痕
深度长线：α 招路图 → 仅硬核试验区，验证后再薄接入精英/Boss
暂缓：γ 改拓扑
爬塔：热闹优先；普通关不塞 α；存在但不靠门闩留人
```

### 5.1 为什么不拿「馆 1 强制硬拆」当支柱

- 留人靠的是 **重复欲望**，不是第一次打勾成功。  
- 强制硬拆要配套：教学、锁牌、失败解释、难度——**配套很大，收益是一次性**。  
- 与「破招深度不够」的真问题错位。  
- 硬核试验区里可以有 **教学关要求演示一种拆边**，那是实验协议，不是爬塔留人策略。

### 5.2 双模式怎么分工（落地）

| 阶段 | 硬核（试验区） | 爬塔（弱存在） |
|------|----------------|----------------|
| 现在→原型 | 只在此实装招路+墨痕 | 规则暂不动或仅同步反馈小修 |
| 原型通过 | 扩 5–8 关对照旧规则 | 精英/Boss 接入招路薄版 |
| 未通过 | 改 α/β 或启动 γ 讨论 | 不把失败规则灌进十馆 |

## 6. 90 日路线（重拟，替代旧 W1→W2→W3）

### P0 · 共识与对照台（约 1 周）

- 冻结：馆 1 强制硬拆通关 **不做**。  
- 硬核入口标明「试验区 / 对照」。  
- 定一页「旧规则 vs 招路规则」对照表（给测试者）。  
- 可选：踢馆仅修「破招被 climbBreakLight 压音」——属卫生，不宣称解决深度。

### P1 · 可玩原型（约 3–4 周）· 只在硬核

**交付物：**

1. 招路图数据格式 + 3 关（Rα1–3）  
2. 墨痕 v0（硬拆留痕、上限 2）  
3. 拆边成功/失败的 **局势变化** 必须可见（打开节点 / 切支路）  
4. 基础可读：节点上写清「要站哪、出什么类牌」——否则试验无效  
5. 录屏：同关「旧线性拆」vs「招路拆」并排说明差异（对照实验）

**通过标准（比「大声效」硬）：**

- 至少 2 名深度玩家：**愿意再开一局试另一条拆边**（重复意愿）  
- 能口述「我在走哪条路，代价是什么」  
- 不要求非深度爱上；非深度可只观察是否「看得懂在下棋」

**失败则：** 改节点数量/绑定条件；仍失败 → 评审 γ，而不是加门闩。

### P2 · 反馈与可读成为放大器（约 1–2 周）

在 P1 通过后，把旧 W1-A/B 里有用的部分接到 **新玩具** 上：

- 走对边 / 走错边 的视听高潮（比四档更贴新语义）  
- 意图/节点信息清晰  
- **仍然不要**爬塔馆 1 强制硬拆

### P3 · 爬塔薄接入（约 2–3 周）

- 普通关：保持简单线性或极简一路图  
- 精英/Boss：挂招路  
- 肉鸽奖励开始出现「专拆某类边」的牌——这时 W2「构筑方向」才有意义  
- 黑市/赌馆仍可后置；无深度玩具时做它们是空转

### P4 · 若仍嫌空间不够

- 启动 γ 小原型（环台或双轨）仅硬核 1 关对比  
- 通过再谈品牌改名与全量迁移

## 7. 与「不够新颖」的对齐

本方案的新意不在文案，而在 **玩法状态机**：

| | 旧 | 新（α+β） |
|--|----|-----------|
| 决策对象 | 段是否破 | 图上走哪条边 |
| 盘面 | 无记忆红格 | 墨痕改变未来威胁 |
| 对手 | 队列兑完 | 支路切换 = 可见回应 |
| 试验方式 | 爬塔与硬核糊在一起 | 硬核对照实验，爬塔弱跟随 |

若你还觉得不够新，下一层才是 γ（改拓扑）或更激进的「双棋子：人与刀势」——但那是第二笔赌注，建议先让 α 被骂够、改够。

拍板后下一步：写 **「爆点包 + 墨痕」垂直切片规格**（含可剪 15s 验收），α 另开硬核 1 关试验规格——两套文档，避免又糊成一套复杂主规则。

---

## 10. 结语

加深可以，但 **加深不能当门面**。  
买断制爆款靠的是：基础玩家觉得热闹、前两小时不想退、随手能发出 15 秒帅镜头；  
深度玩家靠硬核/后期把 IP 走远。  

**真正可行落地的是 β + 爆点包；α 可行但必须关在试验区；γ 现在不可行。**  
盲加 α 当主规则，就是你说的「复杂难玩」——那条路我收回「默认主投」。
