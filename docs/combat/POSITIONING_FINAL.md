# 定位终审 · 明手：七步石台

> **日期：** 2026-09-05  
> **性质：** 不留情面、不计代价的定位终审。项目初期，连名字都可以改。  
> **核心问题：** 7 格确实很少，能接纳的玩法很少；我们的游戏定位到底是什么？总时长多少？后续是否持续更新？最准确的定位是什么？

---

## 一、先回答最狠的问题：7 格是不是死局？

**是，也不是。**

| 看法 | 判断 |
|------|------|
| 7 格能做出深度博弈 | **错。** 7 格一线拓扑太贫，站位选择少，博弈天花板低 |
| 7 格能做出热闹爆点 | **对。** 亮红 → 应对 → 大破，外行能看懂，可剪 15 秒 |
| 7 格能撑起 20+ 小时 | **错。** 重复感会在 3–5 小时杀死非深度玩家 |
| 7 格能撑起 5–8 小时 | **对。** 如果每场有热闹高潮、有记忆（墨痕）、有构筑差异 |

**结论：** 7 格不是死局，但 **7 格 + 深度博弈** 是死局。  
7 格的正确用法是：**浅规则、高反馈、可传播、短时长**。  
深度博弈必须靠 **α 招路图（硬核试验区）** 或 **γ 改拓扑（暂缓）** 来补，不能靠 7 格本身。

## 二、总游戏时长：多少才够？

### 2.1 买断制市场现实

| 时长 | 定价区间 | 玩家预期 | 我们的能力 |
|------|----------|----------|------------|
| 2–4 小时 | $5–10 | 「小品」「demo 感」 | 能做到，但对不起「武侠卡牌」的期待 |
| 5–8 小时 | $10–15 | 「完整小品」「值回票价」 | **推荐区间** |
| 10–15 小时 | $15–20 | 「正经独立游戏」 | 需要三线 + 遭遇 + 构筑差异，产能吃紧 |
| 20+ 小时 | $20+ | 「大作」「持续更新」 | 7 格撑不住；需要 γ 或持续内容 |

### 2.2 推荐：**5–8 小时主线 + 硬核试验区无限重玩**

| 模式 | 时长 | 内容 |
|------|------|------|
| 踢馆主线（一条线通关） | 3–4 小时 | 10 馆 + 遭遇 + 营地 + 黑市 |
| 踢馆三线全通 | 6–8 小时 | 三线差异 + 构筑方向 |
| 读招硬核 | 无限 | 周挑战 + 招路图 + 对照实验 |
| 无尽踢馆 | 无限 | 打榜；无遭遇；馆数不停 |

**关键：** 主线 5–8 小时是「值回票价」的底线；硬核/无尽是「留下来」的理由。  
不要假装能做 20 小时；7 格做不到，做了也是注水。

## 三、后续是否持续更新？

### 3.1 买断制独立游戏的现实

| 模式 | 优点 | 缺点 | 适合我们？ |
|------|------|------|------------|
| **一次买断，不更新** | 简单；无运营压力 | 无长尾收入；无社区 | **不推荐** |
| **一次买断 + 免费更新** | 口碑好；社区活 | 无持续收入；产能压力 | **推荐（若首发成功）** |
| **一次买断 + DLC** | 持续收入；内容扩展 | 分割玩家；DLC 疲劳 | **备选（若首发成功且产能够）** |
| **免费 + 内购** | 长尾收入 | 与买断制定位冲突 | **不做** |

### 3.2 推荐：**首发 5–8 小时 + 免费更新（若成功）**

| 阶段 | 内容 | 条件 |
|------|------|------|
| 首发 | 踢馆三线 + 读招硬核 + 无尽 | 必须 |
| 更新 1（1–2 月后） | 新线 / 新 Boss / 新遭遇 | 首发成功（愿望单 >5k 或首周 >1k） |
| 更新 2（3–6 月后） | α 招路图全量 / γ 改拓扑 | 深度玩家留存好 |
| DLC（可选） | 新门派 / 新模式 | 首发成功且产能够 |

**关键：** 首发必须完整；更新是奖励，不是补完。  
不要首发半成品靠更新补——买断制玩家不吃这套。

## 四、最准确的定位是什么？

### 4.1 排除法（不留情面）

| 定位 | 为什么不是 |
|------|------------|
| 「深度博弈卡牌」 | 7 格做不到；深度玩家会嫌浅 |
| 「动作武侠」 | 没有动作手感；是回合制 |
| 「肉鸽爬塔」 | 爬塔壳有，但核不是构筑多巴胺 |
| 「解谜游戏」 | 太硬；非深度玩家不进 |
| 「休闲武侠」 | 太硬；休闲玩家不懂拆招 |

### 4.2 最准定位（一句话）

> **「七步石台上的读招武侠卡牌——先看懂他要打哪一格，再决定你出哪一张。」**

更狠的版本：

> **「外行看热闹（亮红 → 应对 → 大破），内行看门道（拆招博弈），硬核玩试验（招路图）。」**

### 4.3 定位分层

| 层 | 定位 | 目标人群 | 时长 |
|----|------|----------|------|
| **门面** | 热闹武侠卡牌 | 基础玩家 / 主播 / 短视频观众 | 前 1–2 小时 |
| **里间** | 读招解谜 | 深度玩家 / 策略爱好者 | 5–8 小时主线 |
| **试验室** | 硬核博弈 | 核心粉丝 / IP 养料 | 无限重玩 |

## 五、名字要不要改？

### 5.1 「明手：七步石台」的问题

| 问题 | 严重度 |
|------|--------|
| 「明手」不直观 | 中（需解释） |
| 「七步石台」暗示 7 格 | 高（7 格是天花板，不是卖点） |
| 整体偏文艺 | 中（不够「武侠」不够「热闹」） |

### 5.2 改名方向（若改）

| 方向 | 例 | 优点 | 缺点 |
|------|-----|------|------|
| 强调「读招」 | 《读招》/《看破》 | 直接 | 太硬，不热闹 |
| 强调「石台」 | 《石台》/《七步》 | 保留品牌 | 仍暗示 7 格 |
| 强调「武侠+拆」 | 《拆招》/《破招》 | 直接、热闹 | 可能太直白 |
| 强调「明手」保留 | 《明手》副标改 | 保留 IP | 副标要更准 |

### 5.3 推荐：**暂不改名，改副标**

```
明手：七步石台
副标：先看懂他要打哪一格，再决定你出哪一张
```

若首发后「七步石台」被证明是负担（玩家嫌 7 格少），再考虑改名。  
**现在改名的成本 > 收益。**

## 六、为什么爆的是我们不是别人（AI 时代终审）

| 别人的 AI 游戏 | 我们的 |
|----------------|--------|
| AI 生成图 + 通用玩法 | 爆点包 = 实机可验证的玩法镜头 |
| 灵感多，执行散 | 爆点包是规格 + 验收，能写进工单 |
| 深度靠堆系统 | 深度靠 α 试验区，不塞进第一小时 |
| 热闹靠买量 | 热闹靠可剪镜头，主播自来水 |
| 退款靠祈祷 | 退款靠前 1–2 小时热闹密度 |
| 定位模糊 | 定位分层：门面热闹 / 里间解谜 / 试验室硬核 |
| 时长注水 | 时长诚实：5–8 小时主线 + 无限硬核 |

**核心：** AI 让灵感贬值，让 **可执行的规格** 升值。  
我们的护城河不是「7 格」，是「**外行看完觉得帅、内行打完觉得有博弈、硬核愿意专精**」的同一套镜头。

## 七、最终建议（不计代价）

| 项 | 建议 |
|----|------|
| **总时长** | 主线 5–8 小时 + 硬核/无尽无限 |
| **后续更新** | 首发完整；成功后免费更新；DLC 备选 |
| **定位** | 门面热闹 / 里间解谜 / 试验室硬核 |
| **名字** | 暂不改；副标强化「读招」 |
| **7 格** | 承认天花板；用爆点包+墨痕做热闹；用 α 做深度；γ 暂缓 |
| **爆点包** | 可剪 15 秒镜头，不是音量包 |
| **爬塔** | 热闹主门；普通关不塞 α；存在但不强势 |
| **硬核** | 试验区 + 对照实验；养深度与 IP |

---

## 八、一句话终审

> **7 格是天花板，不是死局；用爆点包做热闹，用墨痕做记忆，用 α 做深度，用硬核养 IP；主线 5–8 小时，首发完整，成功后免费更新；名字暂不改，副标强化读招；AI 时代爆的是可执行的规格，不是生成的灵感。**
