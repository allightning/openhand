> **拍板：** 只做江湖线；少林/朝廷封线（界面显示「后续开放」）；产能全压单线质量。

## 一、P1 · 单局战斗完善（最核心，3–4 周）

> 目标：**一场战斗本身就是一个好玩的玩具**。外行觉得帅，内行觉得有博弈。  
> 这是所有后续内容的地基：奖励、营地、黑市、遭遇全是「为了下一场战斗服务」。

### 1.1 爆点包（S1 并入，1 周）

| 项 | 内容 |
|----|------|
| 四档感官身份证 | 硬拆/擦破/miss/命中 各一档：屏幕震动幅度、墨色飞溅、音效、字色 |
| 硬拆大顿 | 硬拆瞬间 120–200ms 顿帧 + 墨爆 + 低鼓 |
| 可剪 15 秒 | 一场战斗至少一次「值得录屏」的瞬间 |
| 敌方出手前 1.5s 停顿 | 已有，保留并调优 |

**出口：** 录屏 15 秒给没玩过的人看，对方问「这什么游戏」。

### 1.2 意图可读性（S4 前半并入，1 周）

| 项 | 内容 |
|----|------|
| 意图功能名 | 意图格子显示「扫/刺/架」功能名 + 图标，不只显示伤害数字 |
| 破法提示 | 长按/悬停意图格，显示「用什么破」 |
| 队列全貌 | 敌方 3–5 段队列一眼看完，当前段高亮 |

**出口：** 新玩家第一局就知道「这一格该出什么」。

### 1.3 状态可读性（S4 后半并入，0.5 周）

| 项 | 内容 |
|----|------|
| 状态三件套 | 每个状态：图标 + 一句话作用 + 来源（谁给的/为什么有） |
| 状态获得瞬间 | 弹一行小字「获得 XX：效果」 |

**出口：** 玩家不再问「这状态干嘛的」。

### 1.4 β 墨痕（S2 并入，1 周）

| 项 | 内容 |
|----|------|
| 规则 | 硬拆成功后，该格留「墨痕」1 轮；敌方下轮踩痕段被克 |
| 表现 | 格子上淡墨渍，踩中时墨色爆开 |
| 深度 | 玩家开始想「这刀拆哪格，下轮赚更多」 |

**出口：** 深度玩家反馈「有记忆点，想再拆一次」。

### 1.5 多段队列 + 应激（0.5–1 周）

| 项 | 内容 |
|----|------|
| 多段队列 | 精英/Boss 队列 3–5 段，段间有互克关系 |
| 应激 | 被硬拆后，敌方追加一段应激（怒击/回架），队列可视化 |
| 节奏 | 每场战斗从 2–3 分钟 → 4–6 分钟（不堆血，堆段） |

**出口：** 单场战斗时长翻倍，但不靠海绵血。

### 1.6 战斗数值打磨（贯穿）

| 项 | 内容 |
|----|------|
| 江湖线 10 馆曲线 | 每馆难度阶梯、敌血量/伤害、我方成长全部重调 |
| 敌种差异 | 江湖线敌人各有「招路性格」（莽/稳/阴），不只数值差 |

**出口：** 10 馆打下来有「越打越难但越打越会」的曲线感。

**P1 总出口：** 江湖线一场普通战斗 4–6 分钟，外行觉得帅，内行觉得有博弈；可剪 15 秒镜头；新玩家第一局会玩。

## 二、P2 · 肉鸽奖励完善（2 周）

> 目标：**每次奖励选择都有「我想要」的感觉**。

| 项 | 内容 |
|----|------|
| 构筑方向条 | 配装界面明示本体系标签：位移流/反架流/出血流（江湖线先做 3 个方向） |
| 奖励染色 | 免费奖励标注「强化你的 X」或「新开 Y 线」 |
| 卡牌池重排 | 江湖线卡牌按 3 个方向分组，每张卡有明确归属 |
| 奖励三选一 | 每馆后奖励三选一（可刷新一次），不再被动给 |
| 银两奖励 | 战斗奖励与银两挂钩，硬拆多给银两（喂经济系统） |

**出口：** 玩家在第 3 馆就能说出「我这把走 XX 流」。

---

## 三、P3 · 营地新机制（1–2 周）

> 目标：**营地不只是回血点，是「构筑的另一半」**。

| 项 | 内容 |
|----|------|
| 营地三选一 | 每馆间营地：回血 / 强化（升级一张卡）/ 换牌（删一换一） |
| 篝火对话 | 营地短文案（2–3 句），给路线倾向标签 |
| 预览下一馆 | 营地可看到下一馆敌人类型（不完全，给倾向） |
| 休整抉择 | 高风险高回报选项：「不休息，下馆奖励 +50%」 |

**出口：** 玩家在营地停留 1–2 分钟，有真实抉择。

---

## 四、P4 · 黑市 + 经济系统（1–2 周）

> 目标：**银两有地方花，黑市有「今日钩子」**。

| 项 | 内容 |
|----|------|
| 银两闭环 | 战斗赚 → 黑市花 → 变强 → 打更难赚更多 |
| 明星货 | 每摊 1 件「今日钩子」：强力但贵或带副作用 |
| 商品分层 | 普通货（卡/药）/ 明星货（构筑核心）/ 赌货（随机） |
| 赌馆重做 | 赌馆与黑市合并或独立，赌的是「构筑方向」不是纯随机 |
| 价格曲线 | 越往后越贵，逼玩家前期做选择 |

**出口：** 玩家会为了「攒银两买明星货」而主动打硬拆。

---

## 五、P5 · 遭遇 + 剧情（1–2 周）

> 目标：**遭遇有路线感，剧情不是套皮奖励**。

| 项 | 内容 |
|----|------|
| 遭遇密度 | 每馆间 2–3 个遭遇（客栈/岔路/伏击/同道/情报） |
| 路线反馈 | 选完显示倾向标签（如「偏向：杀伐」），影响后续遭遇池 |
| 剧情摘要 | 营地可看本局已选路线的一句话摘要 |
| 江湖线剧情 | 只写江湖线一条完整剧情弧（10 馆 + 结局） |

**出口：** 玩家能复述「我这把走了一条什么路」。

---

## 六、P6 · 整体 UI 样式（1–2 周，可穿插）

> 目标：**界面摆放、UI 设计统一，不像原型**。

| 项 | 内容 |
|----|------|
| 战斗界面 | 石台、手牌、意图、状态、队列的布局重排 |
| 门厅/选线 | 封线后的选线界面、门厅布局 |
| 配装/黑市/营地 | 三个界面统一语言（墨色 + 纸质） |
| 动效 | 界面切换、卡牌打出、奖励获得的动效统一 |
| 字体/字色 | 全游戏字体层级统一 |

**出口：** 截图能直接当商店图。
