## P1 · 独立硬核点：资源走哪

登门没有随机卡牌运。牌从哪来，决定玩家死在「没抽到」还是死在「没看懂」。三个候选都满足「不进肉鸽奖励池」。差别在取舍发生在进门前、进门后，还是根本不发生在牌上。

现行训练场已经有一套燃料：气力开局 3、每拍回 3、帽 5；拆费 2、硬拆还 1；盯梢 1。正名局沿用这套燃料。本稿不新造货币，不改这些数。数值阶段再动。

### 候选 A · 固定军械库（推荐）

进任何一位大师的门，手里都是同一套已知动词：拆·压、拆·点、拆·引、架、闪、进步、撤步、攻、过、盯梢。绝式仍要气势满 8，不另发牌。没有三选一，没有战前漏带，没有关卡解锁。

循环：

1. 进门看见习惯表的公开份数（一番刺 3、扫 2、撞 1）。表上是人的脾气。牌不在这张表上。
2. 三番用这一套牌打。每一拍气力不够同时押满三段。取舍发生在看见刀、看见红格的那一下。
3. 他按你硬拆过的式、躲开的格改下一番的权重和落点。你的牌不变，他的出法变。
4. 赢走他的招不往你手里加按钮。见 P3：该式以后不再诱，权重减一档。你少被骗，他少用这一式。

爽点：招你都会，气不够全押。看懂刀平就押拆·点，看错就挨这一段，收势当拍能指出是刀看错了还是格站错了。和黑神话式 Boss 战同一类快感：死亡来自这一手的判断，不来自背包。

和行路的差异：行路的洞靠下一馆的奖励补。登门的洞在这一拍的气力。行路可以换一套构筑绕过没读懂的架势。登门绕不过，因为下一场牌还是这一套。

### 候选 B · 关卡内解锁

开局发拆里的一张，加上移动。硬拆对某一式之后，该式的对策或「用他的这一式」解锁，带进下一番。

循环：一番用残手试探 → 读对就变长 → 三番用他的招打他。

爽点：成长看得见。策略定调里「赢走他的招」有一个按钮可以按。

和行路的差异：行路的新牌从奖励屏来，和这一战读没读懂无关。登门的新牌从这一战的正确拆来。

不推荐。输家工具更短，复盘句容易变成「这一式还没解锁」。赢了变强，读人变成场内养成，靠近肉鸽的奖励曲线。正名要的是同一套工具打出不同判断。

### 候选 C · 战前预算制

军械库公开，进门前用固定槽数勾选本番带上石台的牌。槽数少于全动词，三拆不能齐带。番与番之间用同一笔预算重选。没有随机掉落。

循环：看习惯表 → 勾牌 → 打完 → 他按你带的牌和你的拆改表 → 重勾 → 再打。

爽点：开打前就有一次承诺。二番重勾是「他读过你的准备」的对策。

和行路的差异：行路的配装跨十馆，牌从路上来。登门的勾选对这一位大师有效，打完清空，不进下一座。

不推荐作正名主模型。开打前的勾选本身有对错：没带拆·引，撞来了，句子是「我没带这张」。北星要拿掉的配装运，会从十馆缩成三番，仍是配装。验收句要的是读招。打包对错留在备选里，第一场不要这条。

登门新设计页上的「手牌即阵型」（行路已否决，备忘留给登门）属于这一类的加强版：从左到右就是连招序。第一场不上。理由和预算制相同，并见文末创新思路。

### P1 结论

| | 固定军械库 | 关卡内解锁 | 战前预算 |
|---|---|---|---|
| 牌从哪来 | 进门就齐 | 读对才长出来 | 进门前勾 |
| 取舍发生在 | 看见刀的那一拍 | 解锁之后的番 | 进门之前 |
| 输了的句子 | 刀或格 | 还没解锁 | 没带那张 |
| 随机卡牌运 | 无 | 无，有场内成长 | 无，有战前配装 |

主模型用 A。B 的「赢走」收成信息，不收成新牌。C 留作以后若要加密度时的备选，不进第一位大师。

## P2 · 过招在登门

### 两套核

行路结算在 sim：血、劲、抽牌、配装、职业、缘分、七系核副。登门结算在 qiCommit：架势条、气力、气势、起手、诱、墨、拆。两核并列，互不调用。共享停在石台的几何和「这一段打完，画面再改这一段的条」。

登门板沿用现行 7 格、两端有墙。行路 9 格、高侧单墙。正名不靠多两格，本稿不改板。

| | 行路 sim | 登门 qiCommit |
|---|---|---|
| 胜负条 | 血 | 架势（你 12 / 这座 14，沿用现行数） |
| 燃料 | 劲，回合结束回 | 气力，每拍回，帽 5 |
| 牌 | 配装 ×3 摸进来 | 军械库固定，不摸 |
| 人 | 三人、换人、缘分 | 你一个，对面这一位 |
| 半明 | 类型计数；顺序默认藏 | 段序和红格亮；招种藏在起手里 |
| 虚 | 架势标签是假的 | 起手是假的，真招不动 |
| 插入 | 七系反应窗，耗蓝 | 一种改口窗，耗气力 |
| 重打 | 该敌配招全亮 | 暗段仍扣；门厅留一句复盘 |

「像而底层不同」落成这四对，不要再加第五套名词。

### 架势：同字两物，登门不引进六类

行路的架势是意图类型：伤势、进势、退势、守势、蓄势、诡势。条上写「伤势 ×2 · 进势 ×1」。顺序默认隐藏，亮招档才按段打开类型。

登门的架势是胜负条。段上公开的是序、红格、起手（刀下 / 刀平 / 收刀）。蓄力段照旧全亮，没有起手。

登门不挂六类聚合。挂了之后，玩家读的是「这手是伤还是进」，刀的三式就空了。行路的半明是类型。登门的半明是刀。

### 顺序：登门更明

主张：**登门亮顺序。** 队列从左到右就是他这一拍的出法。每一段标红格。藏的是这一段的刺、扫、撞。

行路把顺序做成商品（常规藏，亮招买前几段，底细买全）。登门的顺序不卖。卖顺序会和行路抢同一笔情报钱，也会把「看书」变成登门的解。登门没有黑市买招。若要风声，风声给习惯表里哪一式份数高。某一拍的段序不卖，进门就亮。

这是更硬的半明：格和先后你都看见，招种要自己认。认错当拍就挨打，不隔一轮才告诉你。

### 虚招：登门就是现有的诱

行路虚招（页 9，已拍）：架势标签是假的，出手才见真；虚段和真段完全同形；虚招里的招不能被反应窗自动获取；只给刺客原型；反制是亮虚招情报、刺客职业、重打读懂。

登门虚招：**起手换成另一式，真招不动。** 首拍不诱。之后约 1/6。三把刀都长那样，没有第四种刀，这就是登门的「完全同形」。盯梢花 1 气，播报写明真招，诱被拆穿。

登门不再叠一层「类型造假」。两层虚叠在一起，玩家分不清是刀骗了人还是标签骗了人，验收句说不出口。

已识破的式（P3 学走招）不再诱。未识破的式仍按 1/6。

### 反应窗：更少，不更多

行路：七系各一件，耗蓝，每场玩家 1–2 次，默认思考 5 秒，圆窗。定位是中核里的一柱，数量封顶。敌方窗从精英馆起。

登门主张：**不搬七系窗，不加第八种系窗。每番 1 次，思考 3 秒，耗气力 1。** 名字叫改口。

触发：你已经把一张拆落在暗段上，这段出手时起手和真招不符（诱），或这段以后填了 fork、走到了另一支。窗里两枚按钮：维持原拆，或把这张承诺改成躲（人仍须在能躲的规则里；改完站错格，这段仍按打空结算）。

改口不造成伤害，不削他的架势，不回气。它修正你已经写下的那一笔。行路的窗是插进去打。登门的窗是承认自己看错了刀，当段改口。

更多窗会把登门打成第二套弹窗构筑。登门没有反应窗流，没有刺客职业，没有外功强化窗。硬核来自窗短、窗少、窗不输出。

没诱、没分叉的拍，窗不弹。玩家不能靠窗白看真招。

### 读懂：死了留一句，不留全亮

行路 L3：失败后重打，该敌配招全亮。场内聚合条不挂招名。

登门重打：三番从一番重开，权重回到 3/2/1，暗段照旧扣着。门厅留上一趟的一句，例如「刀平。你拆了压。」下一趟不因此把刀平改成明牌。

全亮暗段等于把登门的题买掉。行路的全亮配招合理，因为行路平时根本不给你段序。登门平时已经给你段序和红格，再全亮招种，正名局就变成背谱。

### 边界（以后落码时遵守）

- sim 不读气力、架势条、起手、诱、改口。
- qiCommit 不读劲、抽牌、配装、职业、缘分、六类架势、七系窗。
- 过招四个名字可以两边都用（情报 / 架势 / 反应窗 / 读懂）。填进去的东西按上表分套，不共用数据结构。
- 行路窗族的封顶不动。登门改口不算第八件。

## P3 · 三番原型三件

沿用原型卡已拍的部分：半隐 C、起手三式、首拍不诱、后续 1/6、打空算躲、招路分叉 B 的字段先留着。结算数字沿用 qiCommit，本稿不改。

### 1. 权重 3/2/1：用

一番公开：**刺 3 / 扫 2 / 撞 1**，合计 6。和 1/6 的诱放在同一分母上，玩家能说「刺占一半」。每式最低 1，他不会把一式删掉。你没带对策的那一式仍可能出现——在固定军械库里对策都在，最低 1 的意义是：你拆得最多的那式会变少，不会消失，三番都还有得读。

抽的是真招。起手跟着真招。诱时起手改成另外两式之一，真招不动。

| 番 | 权重怎么变 | 落点 |
|---|---|---|
| 一番 | 3 / 2 / 1，不改 | 按座前：第一段亮，后段扣 |
| 二番 | 一番里硬拆次数最多的那式 −1，最低停在 1 | 你躲开次数最多的那一格，成为二番优先红格 |
| 三番 | 学走招里的每一式再 −1，最低仍是 1 | 红格规则同二番，按二番的新记录再算 |

平局：硬拆次数相同，减当前权重最高的那式。权重也相同，先减刺（公开默认）。复盘写出来：「刺和扫你都拆了两次。刺的份数高，刺减 1。」

一番什么都没拆中：权重原样进二番。他没有从你身上学到洞。

权重不改伤害，不改气力。它决定下一番抽到哪一式。

### 2. 架势跨番。气力不跨。气势不跨。墨不跨

三番是一场。架势是这一场的胜负条。跨番：一番看错刀，条上的缺口留到二番。你可以一番换信息、二番承伤、三番收。每番回满架势，三番就成了三场小关，误读没有利息。

气力不跨。每番第一拍从开局 3 起，帽仍是 5。「过」存下的 1 气在番末清掉。气力跨番会变成囤燃料，靠近行路的劲。登门的取舍应每拍重新做。

气势不跨。番末归 0。跨番可以一番堆到 8、二番开场绝式，三番被滚雪球盖住，读招让位给资源。绝式仍可以在同一番里打出来。

墨不跨。番末清格。墨留在训练场的动词课。这位大师的记忆在权重和红格上。

### 3. 第一场 fork：不填

招路分叉 B 已拍要留。字段保持 `fork: null`。第一场的队列不放承 / 合。

第一场同时有习惯表、半隐、诱、三番。再加「一段两支」，误读变成三轴：刀、格、支。验收句说不全。B 的兑现放到第二位大师，或这位大师的再战：承段亮，合段扣，合用另一把刀。那时候玩家已经能分开刀和格。

第一场不回答「分叉的另一支是脚本还是再抽一次」。字段空着，这个问题不必先答。

### 学走招（配合固定军械库）

原型卡把 `learnedByYou` 写成你获得的招。本稿改含义，不改「赢走」这四个字：

- 二番结束时，你硬拆对过的每一式标成可学。
- 三番你赢：这些式进入识破。之后（含这一场已经结束的结算展示，以及若以后再战这位）该式起手不再诱，权重再 −1。
- 三番你输：不识破，不加。
- 手里不出现新牌。军械库仍是进门那一套。

复盘句（番末，不写在选项上）：

- 输：「刀平。你拆了压。」或「人在 2。红格在 4。」
- 赢：「他刺最多。二番刺少了。」

一句里一件事。刀和格分两句时，取这一番第一次掉架势的那一段。

### 三件对照

| 挂账 | 推荐 |
|---|---|
| 一番权重 3/2/1 | 用。最低 1。平局先减份数高的，再先减刺 |
| 架势、气力跨番 | 架势跨。气力不跨。气势不跨。墨不跨 |
| 第一场 fork | 不填。字段留空。B 留给下一位或再战 |

## 第一场轮廓

一位未命名的大师，座前壳。一场三番。牌是固定军械库。习惯表从 3/2/1 起。半隐、诱、盯梢、打空算躲沿用已拍规则。改口窗每番最多 1 次。没有六类架势，没有七系窗，没有战前勾牌，没有 fork。

胜负：任一番结束时有人架势到 0，这场结束。三番打完他的架势仍大于 0，你输。你的架势先到 0，你输。

重开：权重回到 3/2/1，暗段照旧。门厅留上一句复盘。

训练场 R1–R8 与进修 R5 / 座前不改目标、不改数字。它们教动词。这一场才是正名。

## 创新思路

1. **对偶半明。** 行路亮类型、默认藏顺序。登门亮顺序和红格、藏招种。以后凡是「两边各藏一半」的设计，先问藏的是类型还是招种，避免两套半明藏同一件事。
2. **军械库固定，成长记在他身上。** 识破 = 该式不再诱 + 权重 −1。不发新按钮。正名局的成长：你更不容易被这个人骗。
3. **改口是登门唯一的插入。** 短、少、不输出。窗里改的是已经写下的承诺。行路窗继续按七系封顶，两边不共用窗表。
4. **重打留句，不留答案。** 和行路「死了换全亮配招」对偶。登门的死换来一句人话，下一趟题还在。
5. **条跨番，燃料不跨番。** 误读有利息，囤气没有利息。气势、墨跟着燃料清。以后加登门资源，先问它是条还是燃料。
6. **手牌即阵型先不进第一场。** 登门新设计页已记下：行路否决「左到右 = 连招」，认为适合登门。若主窗以后要密度，建议做成番间排一次序：他看得见从左到右（晕先锁左），看不见你这一拍把哪张按在哪一段。第一场不上，避免复盘句变成「闪排左了」。
7. **权重最低为 1，减的是你拆得最多的那式。** 他变，但三式都还在。复盘可以生成，不靠策划为每一番写死队列。
