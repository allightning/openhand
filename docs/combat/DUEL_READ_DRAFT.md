## 已拍板

| 项 | 决定 |
|----|------|
| 冻结 | 只锁 **七格** + **全亮意图**。拆四档 / 拆势 / 破眼 / 应激都不锁。 |
| 全亮 vs 对线 | **不冲突。** 当前条 = 他**下一回合**要出的，全亮、你出牌期间不改。结算后他根据**这一回合你的操作 + 场上**重排；你再看到的那一条，才是改进后的计划（即「下下回合」那一轮全亮）。 |
| 刀 | **贴脸（dist=1）保持高数值**（伤档第二，低于枪 3–4 格）。**距 2 必须低伤**。流血等副机制暂不动。简单上手保留。 |
| 池子 | 心法 / 外功 / 助战 **全程可出**。淬刃、换页 = **3 馆战后开始进池**，权重随机，不保证每馆都有。绝招 = **7 馆战后进池**，同样不保证。配对靠随机会到，才有爽感。 |
| 黑市 | 与免费池 **同一张闸**：池子里还没有的，黑市也不能提前卖。 |
| 应激 | **1–2 馆强制帽 0**。 |
| 不做 | 强制新手、隐藏意图、出牌中途改队列。玩家卡池不新开机制族。敌意图与破法表的扩张见 `ENEMY_DIVERSITY_DRAFT.md`（含「撤」「追」）。 |

伤档名次（未换页、无拆势）：**枪（距 3–4）> 刀（仅贴脸）> 剑 > 钩中下 > 拳 = 棍**。

奖励时间轴：

```
馆 1–2 战后     薄：心法 / 外功 / 助战 / 道具 / 同档加牌
                不出：淬刃、换页、±2、绝招

馆 3 战后       二档选人（人）
                淬刃、换页 **开始进池**（随机，可能没有）
                淬刃顶 2

馆 4–6 战后     中期加厚：上列全有，淬刃/换页权重起来；±2 可进
                仍不是「只有淬刃换页」

馆 7 战后       三档选人；绝招 **开始进池**（随机，可能没有）
                淬刃顶 3

馆 9 后         4 选 3
馆 10           无战后成长
```

对线 AI 输入（生成**下一条**全亮队列时）：你的兵器、这一回合你走了哪、当前距离、他的劲/血/架、他自己的兵器。  
馆 1–2 只温和进/撤 1 格；馆 5+ 才换位连撤。

## 下一批改进（按序）

现行缺口 1–5 已落地（2026-09-01）。对线 AI 仍待做。

### 1. 打击反馈（手感第一刀）✅

拆 / 让 / 空 / 打 / 拆势打出 / 劲尽跳过：各自 **飘字 + 意图段章 + 音**（至少两条通道）。血条可以慢一拍。  
验收：不看血条能分清这六件事。

### 2. 池闸对齐（内容曲线）✅

- 1–2 馆：免费 + 黑市都不出淬刃、换页、绝招。  
- **3 馆战后**：淬刃、换页进权重池（可不出）。淬刃顶 2。  
- **7 馆战后**：本系绝招进池（可不出）。淬刃顶 3。  
- 心法 / 外功 / 助战 / 道具：1 馆起就可出。  
- `marketOffers` 与 `pickWeightedKind` 共用 `rewardGate(fought)`。

### 3. 1–2 馆无应激 ✅

阶梯写死 `stressCap: 0`，开战 `applyStageTuning` 覆盖默认帽 3。硬拆不挂「应」。

### 4. 刀距伤 ✅

`斩`（及刀系主攻）：dist=1 维持高数值；dist=2 掉到中低档。流血暂不改。枪 2/3/4 格 4/7/10 仍为最高档。

### 5. 意图条：会不会打出来 ✅

每段常驻：落点、`打`/`空`、耗劲、劲不够则 `跳过`。吐纳 / 卸力 / 回血成为常见段，玩家能读「他为什么出这招」。

### 6. 对线 AI（读你，下一轮全亮才改）

并入 `ENEMY_DIVERSITY_DRAFT.md` D 批（套件 + 撤 + 读兵器）。本条不单开。
