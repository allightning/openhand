## HUD 五处

1. **意图条。** 段继续 `flex-wrap: wrap`。带子最高 7.4rem，多出来的段在带子里滚动，不把牌手区往下挤。
2. **阶段条。** `.lab-phase-slot` 高度锁在 1.7rem。空的时候仍留 `is-idle` 占位，`data-phase` 在 `idle` / `live` 之间换，槽不增不减。
3. **状态 chip。** 一列最多 6 个，多的收成「还有 N」。被收的名字和数字留在隐藏的 `.status-chip-rest` 里。列本身可换行，最高 8.5rem。
4. **预演条。** 牌名一列，括号构成和括号后的效果留在 `.preview-paren` 同一串里，右对齐。不改 `damageBreakdown`。对不上时「待 · 核玩」仍单独一列。
5. **牌手区。** 底栏改成三列网格：左侧兵器和 chip、中间手牌、右侧敌方兵器和 chip。手牌 `margin-left` 从 -36px 改为 0，多牌横滑，不再叠牌。弃牌、置换、换人、收势在动作行里 `position: static`，放不下就换行。

## 创新思路

**环境视觉。** 词条是石台的材质，不是多一条 HUD。灼烧是颜色和一点朱砂，无墙是墙自己断掉，缺格是台面缺一块、那格不能落。三套都用 `data-env` 开关，不在 CSS 里写伤害或概率。文案键 `env.*` 空着，遭遇窗以后把句子填进来，画面不用改结构。

**守卫。** 按钮重叠用排盒子证明，不用截图。样式表导出 `--hud-action-btn-w`、`--hud-card-w`、`--hud-intent-w`、`--hud-action-gap`。测试按这些数从左往右排，排不下就换行，再两两看相交。手牌叠不叠直接读 `margin-left`。相交函数单独有一条会红的例子，守卫坏了自己先红。

**可读性取舍。** 手牌不再用负边距叠成扇形，5 张并排，多了横滑。意图条自己滚动，悬停说明可能被带子裁一点，换来的是牌手区不被段数撑走。阶段条用固定高度，空和有字占的地方一样。预演的构成和括号后效果留在同一串文字里，方便朗读，也让旧断言「）裂创」还在。chip 从第 7 个起收成「还有」，名字仍在 DOM 里。

**值得写进渲染规范的。**

- 石台列数跟 `data-board` 走，禁止再写死 7 列网格。
- 墙是格外元素，禁止用 `cell.wall` 表示行路的单墙。
- 阶段条用固定高度占位，禁止有字才插入、没字就拿掉。
- 按钮组打 `data-overlap-group`。宽度写进 `--hud-*`。新按钮先过 `noOverlap.test.ts`。
- 环境词条只加 `data-env` 和 class，不在壳层写数值。
