# 上架总路线 · 从现在到发行

> **状态：** 2026-09-03 定稿（产品路线，随执行滚动修订）  
> **前提：** 主线地图继续冻结；只做 Combat Lab。  
> **产品结构：** 同品牌双模式——**踢馆肉鸽** 与 **读招破招**，各带剧情模式 + 无尽/打榜。  
> **关联：** [RULES.md](./RULES.md) · [ROGUE_GRADIENT.md](./ROGUE_GRADIENT.md) · [ROADMAP.md](./ROADMAP.md) · [PLAY.md](./PLAY.md)

## 0. 一句话目标

做出一款能在 **Steam（或等价 PC 商店）软发售** 的武侠七步石台战斗游戏：

| 模式 | 卖点 | 剧情 | 无尽 |
|------|------|------|------|
| **踢馆肉鸽** | 选线 · 构筑 · 彩金风险 | 三线十馆 + 遭遇树 | 馆数 / 彩金打榜 |
| **读招破招** | 读意图 · 站位 · 完美拆 | 章节谜题关 + Boss | 周种子 / 连破分榜 |

对外一句话（上架期只押一个钩子，另一句作副标）：

> **七步石台上的读招武侠卡牌——先看懂他要打哪一格，再决定你出哪一张。**

## 1. 当前基线（起点）

### 1.1 已有

- 门厅：正赛开踢、无尽踢馆、低阶/新手关、训练馆、实验台
- 肉鸽：三线、十馆脊骨、垫资、赌馆、营地/黑市、赊账/带伤、同道 3/7、遭遇树 + N-k 支线
- 战斗核：7 格、意图全亮、六系距离与特色、拆招四档内核、枪拨杆等手感补丁
- 工程：`npm run test:combat`、Pages/Cloudflare 可玩、原画 LFS

### 1.2 未有（上架前必须补齐的大块）

- 读招破招 **独立产品线**（剧情章 + 专属无尽）
- 发行包装（商店页、预告片、定价、成就、云存档策略）
- 前 30 分钟「陌生人零说明书」体验验收
- 内容厚度到「一周回访」量级
- 稳定真机打磨与平台合规

### 1.3 明确不做（到 1.0）

- 解冻大地图 / 主线 RPG
- 实时联机 PVP
- 重度内购抽卡（若上架以买断为主）
- 为爆款并行铺开所有系统（先竖切再加厚）

## 2. 阶段总览

| 阶段 | 名称 | 目标产物 | 建议周期* | 出口验收 |
|------|------|----------|-----------|----------|
| **P0** | 定锚与门厅 | 双模式信息架构冻结 | 3–7 天 | 门厅文案二分；文档口径一致 |
| **P1** | 破招竖切 | 30 分钟可传播 Demo | 4–8 周 | 陌生人能录出「一破」高光 |
| **P2** | 肉鸽可卖竖切 | 一条线通关可感完整 | 3–6 周（可与 P1 尾重叠） | 新测 70%+ 能打完十馆或明确败因 |
| **P3** | 双模式加厚 | 内容与打榜齐 | 6–10 周 | 两模式各有剧情+无尽；周挑战可转 |
| **P4** | 打磨与包装 | 软发售候选包 | 4–6 周 | 商店页+预告片+稳定性门槛 |
| **P5** | 软发 → 1.0 | 上架与热修 | 持续 | 愿望单/评测反馈闭环 |

\*周期按 **1 名主程 + 你（策划/手测/文案）** 估算；加人可压缩，但内容产能仍是瓶颈。

```
现在 ──P0──► P1 破招竖切 ──┐
                           ├─► P3 加厚 ──► P4 包装 ──► P5 上架
        P2 肉鸽竖切 ───────┘
```

**铁律：** P1 未做出可剪辑高光前，不全面铺遭遇/牌种；P4 前不定死第二平台。

## 4. P1 · 读招破招竖切（上架钩子，优先）

### 4.1 产品规格

| 项 | 规格 |
|----|------|
| 体量 | **8–12 关**锁牌谜题 + **1 个综合 Boss** |
| 时长 | 熟练 20–30 分钟；首通 40–60 分钟 |
| 胜负 | 指定破法达标 / 段段硬拆 / 限伤通关（按关配置） |
| 构筑 | **锁牌或极窄牌池**；手法优先 |
| 结算 | 拆质量为主（硬拆数、受击、用时）；少彩金 |
| 入口 | 门厅「读招」；可与现有新手关六局合并/升级，不另起炉灶浪费 |

### 4.2 关卡内容表（建议稿）

| 关号 | 教什么 | 敌意图焦点 | 锁牌提示 | 通关条件（例） |
|------|--------|------------|----------|----------------|
| R1 | 红格与退步 | 打击 | 进步/撤步/卸力 | 受击 ≤1 |
| R2 | 位移充能 → 硬拆 | 打击×2 | +位移牌 | ≥1 次硬拆 |
| R3 | 让 vs 硬拆 | 连打 | 格挡牌 | 用「让」活过一轮后再硬拆 |
| R4 | 追撤段 | 撤/后退类 | 朝他进步 | 追成功 1 次 |
| R5 | 反架 | 卸力/架 | 破绽类 | 破架 1 次 |
| R6 | 枪距 / 拨杆 | 点枪+贴身 | 枪套 | 在 2–4 格打出有效伤 |
| R7 | 桩与冲锋 | 冲锋/落桩 | 棍或进步 | 破冲锋或砸桩 |
| R8 | 多段队列 | 混合 3 段 | 综合小池 | 一轮内 2 次合法拆 |
| R9 | 应激预告 | 带应签 | 同上 | 不吃满额应打 |
| R10 | 换人节奏（可选） | 双人意图 | 含换人 | 指定同伴上场拆 |
| RB | Boss 综合考 | 三循环套路 | 本章牌库 | 三阶段；每阶段强制一种破法 |

> 关名、叙事口吻走少林/江湖/朝廷三皮之一即可，**不必**三线全做。

### 4.3 工程要点

- 新 `breakCampaign`（或扩 `breakDemo`/`trainingHall`）跑剧情章；**复用** `sim` / 意图 / 破法表
- 关卡数据：JSON/TS 表（敌、锁牌、胜负谓词、教学气泡）
- 结算屏：可复制「战报短链/图」——服务预告片与社媒

### 4.4 验收（P1 出口）

- [ ] 未玩过的人按提示能打完 R1–R4
- [ ] 至少 3 段成片素材：亮意图 → 位移 → 硬拆反馈 → 战利品/结算
- [ ] Boss 关失败有明确「缺哪种破法」提示
- [ ] `test:combat` 覆盖胜负谓词与关卡加载

## 5. P2 · 踢馆肉鸽竖切（可卖的一条龙）

与 P1 尾可重叠，但 **人手不足时让路给 P1**。

### 5.1 范围（先做「一条线完整」）

优先 **江湖线** 打磨到「可单卖 demo」；少林/朝廷保持可玩，文案与遭遇可后刷。

| 块 | 内容任务 |
|----|----------|
| 前 3 馆 | 零说明书能赢；应激帽 0；奖励薄池按 `ROGUE_GRADIENT` |
| 遭遇 | 关键句加黑定稿；每线客栈/岔路/伏击/赌摊 **有效差异** ≥ 现状 |
| 同道 | 3/7 四具名；短战/买命手感验收 |
| 终局 | 人海/座前/私了差异可感知 |
| 反无脑 | 六系各至少 1 条「乱点吃亏」；不强制破招通关 |
| 无尽 | 过 10 后梯度可读；本机榜保留，全球榜可放到 P3 |

### 5.2 内容加厚清单（P2 最低）

| 类型 | 数量目标 | 说明 |
|------|----------|------|
| 具名敌人可辨 | ≥18（已有骨架则补齐身份/招式别名） | 不重复路径规则保持 |
| 谱牌可感差异 | 每系主攻+副攻+状态+步法齐，通用功能牌 6–10 | 重复上限 3 已落地 |
| 遭遇有效选项 | 每线每事件类型 ≥4，且机制句清晰 | 支线 N-k 每线至少 1 条常驻 |
| 同道 | 18 人可用池维持 | 馆 7 同门优先保留 |

### 5.3 验收（P2 出口）

- [ ] 5 名新测：≥3 人能说明「彩金 / 替补 / 多抽」在选遭遇时的含义
- [ ] 江湖线完整通关录像 1 条（含终局）
- [ ] 无尽打到 12+ 馆不崩、难度有感知递进
- [ ] `test:combat` 绿

## 6. P3 · 双模式加厚（冲软发内容量）

### 6.1 读招模式加厚

| 项 | 目标 |
|----|------|
| 剧情章 | **3 章**（每章 6–8 关 + Boss）；每章只引入有限意图子集 |
| 无尽 | **周种子关** + 排行维度：完美硬拆、受击、用时 |
| 分享 | 战报卡（静态图或短链） |
| 与肉鸽关系 | 进度 **分存**；破招教会的手法以「可选高收益」回灌踢馆，不改「不破也能爬」 |

### 6.2 肉鸽模式加厚

| 项 | 目标 |
|----|------|
| 三线 | 少林/朝廷遭遇与终局文案补到与江湖同级 |
| 支线 | 每条脊骨线至少 3 个可进支线点（仍不占馆号） |
| 牌/人 | 按 `ROGUE_GRADIENT` 闸把淬刃/换页/绝招手感做满 |
| 无尽 | 正赛/无尽分榜；可选「见好就收」已有则打磨文案 |
| Boss | 馆 10 三终局手感再拉开一档 |

### 6.3 系统债（穿插，按痛点插队）

来自 [ROADMAP.md](./ROADMAP.md) 仍有价值的项，**按玩家抱怨优先级**吃，不平行全做：

- 敌劲条 / 出招谱 UI  
- 7 馆后梯度与奖励感  
- 黑市/复活经济手感复验  
- 武器神技有代价  

### 6.4 验收（P3 出口）

- [ ] 读招 3 章可通；周挑战可换种子重打
- [ ] 肉鸽三线均可通关且遭遇不「换皮重复」
- [ ] 内部「一周日常」试玩：至少 3 次主动回访理由（榜/周关/另一线）

## 7. P4 · 打磨与发行包装

### 7.1 质量门槛

| 项 | 标准 |
|----|------|
| 崩溃 | 完整通关路径 0 硬崩；`test:combat` + 烟测清单 |
| 存档 | 局内退出可续；版本迁移策略写明 |
| 分辨率 | 1080p / 1440p / 笔记本 1366 宽可玩；UI 不裁死 |
| 无障碍最低 | 色弱可辨意图威胁；关键操作有键鼠路径 |
| 性能 | 中端机战斗 UI 流畅；大图 LFS 加载有进度或预载策略 |

### 7.2 包装清单

| 交付物 | 说明 |
|--------|------|
| 商店名 / 副标题 | 中英各一版定稿 |
| 胶囊图、头图、截图 5–8 | 至少 2 张破招高光、2 张踢馆遭遇/营地 |
| 预告片 60–90s | 前 5 秒必须出「读招→硬拆」 |
| 愿望单页文案 | 短：钩子；长：双模式说明 |
| 定价假设 | 买断档位研究（参考同体量独立）；首发折扣策略 |
| 成就 / 统计 | 首通、无尽馆数、完美拆、三线等 |
| 年龄分级与内容描述 | 暴力表现等级自检 |
| 隐私/遥测 | 若做分析，需明示；可先做本地统计 |

### 7.3 平台建议（1.0）

1. **首选 Steam 软发售**（愿望单 + 评测）  
2. Web 试玩（现有 Pages）作漏斗，**试玩进度不与买断强绑**亦可  
3. 主机版 / 移动版：**1.0 后**再评估操控与 UI

### 7.4 验收（P4 出口 = 可提审/可软发）

- [ ] 商店页素材齐；预告片过你本人「愿不愿转发」测试  
- [ ] 外测 20 人问卷：前 30 分钟去留原因有数据  
- [ ] 已知 P0 Bug 清零；P1 Bug 有清单与时限

## 12. 决策冻结（避免路线摇摆）

1. **双模式**，不是两款独立 App。  
2. 肉鸽 **不破也能爬**；破招线 **不破不能过**。  
3. 上架期对外钩子 **先押读招高光**；肉鸽作深度与时长。  
4. 地图主线 **1.0 前不解冻**。  
5. 未达 P1 出口前，禁止开「大重构拆招公式」除非堵死竖切。
