# 洛阳·天津桥 绝对基准（截图态）

最后锁定：2026-08-23（玩家截图确认）

## 基准是什么
玩家满意的《洛阳·天津桥》状态：
- **建筑 / 墙体 / 洛水 / 天津桥布局**保持现有 `luoyangGen` 骨架，不得推翻
- **局内人物**使用 `/art/sprites/sprite-*.png` 小模型（截图中的灰色小人体系）
- **局内景物**以树、木桶、灯笼、炉火等基础物件为主，疏密有致
- **对话栏头像**可用 `/art/stand/*.png` 立绘（与局内模型分离）

## 绝对禁止
1. 用 `/art/stand/` 立绘图片当作局内 actor 模型
2. 运行时 SVG / Canvas 画 NPC 小人
3. 为凑校验删 NPC / 删物件
4. 推翻天津桥 / 洛水 / 院落墙骨架

## 增量方向（在本基准上做，不许推倒重来）
1. 把重复的灰色小人，**逐个**换成独立 `sprite-<id>.png` 局内模型（同等像素风，非立绘）
2. 丰富景物种类（多树种/摊位/石碑等），保持疏密，不塞满
3. 具名 NPC 对话头像独立映射，单张全城占比 ≤30%
4. 数量参考：NPC≈57、树≈12–15、桩≤10、车≤8、木桶≤6

## 技术锚点
- 局内：`cutSprite` → `spriteSrc()` → `/art/sprites/`
- 头像：`stand()` / `getPortraitSrc()` → `/art/stand/`
- 布局：`src/map/luoyangGen.ts`
