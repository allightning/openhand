## 试用四条（直接贴 Lovart）

先在 Lovart 建 Brand Kit（或每条开头重复「风格锁」）。有沈夜行立绘就当参考图垫上。

### 0. 风格锁（每条前面都带）

```
项目：水墨武侠卡牌肉鸽《明手 / Openhand》Combat Lab。
风格：中国写意水墨，枯笔为主、润笔为辅，微暗黑（压明度+墨晕，不是纯黑赛博底）。
色板必须遵守：底墨黑 #1a1410，面宣纸米 #e8dcc4 / #f4ead6，朱砂 #c0392b 只点缀关键反馈（印章、腰带、一处血/印），大面积留白。
禁止：厚涂、油画、赛博朋克、日式动漫脸、3D渲染、照片、霓虹、金粉堆砌、满屏红、英文字体花体、完整游戏UI边框和按钮。
文字若出现：用宋体/楷意味道的中文短词，不要长文，不要口号哲理。
```

### 1. 先看画风：情绪板

```
（先贴风格锁）
出一张横版情绪板，2×3 或 3×2 宫格，六张小图拼在一张画布上，不要做成可点击界面。
六格分别是：①宣纸上的枯笔刀客剪影（斗笠）②茶馆庭院远景淡墨 ③朱砂小印落在米纸上 ④墨点飞溅 ⑤空石台七格示意（只画地面格子，不要按钮）⑥门厅匾额纹样局部。
统一色板。用于确认 Lovart 能不能稳住水墨，不是出成品入库。
尺寸：1920×1080。无水印、无英文标题。
```

### 2. 最有用的一张：无缝纹样

```
（先贴风格锁）
中国传统回纹+细云纹，墨线，宣纸米底，扁平，可无缝平铺。只要纹样，不要边框、不要按钮、不要人物、不要字。
用于以后 CSS 九宫格贴边，所以边缘必须能 tile。导出 PNG。正方形 1024 或 2048。
```

### 3. 包装：告捷笺（不是局内 HUD）

```
（先贴风格锁）
一张竖版游戏结算插画/笺面氛围图，不是可点界面。
内容看见的：米纸笺铺在墨色上，笺上只有三个字「告捷」，小朱砂印一枚，远景淡墨屋脊。不要血条、不要手牌、不要菜单按钮、不要英文 WIN。
留出上下空白，以后程序会叠真正的按钮。
尺寸：1080×1350。
```

### 4. 营地氛围（中间要空）

```
（先贴风格锁）
横版游戏背景：客栈内堂或庭院石桌，近景地面留大块空，给人物和货架卡片站位；细节放远景梁柱、灯、淡墨窗外。
写意水墨，2D 游戏场景。不要在图上画按钮、货价数字、对话框。不要人物特写抢中间。
尺寸：1920×1080。
```

试完看三件事：色有没有漂、朱砂有没有满屏、缩到手机宽还像不像水墨。纹样能 tile、告捷没有假按钮，就算 Lovart 值得继续用。
