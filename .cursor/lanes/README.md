# 踢馆车道 · 怎么开新对话

**主窗 = 爬塔核玩（肉鸽核心玩法）。** 其余车道都服务它。

同步不靠闲置聊天互相「记得」。各窗共同读一份短板：

**`docs/combat/AGENT.md`** ← 游戏全貌 + 精简流程（新窗先读）  
**`.cursor/lanes/SYNC.md`** ← 现行板 / 收件箱  
`.cursor/handoff.md` ← 日记，需要历史再翻  
Notion 六系页 ← 设计脊柱（核玩写、你看完才锁）

统筹另开长对话（`T-统筹.md`）：系统测试、查 bug、用户同意后**唯一 git commit**。统筹窗不对业务做功能开发。

**跨切（文风、用词、铁律口径）只跟主窗说**，不要对每个车道讲一遍。主窗会改 SYNC，并写出可粘贴到专窗的开场提示词。只影响一摊的（叠按钮、叠歌、某段遭遇），直接跟对应窗说。详见 `SYNC.md`「跨切跟主窗说」。

执行车道用**新聊天框**。第一条只粘对应「开场提示词」（已改成先读 SYNC）。闲置 3～4 天的旧窗不要接着改：在该窗先说「读 SYNC 再开工」，或新开一窗贴提示词。执行车道**禁止 git commit**。

| 车道 | 文件 | 何时开 |
|---|---|---|
| 爬塔核玩 | `1-核玩.md` | **主窗。** 只做肉鸽爬塔玩法与数值 |
| 统筹 / 测试与提交 | `T-统筹.md` | 对账、测试、派单、验收、commit |

| 音乐音效 | `4-音频.md` | BGM、叠播、胜负切曲、出招声 |
| 读招破招 | `5-读招.md` | 识招破招、拆招战役、训练馆硬核；不改爬塔经济 |
| 特效制作 | `6-特效.md` | Godot 2D 水墨演出。**默认学习，未点名接入不进战斗** |
| 视觉 / Lovart | `7-视觉.md` | 包装图、纹样、氛围板。**默认试用，未点名不入库** |

并行：最多两窗，文件集不重叠。`sim.ts` 爬塔核玩与读招都可能碰到：同时只开其中一窗。`break*` / `intentWeakness` / `labV2` 只派给读招窗。`main.ts` 同时只给一个车道。

收工：改 `SYNC.md` 自己那一节，长过程可再记一笔 handoff。不要把日记当现行。
